# 评估数据集

本目录保存可版本化的固定评估输入，不保存真实私人对话。

- `synthetic/`：人工构造的合成样例。
- `benchmarks/`：外部公开数据及其转换说明。
- `regression/`：防止历史行为退化的固定样例。

每个数据集必须记录来源、格式、许可和版本。

## P5.3 陪伴策略离线回放

`synthetic/companion_absence_replay_v1.json` 是本项目编写的固定合成时间线，版本 1.0.0，不含真实个人信息或第三方内容。它覆盖常见时段后的正常缺席、当天已经聊过、勿扰、待回应、会话活跃、每日上限、设备离线和错过检查等边界。

运行 `uv run --locked python -m longmemory.evaluation.companion.absence_replay` 可执行回放。输出中的“门控通过”只表示实现与这组明确预期一致且没有放行标记为不得联系的样例；它不连接模型、个人数据库或圆屏，不证明真实用户喜欢该策略，也不会激活候选。

## P3.2 日常提取开发集

`synthetic/daily_extraction_v1.json` 是合成中文小样例，覆盖身份、偏好、习惯、带时间计划、问题、助手猜测、第三方引述和提示注入。它定义模型辅助 L1 的首轮产品契约，不包含真实个人信息，不涉及冲突取代、L2/L3 或召回质量。规范化措辞可能不同，真实模型仍需人工复核；不能把通过该小集合写成通用提取准确率。

`synthetic/l1_extraction_v2.json` 是不替换 v1 的独立冻结提取基准，包含 16 条开发题与 8 条留出题。它增加多事实、否定、不确定性、临时状态、混合陈述与问题、第三方主体和指令注入等边界；标签以必需词/禁用词约束允许合理改写，并要求候选数量和 ADD/NOOP 操作一致。默认只运行开发题；留出题必须显式允许。该集合很小、全部为人工合成，词项约束也不是完整语义评价，不能当作真实使用准确率或论文结果。运行和指标说明见 [L1 提取冻结基准](../docs/research/l1-extraction-dev-holdout-v2-2026-09-13.md)。

## L1 语义关系开发集

`synthetic/l1_semantic_relations_v1.json` 是项目原创的合成中文配对集，不含真实个人信息。开发集和留出集各有 8 条 L1、4 组已标注关系，覆盖等价改写、可能冲突、明确事实变化和可并存陈述。未标注的两两组合不是自动负例，因此评估器只报告已标注配对召回率与未标注候选数量，不伪造精确率。关系分类器的正确率属于后续独立指标；配对覆盖不能代表分类正确或允许修改记忆。见 [首轮配对基线](../docs/research/l1-semantic-pairing-baseline-2026-09-13.md)。

## 跨方法比较数据（独立于下方 smoke 数据）

`synthetic/method_comparison_v1.json`：本项目新编写的虚构合成对话，无真实个人信息或第三方原文；版本 1，JSON schema_version=1。数据未单独指定对外许可，外发前应明确许可范围。

14 条事件分属 3 个会话，保留角色、原文、时间和事件 ID；8 道开发题、4 道留出题。开发题覆盖身份转述、偏好、非第一人称陈述、跨会话/多来源、助手猜测与未知事实。默认只执行开发题，每个方法 8 次独立回答请求；当前两个方法共 16 次。

`answer_contains` 为词面参考，`required_terms` 可显式指定多个必需词语；`evidence_sets` 为替代的充分来源集合，仅评分读取。留出题与开发题共用历史且源码可见，不是外部盲测；不得把小合成集结果作为论文性能结论。运行方式见 [比较指南](../docs/research/method-comparison.md)。

## 原工程 smoke 数据（保持不变）

当前默认数据：`synthetic/memory_smoke_v2.json`（人工合成、CC0-1.0），包含 8 个小样例。
原 `synthetic/memory_smoke_v1.json` 的 5 例保持不变；v2 保留这些样例，新增无问号召回、未知属性提问和历史提问不入库回归。
v2 两组正常完整运行共 40 次回答调用；v1 为 24 次。不同数据/评分器版本不能直接比较总通过率。
用例字段包括历史输入、查询、预期记忆、预期召回、答案关键词及是否应拒答。
覆盖写入、跳过、重复、未知事实、相关但不足的证据。数据很小且集中在中文猫名情境，
只适合检查工程闭环，不适合估计模型通用准确率。
