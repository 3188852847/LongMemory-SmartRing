# 评估数据集

本目录保存可版本化的固定评估输入，不保存真实私人对话。

- `synthetic/`：人工构造的合成样例。
- `benchmarks/`：外部公开数据及其转换说明。
- `regression/`：防止历史行为退化的固定样例。

每个数据集必须记录来源、格式、许可和版本。

## 跨方法比较数据（独立于下方 smoke 数据）

`synthetic/method_comparison_v1.json`：本项目新编写的虚构合成对话，无真实个人信息或第三方原文；版本 1，JSON schema_version=1。数据未单独指定对外许可，外发前应明确许可范围。

14 条事件分属 3 个会话，保留角色、原文、时间和事件 ID；8 道开发题、4 道留出题。开发题覆盖身份转述、偏好、非第一人称陈述、跨会话/多来源、助手猜测与未知事实。默认只执行开发题，每个方法 8 次独立回答请求；当前两个方法共 16 次。

`answer_contains` 为词面参考，`required_terms` 可显式指定多个必需词语；`evidence_sets` 为替代的充分来源集合，仅评分读取。留出题与开发题共用历史且源码可见，不是外部盲测；不得把小合成集结果作为论文性能结论。运行方式见 [比较指南](../docs/research/method-comparison.md)。

## 原工程 smoke 数据（保持不变）

当前默认数据：`synthetic/memory_smoke_v2.json`（人工合成、CC0-1.0），包含 8 个小样例。
原 `synthetic/memory_smoke_v1.json` 的 5 例保持不变；v2 保留这些样例，新增无问号召回、未知属性提问和历史提问不入库回归。
v2 两组正常完整运行共 40 次回答调用；v1 为 24 次。不同数据/评分器版本不能直接比较总通过率。
用例字段包括历史输入、查询、预期记忆、预期召回、答案关键词及是否应拒答。
覆盖写入、跳过、重复、未知事实、相关但不足的证据。数据很小且集中在中文猫名情境，
只适合检查工程闭环，不适合估计模型通用准确率。
