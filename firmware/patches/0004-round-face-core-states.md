# 0004：真实圆屏核心状态脸

状态：前置哈希、干净应用、反向回退检查、ESP-IDF v5.5.4 构建、仅应用分区烧录和独立读回比对均已通过；真实视觉状态尚待用户逐项观察，不能视为实机 UI 验收完成。

## 目的

浏览器圆屏只是状态协议的设计模拟器，真实 B V2 固件仍采用微信聊天气泡。这个补丁把 SmartRing-Plus 的真实 360×360 界面切换到“状态脸优先”的第一版，同时避免把网页控制面板或长对话历史塞进圆屏。

第一版只追求五类核心状态一眼可辨：待机、聆听、思考、说话和错误。它不是最终角色皮肤，也不包含复杂动画。

## 修改范围

- `config.json`：板型从微信消息布局切换到默认单消息布局，并开启最多两行的字幕区域。
- `viewe-smartring-plus.cc`：增加板型专用 `SmartRingFaceDisplay`，使用 LVGL 基础圆角对象绘制双眼和嘴部；不同状态调整颜色与几何形态。
- 继续复用既有状态栏、网络/电量、通知、低电量提示、字幕、预览图和主题机制。
- 默认使用深色主题；运行时显式主题切换仍保留。
- 不改变设备状态机、触摸、音频、ASR、TTS、WebSocket、记忆、模型或数据库。

## 验收标准

1. 补丁能在精确前置副本干净应用，并可由反向检查撤销。
2. ESP-IDF v5.5.4 构建成功，应用仍装入 `0x3f0000` 应用分区并记录余量。
3. 待机为粉色中性脸；聆听为蓝色长眼；思考为黄色圆眼；说话为张嘴；明确错误图标映射为红色脸。
4. 状态栏、电量、网络与最多两行字幕继续存在，历史消息不再堆叠。
5. 实机逐项视觉验收前，不把编译或烧录成功写成 UI 已完成。
