# 厂家固件补丁

本目录只存放针对 `firmware/smartring_plus/upstream-baseline.json` 所描述基线的可审查补丁，不存完整厂家源码、构建目录、下载组件或固件二进制。

每个补丁必须同时说明：

- 目标基线与修改文件；
- 修改目的和不包含的范围；
- 应用前哈希检查；
- 构建命令、产物大小与验证结果；
- 实机写入地址、恢复方案和未验证行为。

目标文件哈希未知、上游副本已被手工修改或补丁不能干净应用时必须停止，不允许使用强制三方合并掩盖差异。
