# 0005：运行时圆屏皮肤协议

状态：前置哈希、干净应用、反向回退检查和 ESP-IDF v5.5.4 构建通过；尚未烧录，真机能力探测、应用、回读和重启保持均待验收。

## 目的

在不重刷固件、不改资源分区的前提下，让控制台把经过严格校验的 `skin_api=1` 颜色与脸部尺寸参数发送给 SmartRing-Plus 圆屏终端。浏览器仍可预览完整皮肤清单，设备只接收固定白名单子集。

## 修改范围

- 固件内置 `rose-night-v1` 安全回退皮肤，并从 NVS 命名空间 `round_skin` 读取运行时选择。
- 新增不暴露给普通大模型工具列表的 `self.screen.get_round_skin` 与 `self.screen.set_round_skin` 所有者工具。
- 写入前验证协议版本、皮肤 ID、清单 SHA-256、颜色与尺寸范围；无效或不完整 NVS 数据回到内置皮肤。
- 主题切换后重新应用皮肤颜色，避免设备声明与实际显示漂移。
- 控制桥在写入后完整回读，只有字段逐项相同才返回 `verified=true`。
- 不修改资源分区、网络、音频、模型、记忆或设备状态机。

浏览器清单中的动画周期和渐变仍只用于设计预览，当前设备协议不下发这些字段。

## 实机验收顺序

1. 仅把新 `xiaozhi.bin` 写入应用分区 `0x20000`；不写 NVS 和资源分区。
2. 启动小智时开启设备控制桥，等待圆屏在线。
3. 在“圆屏预览”手动执行能力检测；必须读到 `skin_api=1`。
4. 选择另一皮肤并应用；控制台必须显示经完整回读验证的皮肤 ID 与 SHA-256。
5. 重启圆屏，再次检测，确认 NVS 中的选择仍在。
6. 逐态观察待机、聆听、思考、说话和错误颜色；网页与真机不要求逐像素一致。

## 回退

撤销 0005 并重新构建、烧录 0004 应用镜像即可移除运行时协议。0005 不擦除或重分区；遗留 NVS 命名空间不会被 0004 读取。原始 16 MiB 工厂备份仍是完整恢复手段。
