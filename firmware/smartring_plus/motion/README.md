# 连续圆屏表情（0013）

当前补丁让内置几何脸持续自然眨眼、轻微呼吸、偶尔看向两侧；聆听、思考、说话和故障由既有事件切换。情绪单独保留，因此可以表达“开心地说话”。打断直接从当前几何形状转向聆听，不重播整段动画。

这是在恢复 `restore/restore-0012.patch` 后追加的增量补丁，不能应用到干净厂家代码，也不能与历史 0006 补丁重复叠加。唯一源码基线的板级文件 SHA-256 是 `2e190e96c8f53117b61ae0972e7bfcad705bbe5406bdea1d44e0af05e8c626b4`。摘要和验证边界见 [实验清单](../experiments/0013-continuous-round-face.json)，实际变更见 [0013 补丁](../patches/0013-continuous-round-face.patch)。后置摘要按 LF 归一化核对，不把 Git checkout 的 CRLF 差异当作代码变化。

## 预览与实现边界

用浏览器打开 [preview.html](preview.html)，选择交互状态与情绪，测试说话中切换聆听。它是手动模拟，没有连接圆屏或麦克风；遵循系统“减少动态效果”偏好，也可手动开启。预览复现同一组形状和时间插值，不能当作固件帧率或真实声音效果证据。

- 固件复用三个已有 LVGL 对象，每 40 ms 调度一次，使用实际经过时间进行插值；调度周期不保证设备实际达到 25 帧。
- 嘴形仅指示正在说话，未实现音频振幅同步或音素口型。
- 已有壁纸优先；成功加载壁纸后暂停几何脸计时器。不新增 GIF、模型或外部组件。
- 皮肤 JSON/NVS、A/B 壁纸、字幕、状态栏、音频和网络协议保持既有职责；没有增加设备状态机分支。
- 错误表情优先于开心等情绪。新的真实状态事件解除错误表现，情绪消息本身不解除故障。
- 当前只完成纯模型与补丁验证；完整固件编译由协调会话在独立 ASCII 工作副本验收。没有烧录，实际圆屏仍运行旧固件。语音同时运行时的流畅度、耗电与内存占用尚未测量。

## 纯模型验证

`round_face_motion.h` 不依赖 LVGL、ESP-IDF、音频或文件系统。`round_face_motion_test.cc` 覆盖自然眨眼、状态与情绪组合、打断的连续性、故障优先、不同步长的插值一致性、时钟回绕和减少动作模式。

在已初始化的本机 MSVC 开发子终端中，以 C++17、UTF-8、`/W4 /WX /EHsc` 编译测试文件，输出放项目 `local/` 的独立目录，再运行生成的测试程序。编译及运行通过不代替圆屏完整编译，也不代替实机验收。

`motion/round_face_motion.h` 是可直接审阅和测试的模型副本；补丁中的新增头文件必须与它逐字节一致。Python 合成检查会核对补丁、清单摘要与头文件副本，防止编辑一处后遗漏另一处。
