# 本机控制台：设备与状态、记忆管理、文字聊天

新增[实验中心](experiment-console.md)，查看已有实验、逐题对照来源与回答、单独保存人工复核。新路由需重启 LongMemory 网页服务后生效；不需要停止小智、加载校园模型或重新实验。

当前已实现设备与状态、记忆管理、文字聊天三页，不是完整小智智控台。用户已确认网页音量控制可用。助手角色、完整运行记录页仍待接入；记忆库需显式指定，默认只读，聊天写入需额外开关，不自动迁移。

## 文字聊天：网页入口

此步骤无需重刷圆屏、重新配网或重复测试模型连通。开发测试只使用隔离合成库，真实校园模型与圆屏交叉体验由用户执行。

1. 找到**原 LongMemory 网页服务终端**，按 Ctrl+C 停止旧网页程序。保留小智终端；不是把整套语音链路停掉。
2. 进入项目，用已有 `.env`、演示数据库和角色文件启动：

   ```powershell
   Set-Location "D:\02-项目\LongMemory-SmartRing"
   uv run --extra console --locked --env-file .env python -m longmemory.entrypoints.api --database "data/databases/xiaozhi-demo-v1.db" --enable-chat --chat-provider openai_compatible --assistant-role elysia_v1
   ```

   数据库名来自此前演示约定；若小智实际使用其他文件，必须把路径替换为同一个文件。启动时检查路径和版本，文件不存在/版本不符就拒绝，不创建“看起来成功”的空库。

   `.env` 使用原 `LONGMEMORY_LLM_*` 变量。HTTP 仍需显式 `LONGMEMORY_LLM_ALLOW_HTTP=true`，会明文发送凭据、当前会话和检索证据，仅在已确认风险的校园网用合成文本体验。不要发送 `.env` 或密钥来排查。网页使用现有模型配置格式和角色文件，不会自动读取、覆盖小智的私有 YAML；两边模型/角色是否一致需要核对。`elysia_v1` 只改文字风格，不改音色。

3. 打开 **http://127.0.0.1:8765/chat** 或左侧“文字聊天”，核对页面顶部模型、角色和完整数据库路径。只看网页、管理记忆而不聊天时，可以不传 `--enable-chat`，也不需要模型配置。
4. 输入“我养了一只叫豆包的猫”，点击“发送”。Enter 只是换行。展开回答下方的处理记录：`writes` 是真实 `add/noop` 操作，`retrieved` 是召回内容和来源 ID，`memory_context` 是本轮注入的长期记忆文本；空列表表示没有，null 表示该阶段没有可确认结果。
5. 点“新聊天”，问“我的猫叫什么”。新聊天只丢弃网页短期上下文，不删除 L0/L1；可顺便去“记忆管理”按内容搜索并查看原始来源。没有必要再做一整轮硬件测试。
6. 想验证两端共用时，只需对已连接的小智问同一个猫名问题；网页回答不会自动从圆屏播放。使用同一库才能共享；这是实际双入口体验，不是论文性能评估。

### 当前限制与故障处理

- 页面刷新会另开一个网页聊天；小智当前语音上下文与网页互不共享。网页只给模型提供本会话最近六轮成功对话；这不是长期记忆容量限制。
- 每个网页会话最多 40 轮，全局最多 32 个临时会话、最长 8 小时。服务重启会清除临时列表/轨迹/请求缓存，但原始输入、完整成功回答和长期记忆仍在数据库。完整会话归档和运行记录中心后续实现。
- 用户事件的 L0、L1 和来源在一个写事务中完成，模型调用不长时间占用数据库写锁。更新后的 LongMemory 基线代码才具备此边界；正在长期持有旧模块的进程需正常重启后生效。
- 模型失败可能发生在记忆已写入之后；看 `user_saved`、`assistant_saved` 和 `writes`，不要只看回答。程序不自动重试或回退成 Fake。
- 发送时断线/错误，点击“查询上一条处理结果（不重发）”；请求仍进行中就稍后再查。服务重启后缓存失效，不能声称消息没保存；先核对记忆/来源，不盲目重发。
- “新聊天”仅清除临时会话；不是隐私擦除。已有长期记忆的管理删除仍需 `--allow-memory-delete` 和单条确认。
- 不使用浏览器本地持久缓存、不引入 CDN、不新增密钥页面。不自动把日常输入/轨迹放入研究数据集。
- 离线演示可以改 `--chat-provider fake`，无需 `.env`；它不具备角色和多轮理解能力，不能把替身回答当成学校模型验收。

## 启动与体验

1. 保持现有小智服务运行。之前命令行音量控制已成功，不需要重刷固件、配网或重做模型测试。小智启动需包含 `--device-control`；完整命令见[音量通道指南](device-control-probe.md)。
2. 另开普通 PowerShell，进入 **LongMemory 项目**，不是小智目录。首次安装或同步环境：

   ```powershell
   Set-Location "D:\02-项目\LongMemory-SmartRing"
   uv sync --extra console --locked
   ```

   本次助手已完成这台电脑上的安装。`console` 是可选依赖组，固定 aiohttp 3.13.2；不改小智环境。以后若执行不带 `--extra console` 的 uv sync，需再次同步此组。

3. 启动网页服务，终端保持运行：

   ```powershell
   .\.venv\Scripts\python.exe -m longmemory.entrypoints.api
   ```

   也可以用 `uv run --extra console --locked python -m longmemory.entrypoints.api`。无需 `.env`，不需学校模型连接。

4. 浏览器打开 **http://127.0.0.1:8765/**。不要替换为 localhost、电脑局域网 IP、8000 或 8766。已有同端口服务时不会自动杀进程或换端口；先停止自己旧的控制台，或显式用 `--port 8767` 并访问对应地址。
5. 显示“控制服务不可用”时检查小智是否已开启控制桥；显示“请唤醒圆屏”时轻触圆屏进入聆听，等 5 秒或点击“刷新状态”。这两种情况不是同一个问题。
6. 点击“读取当前值”。上方数字是最近读到的音量，不是电量；30 秒后过期清除，不自动持续读取设备。
7. 选择适度目标音量，例如 30，点击“应用音量”。拖动滑块不会发指令；成功需同时有设备确认和相同读回值。若回执成功但读回失败、数值不一致或超时，先手动读取，不连续重试。
8. 网页服务用 Ctrl+C 停止，不停止小智、不会改回旧音量。关闭浏览器标签也不会关闭后台进程。需要撤销整个控制通道时再按原指南去掉小智启动的 `--device-control`。

这里不要求再次逐项提交确认：可直接使用；遇到错误再提供页面错误提示，**不要发送令牌、Cookie 或完整敏感日志**。

## 数据与安全边界

- 浏览器 → 8765 网页后端 → 8766 小智控制桥 → 已连接圆屏。设备令牌只在后端读取，不发到浏览器。
- 网页只绑定 127.0.0.1，不新增防火墙规则、不发布公网、不注册云站点。页面全部资源由本机提供，无第三方 CDN。
- 会话最多 32 个、有效期 8 小时；HttpOnly/SameSite Cookie，写操作必须匹配 Origin 和 CSRF 令牌。服务重启或会话失效后刷新页面，不会自动重发设置。
- 本机恶意程序或同账号访问文件的进程不在此简易会话的防护范围内。不要改成公共监听、用代理公开或把网页当作多用户管理系统。
- 设置音量范围 5–60 是本阶段安全限制，不是设备硬件极限；不提供任意工具、固件更新、批量删除或密钥管理。
- 当前依赖完整源代码仓库中的 `web/`，独立 wheel 分发网页资源尚未实现。

## 记忆管理页：连接已有库

新版增加路由后，需要重启 **LongMemory 网页终端**；不要关闭小智终端，不需要断开圆屏、配网或再次测试学校模型。

1. 在旧网页终端按 Ctrl+C。进入 LongMemory 项目，按只读模式启动：

   ```powershell
   Set-Location "D:\02-项目\LongMemory-SmartRing"
   .\.venv\Scripts\python.exe -m longmemory.entrypoints.api --database "data/databases/xiaozhi-demo-v1.db"
   ```

   上面是之前约定的小智演示库名。若实际使用的是别的库，只替换路径；控制台不会根据小智密钥配置自动猜库。路径必须已经存在且为 V4，否则显示错误，不创建空库或静默迁移。V3 升级步骤见[使用说明](../guides/使用说明.md#首次使用人工纠正前显式升级-v3-日常库)。

2. 刷新整个网页，打开 http://127.0.0.1:8765/memories 或左侧“记忆管理”。`/memories` 现在是 React 版；旧原生页临时保留在 `/memories-legacy`。先核对顶部完整数据库路径。旧会话失效属于重启后的正常行为。
3. **L1 原子记忆**页签显示可被日常召回的规范化事实，可按当前/退役状态和文字筛选；打开详情可向下查看 L0 原始来源。
4. **L0 原始记录**页签显示用户与助手当时的原文，可按角色、是否已经形成 L1 和文字筛选；打开详情可向上查看派生 L1。“未形成 L1”表示原文存在但没有成为长期事实，不是数据丢失。
5. 每页默认 25 条，列表搜索都是当前层级的文字包含关系，不是语义检索。未记录的事实时间不会拿记录时间代替；来源缺失会明确显示。
6. 命令行启动默认只读，删除按钮不可用。当前本机单用户启动面板例外地默认勾选“允许 L1 单条删除”，可在高级设置取消；终端方式需显式带以下开关重启：

   ```powershell
   .\.venv\Scripts\python.exe -m longmemory.entrypoints.api --database "data/databases/xiaozhi-demo-v1.db" --allow-memory-delete
   ```

7. **不用为测试而删除重要记忆。** 对确认不需要的条目，点击“删除”；弹窗说明将移除 L1 及来源关联。勾选理解影响，再确认才发送操作。
8. 删除后 L0 原始对话和备份仍保留，当前没有一键恢复。如果打开详情后内容或来源变化，删除会拒绝，需重新查看。请求超时不能证明未执行，应刷新核对，不连续重试。
9. 不再需要删除能力时去掉 `--allow-memory-delete` 重启，即恢复只读。以后用户再次陈述同一事实，现有提取流程仍可能产生新记忆；此功能不是永久禁止记忆某事实。

本页开发和回归只用临时合成库，没有对用户现有演示库执行删除、建库或迁移。原先无 `--database` 的启动方式仍可控制设备，记忆页会提示尚未配置。
