# 实验中心：结果查看与人工复核

## 打开

现有控制台增加了“实验中心”导航，地址为 http://127.0.0.1:8765/experiments 。只需重启 LongMemory 网页服务使新路由生效，保留原启动参数；不要停止小智，不需要校园模型连接，也不需要重新运行任何实验。

本次独立预览使用 http://127.0.0.1:8767/experiments ，不加载个人库或聊天模型，以隐藏后台进程运行。日常使用仍建议重启原 8765 服务后进入同一控制台；不要在两个服务中同时编辑同一署名的复核。若不再需要预览，可让助手核对对应进程后关闭，不按端口批量杀进程。

如果只看实验、不用记忆聊天，可以单独启动（没有其他服务占用 8765 时）：

```powershell
Set-Location "D:\02-项目\LongMemory-SmartRing"
uv run --locked --extra console --extra semantic python -m longmemory.entrypoints.api
```

保留 semantic extra 只是防止 uv 同步移除已装向量依赖，本页本身不加载 BGE。没有运行实验按钮，不调用学校接口。

## 阅读结果

1. 左侧选择实验，可搜索数据集/模型/编号，或过滤真实模型、Fake、仅检索。优先打开最新真实冻结检索回答报告；本次真实报告编号尾部为 `e342e421`（完整 ID 见页面展开项）。
2. 上方表格并排显示各组完成数、词面初筛及证据覆盖。Fake 分数不代表质量；证据覆盖的分母只含可评来源的题，不能直接等同答案分母。
3. 选择“我是谁？”等题目，下方对照各组回答。宽屏横向并排，空间不足可横向滚动；窄屏纵向排列。
4. 展开实际注入、完整检索、召回条目与来源 ID、原始来源。原始来源标明 user/assistant，缺失会提示；来源读取不等于重新验证所有产物。
5. 展开评分参照和已有复核。assistant 是助手判断，human 是本机用户自报署名；两者分开，不合并成一个权威分数。不同协议的证据指标范围不同，页面说明中有提示。

## 写下自己的判断

1. 在“我的复核署名”填稳定名称。无需账户，但也不提供身份认证；同一署名继续最近有效附页。
2. 对某一组某一题选择通过、失败、待判断或不可评分，写下判断理由；不是待判断时理由必填。
3. 点击该卡片的“保存此题复核”。只写一份新复核快照，不写原报告或记忆数据库；未评的其他题保留 pending。
4. 刷新或重启服务后选择同一实验/署名即可继续。旧附页仍保留在磁盘，首版页面只显示各署名最新有效版。
5. 出现版本冲突，重新选择实验读取最新状态后再编辑。网络错误可能发生在已保存之后，请先刷新查看，不连续点击重发。尽量只在一个控制台服务里复核，避免跨进程并发。

目前支持 experiments/runs 下的三种最小研究协议，不是任意 JSON 文件浏览器；早期平铺 smoke 报告暂未接入。损坏报告、超限或过期附页会提示，不默认为通过。报告及复核默认不提交 Git，日常个人数据不会自动纳入实验。
