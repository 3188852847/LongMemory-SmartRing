# 实验中心：运行、查看与人工复核

需要可直接复制的完整启动命令，请先看项目根目录的[使用说明](../../使用说明.md)。该说明统一使用 8767；下文保留默认 8765 的配置说明，端口以实际启动参数为准。

## 打开

现有控制台增加了“实验中心”导航，地址为 http://127.0.0.1:8765/experiments 。只需重启 LongMemory 网页服务使新路由生效，保留原启动参数；不要停止小智，不需要校园模型连接，也不需要重新运行任何实验。

此前独立预览使用 http://127.0.0.1:8767/experiments ，不加载个人库或启用聊天。预览不是保证一直在线的系统服务，已遇到进程退出但浏览器仍保留页面的情况；日常请按根目录说明自行启动并保持终端运行。不要在两个服务中同时编辑同一署名的复核，也不要按端口批量杀进程。

如果只看实验、不用记忆聊天，可以单独启动（没有其他服务占用 8765 时）：

```powershell
Set-Location "D:\02-项目\LongMemory-SmartRing"
uv run --locked --extra console --extra semantic python -m longmemory.entrypoints.api
```

保留 semantic extra 只是防止 uv 同步移除已装向量依赖，本页本身不加载 BGE。以上默认启动为只读实验模式，不能运行实验。

## 在网页运行冻结检索回答对照

需要运行功能时，停止你原来的 LongMemory 控制台后使用以下命令（保留日常聊天等其他启动参数；不要停止小智）：

```powershell
Set-Location "D:\02-项目\LongMemory-SmartRing"
uv run --locked --extra console --extra semantic --env-file .env python -m longmemory.entrypoints.api --enable-experiment-runs
```

`--env-file .env` 只让后端读取已有模型配置，不把密钥传到网页。预览使用 `--port 8767`。只想看旧结果不需要校园网，也不需要启用运行。

1. 进入实验中心，上方选择“冻结检索档案”。本轮已有检索报告尾号 `5f4c4`，完整 ID 为 `retrieval-92deeedf9d8d4d419abdec3f2e45f4c4`；与父比较报告自动按摘要匹配，不用手写路径。
2. 选 Fake 做流程体验，或选已配置的学校模型做真实回答。默认 Fake 不联网；真实模型不可选说明服务启动环境未读到有效配置，需重启加载，不是网络检测结果。
3. 上下文字符上限默认 4000，保持不变可沿用上一轮条件。改动只作用于新实验，不改旧结果；字符不等于 token，不能当作严格同 token 消融。
4. 点击“预检与核对预算”。页面只做本地来源检查；显示四组、题数、最大请求次数、模型/目标主机、单次输出上限与网络风险。现有开发集为四组 × 8 题，最多 32 次回答，不提取、不编码。
5. 连接可用的校园网后，阅读并勾选确认，再点“确认启动”。预检 10 分钟失效，失败不重试；没有费用单价，不给虚构金额。
6. 进度区显示已尝试、成功、失败、未结束；只读轮询不会启动新请求。关闭/刷新网页不取消作业；刷新后仍可看到最近任务。
7. 需要停止时点“停止后续请求”。当前正在传输的请求可能完成或计费；后续题不再执行，报告保留完整题目与未完成状态。
8. 完成或部分完成后点“打开结果”，进入原来的四组比较和逐题复核。新报告追加保存，旧结果、旧复核与日常记忆不变。

服务异常退出后显示中断，不自动续跑；需要重新实验时重新预检，产生独立新结果。停止操作需在启动任务的同一控制台服务进行。多个控制台共享同一实验目录时作业互斥，但旧 CLI 不受此锁管理，请勿同时在终端另跑模型实验。

这是第一条图形化运行流程，不是任意脚本启动器：只支持固定合成开发集、四个已冻结条件；提取/向量重建、留出集和论文模块调度后续再考虑。

## 阅读结果

1. 左侧选择实验，可搜索数据集/模型/编号，或过滤真实模型、Fake、仅检索。优先打开最新真实冻结检索回答报告；本次真实报告编号尾部为 `e342e421`（完整 ID 见页面展开项）。
2. 上方表格并排显示各组完成数、词面初筛及证据覆盖。Fake 分数不代表质量；证据覆盖的分母只含可评来源的题，不能直接等同答案分母。
3. 选择“我是谁？”等题目，下方对照各组回答。宽屏横向并排，空间不足可横向滚动；窄屏纵向排列。
4. 展开实际注入、完整检索、召回条目与来源 ID、原始来源。原始来源标明 user/assistant，缺失会提示；来源读取不等于重新验证所有产物。
5. 展开评分参照和已有复核。assistant 是助手判断，human 是本机用户自报署名；两者分开，不合并成一个权威分数。不同协议的证据指标范围不同，页面说明中有提示。

## 写下自己的判断

1. 在“我的复核署名”填稳定名称。无需账户，但也不提供身份认证；同一署名继续最近有效附页。
2. 对某一组某一题选择通过、失败、待判断或不可评分，写下判断理由；不是待判断时理由必填。
3. 点击该卡片的“保存此题复核”。只写一份新复核快照，不写原报告或记忆数据库；未评的其他题保留 pending。
4. 刷新或重启服务后选择同一实验/署名即可继续。旧附页仍保留在磁盘，首版页面只显示各署名最新有效版。
5. 出现版本冲突，重新选择实验读取最新状态后再编辑。网络错误可能发生在已保存之后，请先刷新查看，不连续点击重发。尽量只在一个控制台服务里复核，避免跨进程并发。

目前支持 experiments/runs 下的三种最小研究协议，不是任意 JSON 文件浏览器；早期平铺 smoke 报告暂未接入。损坏报告、超限或过期附页会提示，不默认为通过。报告及复核默认不提交 Git，日常个人数据不会自动纳入实验。
