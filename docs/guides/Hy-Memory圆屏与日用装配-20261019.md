## 选择与资源

正式启动器新增 `hy_memory` 后端，选项只保存下次启动指针。普通启动不会创建 Hy 库；缺失专属配置、解释器摘要不匹配、状态标记或来源文件缺失都会拒绝。旧 `longmemory`、小智摘要和无记忆选项保留；新 Hy 不迁移/覆盖旧个人库。

正式日用装配在初始化前拒绝未授权外部模型或`synthetic_transport`模拟模型；路径/身份检查可离线做，不能把禁网测试替身带进日用。真实模型、BGE和费用执行仍由V交最终结果，之后才允许主会话交接切换。

可信固定入口为项目 `local/config/hy-memory/deployment.json`，公开形状见 [部署模板](../../config/examples/hy-daily-deployment.example.json)。它只有相对路径、解释器 SHA-256、已验收 Python 3.12.13 与 `HySettings.identity()`；运行后再核对SDK报告的实际Python/Hy版本。Runtime及聊天配置暴露同一`state_identity`摘要供切换后核验。私有 `settings.json` 由 V 的白名单设置协议消费，可能包含凭据，不能提交或复制进报告。此文不假定尚未交付的真实模型设置字段。

| 资源 | 所有权与作用 |
|---|---|
| 专属 Hy 解释器 | 从所有者已安装环境只读复用，必须显式路径及摘要，不复制/迁移 `.venv`、不自动安装 |
| `data/memory/<新Hy目录>` | SDK/Chroma、状态身份及引擎独占锁；模型/端点/维度变化不能误开原目录 |
| `data/databases/<新来源文件>` | 平台原文、角色/会话、投递状态、圆屏轮次、召回凭据和严格反馈；来源独占锁 |
| 原 `--database` 基址 | 旧库保持原位，仅继续用其 `.chats.sqlite3`、`.role.sqlite3` 旁库；新记忆写入新来源/Hy目录 |
| 小智配置/声音/绑定 | 仍沿人工来源及厂家生成消费副本流程；Memory 插槽继续使用 LongMemory 薄桥，实际算法以 Runtime 身份为准 |

部署文件路径只能位于项目所属 data/local 内；HTTP 不接受模型端点、文件路径、解释器或任意模块。首次建库由已交接的切换所有者显式调用 `build_daily_hy_runtime(root, create=True)`，普通 API 启动只用 `create=False`。初始化失败先保留状态与证据，不删除后自动换目录重试。

## 轮次、来源与延迟

小智桥每连接产生独立会话，每次顶层调用产生显式轮次键。ASR 正文归档和召回走同一 Runtime；JSON 的语言/情绪包装不当作正文，静默结束提示按结构化来源抑制，助手建议只归档。

1. prepare 保存来源并标记 pending，检索此前已完成记忆，返回中立凭据。
2. 回答模型实际写出助手正文后，包装器只捕获本次调用写入的助手片段；并发旧轮被替代时回传取消，避免串答。
3. complete 在来源库同事务保存助手/关联，再持久认领一次后台投递，排队完整 Hy `observe`。
4. 本轮新事实在后台完整流程成功后才可长期召回；引擎失败保留 failed，可能已有局部写入，不能按失败直接重试。

Hy 整体流程仍保守串行，会阻塞后续召回/查看；本次没有实测真实模型延迟指标。新的当轮事实不会在本轮长期召回中出现，但原话仍属于小智当前短期对话。网页输入同步观察后召回，和圆屏延后时机不同；两者使用相同长期空间。

重复 prepare 返回409，不再次归档；相同 complete 重放原助手 ID，异答案/凭据/轮次拒绝。cancel 的原因限 cancelled/superseded/chat_failed/completion_timeout，用户来源保留 pending，不自动补提取。完成期限为五分钟，在新准备、查询或完成请求时执行；超时完成拒绝。重启中的 preparing → uncertain，prepared 可接受期限内明确完成，但不自动重放。投递认领后而引擎开始前崩溃可能仍 pending，须显式按来源尝试 ID 恢复；failed/uncertain 没有真实幂等保证则拒绝重试。

同一连接会话十分钟内的上一条已完成轮次可接严格“你刚才记错了/忘了”反馈，只写平台反馈表，不自动修改事实。内部观测请求号及可用语音轮次持久关联；缺失时保留 None。播放状态仍 unavailable/unconfirmed，complete 只是助手生成归档。

## 旧主动交流的真实状态

Hy 暂未接入旧事项、许可、安排与主动交流。启动器强制暂停旧定时任务、整理与 L1/L2 影子；旧偏好保留。Runtime 返回 `proactive.state=paused_backend_unsupported`，启动器选项明确提示暂停；旧主动 API 继续501，不能显示为“正常联系”。旧提取/召回选择对 Hy 不生效，Hy 使用独立设置。主动交流实现属于下一阶段。

## 原十元池与模型所有权

正式日用复用V现有`selected_model/ModelGateway/SharedBudget/Endpoint/HySettings`，不新增重复模型配置类。可信部署模板不变，`settings.json`按[托管设置模板](../../config/examples/hy-daily-settings.example.json)使用既有HySettings形状。端点/口令是原型占位，启动后由自有随机回环端点/口令替换；供应商Key不交给SDK、网页回答器或圆屏消费副本。`model_mode=disabled`沿V原枚举；真实托管模式由`managed_gateway=true/network_authorized=true`和已核验网关决定，不能换成synthetic_transport。

保持当前所选DeepSeek请求名、官方端点及BGE固定revision/实际512维。稳定provider_identity沿V的模型身份＋BGE资源身份公式，随机端口/口令和进程变化不改变库身份；模型/端点/BGE变化拒绝误共库。主环境只读加载CPU BGE，SDK继续使用V原专属环境，不复制环境或安装依赖。

唯一费用池固定在主项目`local/worktrees/v-hy-memory-20261019/local/runtime/hy-memory/real-validation-20261019/budget.db`。生产代码只重开已有文件，不提供create/reset。此前0.491022元是V报告的保守上界，不是X重核账单；X不消费原池做重复采样。V的请求数、token界限和最坏预留也保留，可能先于金额触发暂停。

`local/config/hy-memory/price-verification.json`按[核价模板](../../config/examples/hy-price-verification.example.json)保存官方核价时间、至多两小时期限、CNY证明和当前凭据摘要；真实回执不提交。凭据摘要只用于匹配同一币种证明，不代替实际账户核验。有效新回执只能续同一策略期限，账本追加摘要审计；不改变价格、窗口、模型、总额和任何尝试/失败预留。没有自动联网续价或自动按日/月重置。切换前由唯一操作者核实[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)及CNY元数据，再保存真实回执；模板的false/零时间不能直接投入日用。

网页回答、圆屏真实SSE和显式模型连接检查均走同一网关/原池；Hy日用不开放旁路付费实验入口。流式先预留、边收边发，usage与DONE均完整送达才释放差额。中断、缺usage或关闭保留不确定费用；客户端max_retries=0，不自动重试。不是等待完整回答再伪分块。

预算/价格暂停时保持服务可归档用户原话，返回固定本机说明，不调用记忆或回答模型。圆屏在同一轮次下本地转述暂停说明；不会悄悄换供应商或回落旧付费通道。旧后端仍保留，但本次没有自动回退；若之后安排回退对话，仍须遵守原池，不能借旧直接调用路径规避本次费用边界。

运行时持有网关关闭责任：SDK/来源先关，再关闭自有网关及活动连接。初始化失败只回收自己新建的进程/端口/句柄，状态/来源和预算证据保留。厂家消费副本只投影回环模型配置，原人工YAML/角色/声音/绑定字节保留，未知消费副本编辑仍拒绝覆盖。

## 专属管理接线的门槛

`administer_extension('hy_memory', operation)`只接受workspace/profile/history/operations/correct/delete，持Runtime串行锁。写开关关闭即拒绝；correct/delete由路由建立真实user来源，先归档、不observe；重复request_id复用首次时间/会话并核对角色/正文。用户不能从HTTP指定任意事件/路径/角色。

管理写默认false。只有拿到V真实RPC与后台语义写关闭的验收，主会话/Z才可提供与当前worker/process/management_rpc/sdk_bridge源码、SDK版本相符的`management-verification.json`。字段形状见[管理验收模板](../../config/examples/hy-management-verification.example.json)，没有验收时不要将这个false模板复制成生效文件。引擎目录与平台账本两份独占租约必须实际持有；RPC限制delete时继续false，不为UI解锁扩大单条范围。接线语义见 [Y契约](../development/hy-memory-management-contract.md)、[Hy管理指南](Hy记忆管理.md)。

Z 最终组合软件验收已通过，精确源码/构建/资源及交接候选见 [Z 报告](../development/parallel/Z-hy-release-integration-20261019.md)。管理摘要覆盖worker/process/management_rpc/sdk_bridge四文件；可信回执在SDK创建前核验后才开启进程管理flag，settings文件不能自行授权。画像须首次空库范围证明与owner锁，旧库不能补发证明；新建和重开均已实测。删除只允许显式孤立当前条目，历史链成员写审计前拒绝，worker再复查；可见历史正文同样受管理来源/uncertain隔离。见 [ADR-0185](../adr/0185-verified-hy-management-and-visible-history.md)。
