# 声音设置

更新：2026-10-14。当前日用声音是已恢复的 CosyVoice3；真实原声线、连续对话和打断有所有者验收记录，新参考声线的克隆听感仍待实际试听。助手角色决定“怎么回答”，声音档案决定“怎么合成”，二者独立。详细流程见 [参考声音与克隆](参考声音与克隆.md)和[助手角色](助手角色设置.md)。

## CosyVoice3 日用声线

1. 通过中文入口开启陪伴，打开网页“助手设置 → 声音与克隆”，确认声音服务状态。旧服务不支持档案时先停止并重新启动，不能将旧声线当克隆成功。
2. 选择已获授权的 PCM16 WAV，填写名称与录音准确原文，明确上传。支持 3–30 秒、16–48 kHz、单/双声道、最大 4 MiB、最多 32 份。
3. 上传只加入参考库，不自动选择或保存日用声线；在参考声线中选择录音，按需要编辑表达指令。
4. 点击“试听草稿”，用固定文本听效果；草稿试听不保存、不写个人记忆。
5. 点击“保存日用声线”。支持新档案的声音服务在下一次合成读取；已经开始生成的片段保留开始时的声线。页面提示需重启时，以提示为准。

参考录音主导音色，文字表达指令不能保证任意声线或完整风格遵循。“恢复原日用声线”先恢复草稿，仍要明确保存；保存冲突时保留草稿、重新读取，不自动覆盖另一页面。

## 文件与生效边界

| 内容 | 位置/行为 |
|---|---|
| 声音档案 | `local/config/voices/CosyVoice3.json`；网页与圆屏经同一声音服务读取 |
| 录音及元数据 | `data/audio/voice-references/`；内部 ID/摘要，不接收任意本机路径 |
| 公共模板 | `config/examples/CosyVoice3.json`；不含个人原文/声音 |
| CosyVoice 环境 | `local/runtime/CosyVoice/.venv/`，Python 3.10.20，与主项目及小智隔离 |
| 声音健康 | 回环 18770；健康与预热不等于设备播放或声线相似度验收 |

自定义声线启用时，原声线的预生成寒暄/等待音频暂不使用，防止混入旧声音；默认声线快路径保留。风格、原文和声线共同决定缓存身份，常驻数量受限。声音档案、录音和私有备份不提交 Git。

## 选择下次圆屏声音

后端指针表示下次启动选择，不是把运行中进程热切成另一引擎。日常界面精简旧 TTS 入口，底层兼容引擎、资源和历史证据保留；旧后端在高级兼容区。更换后端后明确停止重启，再分别核对当前 provider 和声音健康；失败不自动切换。

| 后端 | 使用边界 |
|---|---|
| CosyVoice3 | 当前恢复主链路；参考档案和受控库是本页主操作 |
| EdgeTTS | 历史联网标准音色方案，参数不等于本地克隆 |
| VoxCPM2 | 历史独立环境/受控 WAV、整句非流式适配；不等于当前恢复资源已齐备 |
| sanoTTS | 历史 Node/WASM 兼容适配；不作为近期恢复主线 |
| 豆包实时备用 | 独立完整语音模式，账号/实机证据待验，不是本地 TTS 参数 |

完整旧参数、测量和排障见 [整理前声音指南](../history/current-docs-before-20261014/docs/guides/声音设置.md)，测量只代表当时配置/负载，不是当前延迟承诺。TTS 固定测试见 [测试台](tts-benchmark.md)，软件能力不与设备首声、播放或 AEC 插话混为一谈。

## 拾音、音量与排障

拾音环境由小智 VAD（语音活动检测）设置管理，圆屏扬声器音量在设备页；两者都不会改变声线。旁人误触发先检查当前拾音环境，不凭普通 VAD 宣称具备声纹识别。网络、模型回答、GPU 合成、Opus 编码和硬件播放分别定位，不用一次整句等待推断合成速度。

保存角色或小智配置先核对摘要/备份；受管人工来源是 `local/config/xiaozhi.yaml`，备份在 `local/archive/config-backups/`，厂家消费副本不人工维护。真实克隆相似度、风格遵循、延迟与圆屏播放由所有者另验收，本轮文档检查没有操作服务、录音或设备，也无需烧录。
