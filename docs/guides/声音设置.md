# 声音设置

当前有两层入口：React 页面只管理 EdgeTTS 的四种标准音色；统一启动面板负责在 EdgeTTS 与 VoxCPM2 本地 `plain` 后端之间切换。不要把“Edge 备用音色已保存”理解为 VoxCPM2 正在使用它。

## EdgeTTS 标准音色

1. 用启动面板停止旧服务并重新启动控制台。
2. 打开 `/chat-react`（例如 http://127.0.0.1:8767/chat-react），点击“声音设置”。默认 `/chat` 暂无此功能。
3. 选择音色：Xiaoxiao（晓晓）、Xiaoyi（晓伊）、Yunxi（云希）、Yunjian（云健）。
4. 点击“联网生成试听”，完成后点击播放器播放。只发送界面显示的固定文本，不发送聊天、角色或记忆；不自动播放，不保存音频文件。
5. 点击“保存音色”并确认，只修改小智音色，不改角色、记忆或扬声器音量。
6. 停止并重新启动小智，让圆屏重新连接后体验。配置保存成功不代表运行中的服务已经加载。

## 限制与排障

- 复用小智现有 Edge TTS，无新增依赖。它是联网服务而非本地模型，见 [edge-tts 说明](https://github.com/rany2/edge-tts)。四个音色于 2026-09-04 通过公共列表核实，未来可用性可能变化。
- 试听使用默认语速、音调与音量，圆屏已有参数和扬声器不同，听感可能不同。
- React 页面仅支持本地 YAML 的 EdgeTTS，拒绝 private_voice 覆盖或其他提供器。切到 VoxCPM2 后该页面会拒绝读取/保存，而不是修改未生效的备用音色。
- 其他页面修改配置后，旧版本保存会失败；“重新读取配置”再选择，不自动重试。重新读取会丢弃未保存选择。
- 备份在小智 `data` 中，沿用 `.config.yaml.role-*.bak` 命名，共享角色同步锁。备份包含私有配置，不上传、不提交 Git。
- 试听单次最长约 30 秒、最多 2 MiB、间隔至少 3 秒；网络失败不影响文字聊天。
- 不需刷固件，不含声线克隆、训练、网页聊天自动朗读或语速调整。

合成配置、权限、备份、冲突及音频边界已测试；真实试听与圆屏生效待用户验收。

## VoxCPM2 本地声音

从 `Start.cmd` 的“圆屏声音”选择 `VoxCPM2（本地 plain）`，先点“检查并同步”，再按普通语音模式启动。模型服务与小智均由同一面板托管；停止后释放显存。完整步骤、资源成本和 Edge 回退见 [VoxCPM2 指南](VoxCPM2独立试听.md)。

当前只有固定 `plain` 参数，不提供声线上传或任意提示词；本机 HTTP 合成已通过，圆屏试听未验收。该增量决定见 [ADR-0025](../adr/0025-local-voxcpm2-tts-adapter.md)，它扩展了 ADR-0024 当时“先复用 Edge”的阶段边界。
