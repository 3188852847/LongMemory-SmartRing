## 本次保留与变化

0013 在原 restore-0012 上加入连续几何脸：静止时的眨眼、呼吸和视线微动，以及聆听、思考、说话等状态之间的连续过渡。没有新增贴图资源或依赖，协议、设备状态机和皮肤 schema 保持原契约；不是按语音音素驱动的唇形同步。

本次从实际设备 OTA（应用更新选择数据）确定活动槽 `ota_0 / 0x20000`，只写入该槽内 3,986,384 字节应用，未写引导器、分区表、OTA 数据、NVS（设备持久配置）、assets 或两份壁纸。重启前独立读回匹配应用 SHA-256，并用设备端区域摘要证明其余全部 Flash 与原备份一致。设备启动后的正常运行行为与人的听感、视觉感受需要另验。

已有壁纸继续优先显示，不能把“仍显示壁纸”直接判定为新应用未加载。若看不到几何脸，先将现象告诉主会话，由所有者决定保留壁纸还是切换显示；助手不自动改 NVS 或壁纸。

## 所有者现在的验收步骤

保持现有日用圆屏模式与服务设置，按实际使用操作；无需再运行烧录器或保持串口 monitor。

| 步骤 | 观察内容 | 记录 |
|---|---|---|
| 静止观察约 30–60 秒 | 几何脸是否眨眼、呼吸、视线微动；有无突然跳变、卡住或闪烁 | 正常/异常；当前看到几何脸或壁纸 |
| 发起一轮正常语音 | 聆听 → 思考 → 说话是否自然连续；状态是否与实际交互一致 | 哪个切换出现问题 |
| 在说话中插话 | 声音是否及时打断；表情是否连续切回聆听；能否接收新一句话 | 插话前后现象 |
| 连续正常聊天数轮 | 声音、麦克风、回答、屏幕是否持续正常；是否重启或出现明显延迟 | 具体轮次与现象 |
| 自然聊到已有记忆 | 原有日用记忆是否仍能在真实回答中正常使用 | 所有者实际观察；不以合成库或模型测试代替 |
| 核对原偏好和壁纸 | 当前原配置、已选壁纸及日常入口是否保持 | 如不同，记录具体变化 |

主会话收集反馈并登记验收结论。读回正确、启动到 idle、离线预览和编译通过不能直接填写这些项目为通过；麦克风/声音/打断/记忆分别记录。如果存在问题，先记录实际触发和屏幕/声音表现，再决定是否需要诊断或仅应用回退。
