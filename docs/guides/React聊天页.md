# React 控制台体验与构建

## 现在怎么打开

这次已在本机完成构建。统一启动面板现在默认打开 `/chat-react`，“打开控制台”按钮也进入 React 版，无需再手动修改网址。例如控制台在 8767 时地址为 `http://127.0.0.1:8767/chat-react`。

不用另开终端或启动 Vite。React 左侧“返回原版聊天”可立即回到 `/chat`，原版左侧也可进入 React 新版。两版使用同一聊天和记忆数据库，发送真实消息也会真实保存；它不是隔离实验沙盒。不要同时在两个页面发送同一会话。

可以依次体验：新建聊天 → 输入合成内容 → 展开本轮证据 → 刷新恢复 → 重命名/切换 → 主题与字号。请求结果未知时只点击“查询结果”，不重复提交。当前仍是原来的规则记忆方法，迁移不提升记忆智能程度。

记忆管理已迁移到 React，入口仍是 `/memories`。页面分为 **L1 原子记忆**和 **L0 原始记录**：L1 可以向下查看原始来源，L0 可以向上查看由它派生的 L1；“未形成 L1”不是丢失，表示原话存在但没有成为可召回事实。旧原生页面临时保留在 `/memories-legacy`。

L2 生活场景位于 `/scenarios`。这里可以按状态浏览 L2、核对构成场景的 L1 快照与当前来源状态，并显式创建、接受或拒绝候选。创建时至少选择两条活跃 L1；服务端还会检查同一主体和两个不同用户 L0 来源，页面选择数量足够不等于一定符合证据门槛。接受后的 L2 当前也不会注入网页或圆屏回答；模型自动生成尚未实现。加载或刷新页面不会创建候选。首次体验可直接照着 [L2 生活场景合成测试指南](L2生活场景测试.md) 操作。

设备与状态已迁移到 `/device`：自动轮询的是连接状态，不是设备音量；读取和应用音量都只在点击后执行，失败不会自动重试。原生设备页临时保留在 `/`。当前可控能力仍只有已验证的扬声器音量，页面没有把电量、亮度或屏幕 UI 猜成可用接口。

个性化设置位于 `/settings`：助手角色、声音和外观集中在这里，但不是一个统一配置事务。角色保存后用于网页下一轮，圆屏需在角色弹窗中单独预检/同步；声音按页面提示决定是否需要重启小智；主题与字号只影响当前浏览器。L3 用户画像不在此页编辑。

实验中心位于 `/experiments-react`，可选择冻结检索档案、预检预算、明确确认后运行回答对照、查看/停止任务、搜索档案、核对逐题证据并另存人工复核。预检不调用模型；真实模型确认会显示请求上限和网络风险；活动任务只用 GET 刷新进度。复核不会改原报告或自动初筛，响应未知时只刷新核对。原版 `/experiments` 暂留回退。

隔离 Fake 环境的真实 Chromium 验收已经覆盖发送/刷新恢复和统一导航；它不替代个人数据库、真实模型、声音、圆屏或视觉体验验收。遇到空白页、弹窗或下拉异常，先返回原版并提供现象；不要关闭安全策略解决。

## 换电脑或源码更新后怎么构建

开发环境需要 Node（本次 24.19.0）和 pnpm（本次 11.19.0）。安装阶段会下载前端依赖，不调用模型；日常运行不下载。项目不会自动修改全局 PATH 或安装 Node。

已经配置 Node/pnpm 的 PowerShell：

```powershell
Set-Location "D:\02-项目\LongMemory-SmartRing\web\react-chat"
pnpm install --frozen-lockfile
pnpm test
if ($LASTEXITCODE -ne 0) { throw "前端测试失败，请勿继续构建" }
pnpm build
if ($LASTEXITCODE -ne 0) { throw "类型检查或构建失败" }
```

需要运行真实浏览器关键路径时，在同一目录执行：

```powershell
pnpm test:e2e
if ($LASTEXITCODE -ne 0) { throw "Playwright 浏览器验收失败，请查看 test-results" }
```

该命令会先构建生产资源，再自动启动 `127.0.0.1:18777` 的临时 Fake 控制台。它创建临时 SQLite，不读 `.env`、个人数据库、校园模型或圆屏。通过时终端显示 `2 passed`；失败截图和 trace 位于 `web/react-chat/test-results/`，HTML 报告位于 `web/react-chat/playwright-report/`，二者都被 Git 忽略。若提示浏览器不存在，只安装与锁定版本配套的 Chromium：`pnpm exec playwright install chromium`；这一步需要联网。

助手当前使用的随附 pnpm 不代表用户终端已有 `pnpm` 命令。若提示找不到命令，先核对开发工具路径，不重新安装 Python 或删除项目。

构建输出在 `web/react-chat/dist/`，不提交 Git；依赖锁文件提交，个人数据库不提交。出现 503 表示缺少或无效构建；出现 404 通常先检查是否仍运行旧控制台进程。旧版入口不依赖这些产物。

## 目录用途

- `web/react-chat/src/`：React 页面、接口封装、局部样式和接口测试。
- `web/react-chat/e2e/`：Playwright 真实浏览器关键路径，只连接隔离 Fake 控制台。
- `web/react-chat/playwright.config.ts`：浏览器、临时服务、trace 和报告设置。
- `web/react-chat/dist/`：生成的生产页面与资源，不手写。
- `web/react-chat/node_modules/`：包管理器安装的开发依赖，不手写。

当前共享 antd/AppShell 块约 473 kB、聊天入口约 187 kB、设备页约 78 kB、记忆页约 84 kB（均为未压缩构建输出）；设备与记忆代码按路由动态加载。构建器仍对共享块给出体积提醒但无构建错误，之后根据真实加载体验决定是否做更细的依赖分块。最新验证数量见 CHANGELOG；自动测试不代表浏览器视觉、弹窗及个人库内容验收已完成。
