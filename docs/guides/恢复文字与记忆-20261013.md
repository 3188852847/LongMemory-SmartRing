## 用户执行：重新构建改名后的网页

进入 `web/react-chat` 后，直接用 fnm 指定原前端运行时安装和构建：

```powershell
fnm install 24.19.0
Set-Location -LiteralPath './web/react-chat'
fnm exec --using 24.19.0 -- pnpm.cmd install --frozen-lockfile
fnm exec --using 24.19.0 -- pnpm.cmd build
```

Node 由 fnm 管理；pnpm 按原 packageManager 使用 11.19.0。fnm exec 只为该命令提供指定 Node，不依赖当前终端已加载 fnm env，也不修改机器默认版本、持久 PATH 或全局包配置。构建完成后回到项目根目录。这里已有 package.json，无需 pnpm init。

本次在根目录误生成的空 Node 项目（package.json、pnpm-lock.yaml、node_modules）已完整归档到私有备份目录，实际前端源码和锁文件继续位于 web/react-chat。
