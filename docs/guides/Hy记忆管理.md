# Hy 记忆管理

日期：2026-10-19。Y 前端及管理 API 候选说明；是否可用由当前装配能力决定，不能把页面预览当作日用切换或真实模型验收。旧引擎与个人旧库保留。

## 从任务进入

当前配置选择 Hy 后，`/memories` 进入“我的记忆”，不再按旧 L1/L2/L3 划分页面。

| 视图 | 可以核对什么 | 限制 |
|---|---|---|
| 记忆条目 | 当前有效内容、原生类型的中文解释、记录时间、来源关联、分页 | 关键词和类型仅筛选本页；SDK 尚无全库正文检索，不调用有费用或状态副作用的 search 代替。 |
| 基本画像 | 引擎组装的基本认识、可得来源 | 必须证明用户/助手/来源范围；未证明时明确显示不可读取。聚合画像不是普通可编辑条目。 |
| 记录与变化 | 管理页操作的完成/运行/不确定状态及请求编号 | 不等同引擎全部内部历史。单条 SDK 历史在详情中按需读取；空记录不证明从未发生变化。 |
| 处理状态 | 本次写入/回答使用开关、等待回执、运行或排队、最近结果 | 反映 Runtime 提供的数据；历史成功不能证明本次设备或模型正常。 |

旧 `/personas`、`/scenarios`、`/memory-quality` 书签在新引擎中先核对配置，再进入相应新任务；旧后端仍使用原页面。新引擎管理不会悄悄查询旧个人库。其他聊天、声音、角色和设备页面没有重做。

## 从一条记忆回看来源

选择“查看详情”后读取完整正文、实际记录时间、有效区间和状态。未提供的时间或来源如实标注，不从提取时间推断事实何时生效。选择一个来源编号后只读取这一条原话；一个来源缺失不会自动扩大读取范围，也不会阻断查看其他来源。助手原话会标明“不是用户事实”。

真实纠正的用户指令由平台操作记录单独关联；原 SDK meta 不会被伪装成已更改。基本画像的聚合 ID 不交给普通 get/update/history。保留层与图谱、意图、深层认知加工的未启用状态明确说明。

列表只预览长内容，详情保留全文。URL 保留视图、页码和选择的条目；键盘可以打开详情、选择原话、读取历史及返回触发按钮。大字号和减少动态沿用控制台外观设置。纠正草稿继续受离页/刷新保护。

## 纠正或删除

Y 已实现表单和受控 API 候选，但默认 `serialized_writes=False`。必须完成 [接线契约](../development/hy-memory-management-contract.md) 中 V/X 的证明和组合验收，并取得服务器启动权限与当前写开关后才显示动作；普通读能力不代表写能力已开放。仅事实和摘要可提交，画像、原始记录与保留层只读。

纠正时填写自己确认的内容，并核对范围；这次真实用户指令会先由平台归档。删除仅作用于选中的引擎条目，原话、历史、备份保留，不是全部隐私擦除，也不承诺同一内容不会从后续对话再次形成。页面没有新 Hy 全库清空按钮。

操作在唯一引擎拥有者中串行比较修订，**不是 SDK 原生原子比较**。失败可能已部分提交。前端不会自动重试；请求编号可沿操作记录及平台来源追踪。重复点击只发出一次写请求，返回请求编号不匹配也不会显示成功。遇到修订冲突应关闭表单、刷新并重新核对；遇到不确定结果应先核对操作记录，暂不再提交。未确认条目不会注入回答；当前尚无自动回滚或解除隔离入口。

实际验证范围与未接线项见 [Y 交付报告](../development/parallel/Y-hy-memory-ui-20261019.md)。只有合成库/模拟 API 使用过这些按钮；真实用户数据和日用服务未操作。
