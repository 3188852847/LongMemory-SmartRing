# Hy 记忆管理

日期：2026-10-19。V/X/Y 接线与 Z 组合软件验收已完成，正式切换仍由主会话/X交接；可用能力由本次装配决定。旧引擎与个人旧库保留。证据见 [Z 报告](../development/parallel/Z-hy-release-integration-20261019.md)。

## 全站导航与机制入口（2026-10-21界面）

控制台从轻量身份接口确认引擎；总览、聊天、设置和设备等页面共用结果。Hy显示“我的记忆”和“记忆机制”，入口为 `/memories?view=mechanisms`；未知、加载或失败不会猜成旧引擎，已有结果刷新失败会注明上次确认。Hy总览/聊天不扫描旧L1或SDK条目来补数量。旧引擎保留原管理能力；显式指定旧库但聊天尚未初始化时，管理页仍可只读浏览，方法保持未知，不为查看开关创建聊天Runtime。

机制页可切换运行路径、Hy L0–L7八层、模式与能力边界、证据入口。固定2.0.3目录含46项一级机制及lite/pro/ultra三种模式；L4为历史兼容，L5为保留层，Hy L0基本信息与平台原话分开。SDK支持、当前配置声明与执行证据分别核对：已接入不等于本次成功、健康或有数据。逐项写入决策、完整最终注入轨迹、旧图库内容浏览等未接通范围继续明确说明；旧后端的质量聚合不套用Hy。机制目录的软件组合记录见[前轮Z记录](../development/parallel/Z-hy-mechanisms-review-20261021.md)，逐层实际内容另按下面的新入口核对，正式发布状态由主会话/X接力记录。

## 逐层查看已保存内容（本轮候选）

进入“记忆机制”→“L0–L7 分层”，或打开 `/memories?view=mechanisms&mechanism_tab=layers`，再选择一层。内容显示在机制说明之前；屏外内容会在显式点层后就近进入视口。运行节点、分页和详情不强制回到整页顶部；刷新/前后退保留URL坐标与可恢复的阅读位置。大字号使用外观设置保存，刷新后继续生效。本节是新增候选的操作说明，不表示正式服务已经切换；组合证据见[本轮Z记录](../development/parallel/Z-hy-layer-data-review-20261021.md)。

L0显示完整可读版本合并的基本信息、字段可得来源和原生版本数，不能把链头差异当完整画像；空值和空文本分别保留。聚合句柄 `profile` 与实际链头、原生版本ID分开，只读详情不提供纠正或删除。L1显示SDK实际保存的RAW（原始记忆），平台原话账本通过单条来源另外读取，两者不是同一份原文。

普通层默认显示全部原生状态，每页20条，可筛选有效、已被取代、否定、冲突、影子或归档。数量只在范围和末页可证明时显示，其他为“总数未知”；非首页空页不证明整层为空。到本次浏览上限时停止向后翻页并说明后续尚未读取，可以返回前页或刷新，不作全库扫描。原生顺序分页不是全库时间排序，跨页也不是冻结快照。

列表正文最多1024字符，详情最多32768字符，原文字符数和截断会标明。详情可查看真实状态/时间、可得平台来源、关联RAW和原生版本；未知时间、缺来源或缺历史都不补造。L4历史兼容、L5保留、L6/L7生成关闭与实际已有内容分别判断；只覆盖向量存储而图库未打开时，总数保持未知，不能据此说整层为空。L0缺范围证明或超过聚合上限时明确不可读取。

忙碌或读取失败时手动重试，不会自动轮询、开启生成或调用模型补数。总览和聊天不预取各层数据，写入/回答使用暂停时仍可只读查看。接口及存储边界见[逐层契约](../development/hy-layer-data-contract.md)。

## 从任务进入

当前配置选择 Hy 后，`/memories` 进入“我的记忆”，不再按旧 L1/L2/L3 划分页面。

| 视图 | 可以核对什么 | 限制 |
|---|---|---|
| 记忆条目 | 当前有效内容、原生类型的中文解释、记录时间、来源关联、分页 | 关键词和类型仅筛选本页；SDK 尚无全库正文检索，不调用有费用或状态副作用的 search 代替。 |
| 基本画像 | 引擎组装的基本认识、可得来源 | 必须证明用户/助手/来源范围；未证明时明确显示不可读取。聚合画像不是普通可编辑条目。 |
| 记录与变化 | 管理页操作的完成/运行/不确定状态及请求编号 | 不等同引擎全部内部历史。单条 SDK 历史先核对机制开关，关闭或未知时不发历史请求；平台管理审计另行读取，空记录不证明从未发生变化。 |
| 处理状态 | 本次写入/回答使用开关、等待回执、运行或排队、最近结果 | 反映 Runtime 提供的数据；历史成功不能证明本次设备或模型正常。 |

旧 `/personas`、`/scenarios`、`/memory-quality` 书签在新引擎中先核对配置，再进入相应新任务；旧后端仍使用原页面。新引擎管理不会悄悄查询旧个人库。其他聊天、声音、角色和设备页面没有重做。

## 从一条记忆回看来源

选择“查看详情”后读取完整正文、实际记录时间、有效区间和状态。未提供的时间或来源如实标注，不从提取时间推断事实何时生效。选择一个来源编号后只读取这一条原话；一个来源缺失不会自动扩大读取范围，也不会阻断查看其他来源。助手原话会标明“不是用户事实”。

真实纠正的用户指令由平台操作记录单独关联；原 SDK meta 不会被伪装成已更改。基本画像的聚合 ID 不交给普通 get/update/history。保留层与图谱、意图、深层认知加工的未启用状态明确说明。

列表只预览长内容，详情保留全文。URL 保留视图、页码和选择的条目；键盘可以打开详情、选择原话、读取历史及返回触发按钮。大字号和减少动态沿用控制台外观设置。纠正草稿继续受离页/刷新保护。

## 纠正或删除

默认 `serialized_writes=False`。可信管理回执、精确源码、真实 RPC 能力和独占锁核对通过才开启；服务器启动权限与当前写开关仍须允许。日用 settings 不能自行打开管理 flag。仅当前有效事实和摘要可提交，历史非 latest、画像、原始记录与保留层只读。决定见 [ADR-0185](../adr/0185-verified-hy-management-and-visible-history.md)。

纠正时填写自己确认的内容并核对范围；真实用户指令先由平台归档。删除只允许没有前驱/后继的当前独立条目，所有历史变化链成员拒绝，避免恢复旧事实。原话、历史、备份保留，不是全部隐私擦除，也不承诺同一内容不会从后续对话再次形成。页面没有新 Hy 全库清空按钮。

确定性的权限/资格/修订拒绝显示“操作未执行”，可关闭、刷新并核对原因，不产生不确定写审计。真正未知仍禁止重复提交。召回含历史版本时，completed 纠正来源随可见版本关联；任一可见版本未确认时整段链头暂不注入回答。

操作在唯一引擎拥有者中串行比较修订，**不是 SDK 原生原子比较**。失败可能已部分提交。前端不会自动重试；请求编号可沿操作记录及平台来源追踪。重复点击只发出一次写请求，返回请求编号不匹配也不会显示成功。遇到修订冲突应关闭表单、刷新并重新核对；遇到不确定结果应先核对操作记录，暂不再提交。未确认条目不会注入回答；当前尚无自动回滚或解除隔离入口。

实际验证范围与未接线项见 [Y 交付报告](../development/parallel/Y-hy-memory-ui-20261019.md)。只有合成库/模拟 API 使用过这些按钮；真实用户数据和日用服务未操作。
