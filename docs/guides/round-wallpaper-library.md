# 动态壁纸素材库使用说明

## 启动

1. 使用日常启动面板启动控制台。启动器会自动发现已有的 `D:\Tools\ffmpeg\bin`，不会下载或改动 FFmpeg。
2. 打开“圆屏预览”页，找到“6. 动态壁纸素材库”。
3. 如页面提示没有 FFmpeg，先确认 `ffmpeg.exe` 和 `ffprobe.exe` 均在上述目录，再停止并重新启动面板服务。

## 导入一个视频

1. 在“源视频”选择本机视频，单文件不得超过 768 MiB。
2. 填“截取起点”。例如要从第 60 秒开始，填 `60`。
3. 选时长、帧率和颜色数。首次建议保持 `5 秒 / 10 fps / 96 色`。
4. 点“导入并生成预览”。大视频需先传入本机服务再转码，页面显示处理中时不要重复点击。
5. 完成后核对圆形预览、源分辨率、截取参数、预览大小和哈希摘要。
