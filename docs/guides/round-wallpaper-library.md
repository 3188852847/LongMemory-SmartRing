# 动态壁纸素材库使用说明

## 启动

1. 使用日常启动面板启动控制台。启动器会自动发现已有的 `D:\Tools\ffmpeg\bin`，不会下载或改动 FFmpeg。
2. 打开“圆屏预览”页，找到“6. 动态壁纸素材库”。
3. 如页面提示没有 FFmpeg，先确认 `ffmpeg.exe` 和 `ffprobe.exe` 均在上述目录，再停止并重新启动面板服务。

## 导入一个视频

1. 在“源视频”选择本机视频，单文件不得超过 768 MiB。
2. 填“截取起点”。例如要从第 60 秒开始，填 `60`。
3. 选时长、帧率和颜色数。首次建议保持 `5 秒 / 10 fps / 96 色`。
4. 点“导入并生成预览”。大视频需先传入本机服务再转码，页面显示处理中时不要重复点击。
5. 完成后核对圆形预览、源分辨率、截取参数、预览大小和哈希摘要。

## 发布到圆屏（0009 固件完成实机迁移后）

1. 用启动面板同时启动控制台和圆屏语音服务；壁纸单文件端口只在该模式监听选定的局域网 IP。
2. 让圆屏进入已连接状态。页面成功回读壁纸协议后，“发布到圆屏”才可点击。
3. 点击某个素材的“发布到圆屏（会重启）”。设备先把文件写入非活动槽，核对长度、GIF 尺寸和 SHA-256，再选择该槽并重启；页面不会自动重试。
4. 圆屏重连后刷新或等待页面回读。只有素材旁显示“圆屏已回读”，才代表新壁纸已成为活动版本。
5. 若新壁纸体验异常，点击“回退上一壁纸”。设备选择上一个已验证槽并重启；没有可验证备用槽时按钮不可用。

如果圆屏聊天正常但下载失败，再打开启动面板的“圆屏网络与防火墙”，为实际圆屏 IP 或受限网段添加项目规则；规则仅开放 `8000/8003/8768`，不会关闭系统防火墙。
