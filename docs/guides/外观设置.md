# 聊天网页外观

1. 更新后停止并重新启动控制台，打开文字聊天。
2. 打开“外观与阅读”。主题可选跟随系统、浅色、深色；字号可选标准、大、更大；界面动画可选跟随系统、减少动画、完整动画。
3. 选择后立即生效并保存到当前浏览器；“减少动画”会关闭圆屏预览的眨眼、聆听波纹、思考轨道、说话嘴型和控制台导航过渡，不会修改真实圆屏固件。
4. “恢复默认”恢复跟随系统主题、标准字号和跟随系统动画。刷新会保留选择；不同端口或浏览器不共享此偏好。
5. 浏览器禁止本地存储时，选择只在当前页面生效，不会阻止聊天。

偏好作用于同一控制台的 React 页面和圆屏浏览器预览，不改变真实圆屏、音色、助手角色或长期记忆。
