# Hy-Memory 真实模型与本地向量验证

本页补充[隔离接入指南](Hy-Memory隔离接入与验证-20261019.md)的真实模型阶段。旧指南“未运行真实模型/保留集”描述的是此前阶段；本轮结果及逐题复核见 [V 实际报告](../development/parallel/V-real-model-20261019.md)。此入口用于隔离合成实验，不是日用启动器。

## 环境与数据边界

使用所有者已安装的 Hy 2.0.3 专属解释器和既有完整锁；主环境只负责本地 BGE、原日用方法和模型网关，不混装依赖。BGE 从主项目固定 revision 子目录只读加载，启用离线模式，不下载模型或分词资源。实验历史只来自 `datasets/synthetic/hy_memory_{dev,holdout}_v1.json`，每次创建新状态，不连接个人库或日用端口。

网关只绑定自有随机 `127.0.0.1` 端口，以随机口令认证。真实供应商密钥只留网关进程，不传给 SDK；SDK worker 只能访问指定本地网关。普通离线入口仍默认禁用模型，不能用真实入口的授权泛化到其他数据/供应商。

本轮窄范围读取主项目已选模型档案及其选中 env 的必要字段；网页/圆屏须同选官方 DeepSeek，模型须与已核价请求名一致。币种元数据须确认 CNY，余额金额不保存。切换模型/币种/端点须重新核价、定范围，不能自动尝试替代源。

## 同一账本执行总预算

整轮上限 10 元人民币。唯一账本位于 V 工作树 `local/runtime/hy-memory/real-validation-20261019/budget.db`，连接检查、开发调试、旧提取、Hy 内部调用、最终回答和保留集全部共享。不要删除、重建或更名账本以继续调用。

`SharedBudget` 先用 SQLite 原子事务预留最坏费用，再允许发出请求；完整、有效的供应商 usage 才能释放差额。失败、超时、崩溃或缺失 usage 保留完整额度。按未命中输入 2 元/百万 token、输出 8 元/百万 token 结算，不采用缓存或时段折扣；这只是保守上界，不是已核账单。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

每次预留完整窗口放大上界：2,097,152 输入＋524,288 输出 token，合计 8.388608 元；已完成请求释放后才可发下一次。请求串行，最多 400 次、累计 token 上界 1000 万，价格有效期两小时。额度不足或价格过期即停止；未知请求不能按零费用重试。网关拒绝另收费服务端搜索/抓取工具，仅接收本地 function 工具声明。

## 相同条件与明确差异

两方法使用同一历史、问题、真实回答模型、原回答提示、4000 字符上下文上限及 512 token 回答上限。旧对照实际使用 `DailyLLMMemory` 模型提取＋`HybridMemoryRetriever` 关键词/BGE 混合召回，包含原自然命令和显式日期路径。Hy 为 pro/chat、graph-off、profile-on，不开启主动意图。

所有付费请求显式关闭 thinking（思考模式），避免默认模式形成未记录条件差异。[官方思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。Hy 系统提示仅追加固定中文记忆适配，保留否定、日期和不确定性，不注入题目答案。BGE 都使用固定 512 维 CPU 模型；SDK search RPC（远程过程调用）带 query 前缀，add 内部的协调检索未提供类型标志，按 document 编码，这一差异保留记录。

原生画像未返回完整来源；适配器通过公开 `get_user_basic_info`、`get` 重新读取结构化版本，重建当前字段并验证与原画像完全一致后才附来源。历史检索通过公开版本 ID 读取全部可见版本来源；任何缺失保持 unknown（未知）。不按正文相似度猜来源，不用链头来源替代整段演化。

## 执行与复核

由协调会话确认本轮范围、现存账本及互斥状态后，在 V 工作树使用主项目既有 Python，设置 `PYTHONPATH=src`，运行模块 `longmemory.evaluation.comparison.hy_real_runner --split dev`。可用 `--probe-only` 单独连接验证，但仍计入同一预算。

开发集逐题复核通过后，将该轮 `condition.json` 原样复制为同目录新文件 `frozen-condition.json`；这一步代表人工冻结，不由程序自动批准。再使用 `--split holdout --dev-campaign <该轮绝对目录>`；源代码摘要、模型、提示、BGE、价格策略等任一变化都会拒绝保留集。保留集仍是本地独立合成集，不能称外部盲测；不得据其答案继续调适配后复用同一保留结论。

实验目录 `experiments/runs/vreal-*` 保存条件、建库/逐题报告、来源账本、封存库、逐题副本、网关 usage 与预算前后快照；原始合成响应与库不提交 Git。每题从已关闭的封存库复制，封存源摘要须保持不变；副本文件变化、公开活动视图与 Chroma 四张逻辑表分别核对。即使这些相同，也不宣称覆盖 SDK 所有私有状态或通过原 strict frozen（严格冻结）协议。

词面评分只是初筛，逐题检查答案、注入证据及真实来源；未知、归因、纠正和日期不能用总分替代。关键失败阻止日用候选推荐。通过只支持当前小规模合成条件，日用组合、圆屏连接/声音/打断和后续主动交流另验收；本入口不改变日用选择或启动调度。

## 管理低层协议接力

2026-10-19 补充的 `management_capabilities/history/update/delete` 使用原 JSONL 包络，参数白名单、SDK 异常 state_unknown、无自动重试。只读历史按当前条目归属校验，当前 SDK history 关闭，空数组不代表没有发生变化。更新仅允许同 user/agent/namespace 的当前 ACTIVE L2/L3，走原生 SDK update＋显式本地 BGE（专项为合成 transport），原 RAW/meta 保留；新纠正来源由 Y 平台审计关联，不伪造进 SDK。

删除只支持 supersedes/superseded_by 都为空的孤立当前 L2/L3。演化链头、中间和尾节点全部拒绝；原生删除会改其他节点，链头删除还可能恢复旧事实。UI/Runtime 应在 running 审计前先做资格检查，worker 再独立复核，不把写前拒绝变成已完成或自动重试。没有 delete_all、原文/备份擦除、原生 CAS 或跨存储事务。

可信装配的 `management_writes_enabled` 默认 false，必须与 Y serialized_writes、Runtime 权限和独占锁同时满足才用于日用写。`management_exclusive_profile` 也默认 false：只有在持有 owner 租约的新空空间首次创建范围证明，后续证明/身份/锁都匹配才公开画像能力；旧库打开开关不会自动补证。保留 `management-scope.json` 随整个状态目录备份。完整字段、真实 SDK 副作用、104 项回归及 X/Z 精确接线待办见 [V 接力报告](../development/parallel/V-real-model-20261019.md#管理-rpc-接力hy-rpc-0022026-10-19)。

本接力禁网、零收费，不重跑真实保留集、不重建或增加原 10 元账本。流式日用网关归 X 实施，V 不修改其文件；低层通过不代替三方组合或实机验收。
