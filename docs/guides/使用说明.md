# 智慧圆屏使用说明

## 开启陪伴与结束使用

1. 双击项目根目录的 [启动智慧圆屏.cmd](../../启动智慧圆屏.cmd)，选择“文字聊天”或“圆屏陪伴”，点击“开启陪伴”。
2. 文字模式进入网页即可聊天；圆屏模式就绪后，按圆屏开始说话。文字模式会暂停圆屏定时联系，网页回答也不会自动从圆屏播出。
3. 用完后点击“停止服务”。要一起关闭启动面板，选“停止服务并退出面板”。只关网页时服务继续运行。

## 文字聊天、会话和记忆

网页可以切换或恢复聊天。“新聊天”会开启一段新对话，已保存的长期记忆仍可查询。点回答旁的“记忆证据”可查看这轮用到了什么；需要核对时，打开对应的原话或来源。入口名称随当前记忆引擎变化。[聊天会话](聊天会话.md)

记错了，在记忆详情里纠正；以前正确而现在不同，原子记忆界面用“记录变化”。如果另一页刚修改过同一条记忆，重新打开核对后再提交。删除一条事实不会同时清除原始对话或备份。

需要暂停记忆时，在记忆设置里分别调整生成和使用。暂停生成仍可能保留对话原文。若 Hy 提示后台同步失败，可再次应用同一设置并查看回执。

## 圆屏使用与设备状态

圆屏没响应时，打开设备页看是否已连接；听不到声音时，查看面板的声音服务状态。换声线、调角色和处理网络问题分别见[声音设置](声音设置.md)、[助手角色设置](助手角色设置.md)和[统一启动排障](统一启动.md)。更改启动选项时，先停止服务，保存后重新开启。

## 主动交流设置

需要圆屏定时联系时，在“设置中心 → 主动交流”设置许可、时段、频率和勿扰。圆屏离线、忙碌或在勿扰时段会跳过问候。频率表示最多多久尝试一次。一次性跟进和问候记录见[主动交流的运行说明](../architecture/workflows.md#主动交流与一次性跟进)。
