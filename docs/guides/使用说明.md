# 智慧圆屏使用说明

## 开启陪伴与结束使用

1. 双击项目根目录的 [启动智慧圆屏.cmd](../../启动智慧圆屏.cmd)，选择“文字聊天”或“圆屏陪伴”，点击“开启陪伴”。
2. 文字模式进入网页即可聊天；圆屏模式就绪后，按圆屏开始说话。文字模式会暂停圆屏定时联系，网页回答也不会自动从圆屏播出。
3. 用完后点击“停止服务”。要一起关闭启动面板，选“停止服务并退出面板”。只关网页时服务继续运行。

## 文字聊天、会话和记忆

网页可以切换或恢复聊天。“新聊天”会开启一段新对话，已保存的长期记忆仍可查询。点回答旁的“记忆证据”可查看这轮用到了什么；需要核对时，打开对应的原话或来源。网页、圆屏和已经确认绑定的 QQ 私聊共用 Hy-Memory，设置页可查看运行状态。[聊天会话](聊天会话.md)

需要纠正记忆时，在记忆详情查看当前条目支持的操作。如果另一页刚修改过同一条记忆，重新打开核对后再提交。删除一条事实不会同时清除原始对话或备份。

需要整库重新开始，在启动面板停止陪伴，进入「启动设置 → 记忆 → 清空当前记忆库」。确认后会创建并复核空库，保留旧库与恢复指针（`data/backups/hy-before-reset-*.json`）。网页聊天档案仍可查看。

本机大肥鱼素材放在 `data/round-screen/whale/`，打开文字聊天可点击桌宠聚焦输入框，在「圆屏状态预览」里可以预览倾听、思考和说话动作。真机使用设备已部署的资源。

圆屏应用 `2.2.3-whale0017` 的大肥鱼待机界面支持三种触摸。轻触头顶后松手，她会露出开心表情；轻戳脸颊会眨眼；在头或脸上横向来回揉一下再松手，她会露出困倦的表情。表情约 1.8 秒后回到待机。想说话时点角色下方的空白区域；正在说话时轻点屏幕仍可打断。在壁纸视图中，点按沿用原来的聊天操作。

需要暂停记忆时，在记忆设置里分别调整生成和使用。暂停生成仍可能保留对话原文。若 Hy 提示后台同步失败，可再次应用同一设置并查看回执。

## 圆屏使用与设备状态

圆屏没响应时，打开设备页看是否已连接；听不到声音时，查看面板的声音服务状态。换声线、调角色和处理网络问题分别见[声音设置](声音设置.md)、[助手角色设置](助手角色设置.md)和[统一启动排障](统一启动.md)。更改启动选项时，先停止服务，保存后重新开启。

## 资料与恢复

### 首次使用人工纠正前：显式升级 V3 日常库

这个旧版操作只适用于历史 V3 库。恢复或迁移现有库时，先核对实际版本与一致性备份，按[文字与记忆恢复指南](恢复文字与记忆-20261013.md)操作。

## 陪伴小屋与 QQ

从网页侧栏打开“陪伴小屋”。控制台使用回环地址读取宿主状态，小屋管理页独立登录。本机安装为 AstrBot 4.29.3 和 [我会永远陪着你 7.2.7](https://github.com/menglimi/astrbot_plugin_private_companion/tree/c0acd88adecc34a6637de00e4ff7f234e2ed5ac0)。宿主、插件及数据位于 `local/runtime/companion/`。统一启动器启动服务时会带起已安装的小屋，已经独立运行的实例由原进程管理。

1. 本机管理入口为 [陪伴小屋](http://127.0.0.1:16185/#/plugin-view/astrbot_plugin_private_companion/陪伴小屋)。本次安装用户名为 `astrbot`，初始密码在私有目录的 `首次登录密码.txt`。
2. QQ 官方机器人扫码后，在手机 QQ 私聊机器人，发送“我会永远陪着你 大肥鱼”。首次在“小屋 → 开始使用”里核对并确认自己的窗口，再设置主动频率和免打扰时段。
3. 在小屋按需启用创作、生图、识屏、现实设备、共同陪伴、游戏和直播。需要外部账号、硬件或采集权限的能力在对应扩展内完成配置。
4. QQ 适配器显示连接中时，先在 AstrBot“机器人”里查看状态。若创建配置后报缺少 `enable_group_c2c`，重新保存 QQ 官方机器人配置，启用私聊所需的 C2C 事件，再核对绑定窗口。已经保存有效凭证时可以直接修复配置。

绑定后，QQ 私聊、网页和圆屏使用同一个 Hy-Memory。网页聊天页按时间显示三个入口的对话，往前翻可以查看更早的消息。大肥鱼自己的回答保存在对话历史里。三个入口共用记忆开关。使用时保持智慧圆屏控制台（日用端口 8767）和陪伴小屋运行。

在「陪伴小屋 → 关系网 → 用户 → 联系偏好」打开「启用主动计划」和「自动寻找联系契机」，可以一起调整三个入口的联系频率和免打扰时段。大肥鱼会结合记住的事和近期聊天选择话题。一次联系只选一个入口：优先出现在正在看的网页聊天页，其次由空闲且能播报的圆屏说一句短话，其他情况发到已绑定的 QQ 私聊。带图片的消息走 QQ。在任一端回复后，都计入同一套联系记录。

恢复本机安装时，将仓库里的 `scripts/development/astrbot/astrbot_plugin_smartring_memory` 复制到隔离宿主的 `local/runtime/companion/data/plugins/`。从项目根目录执行 `.venv/Scripts/python scripts/development/astrbot/install_outreach.py local/runtime/companion/data/plugins/astrbot_plugin_private_companion`，再在 AstrBot 重载这两个插件。补入绑定前的 QQ 文字历史使用 `scripts/development/astrbot/import_qq_dialogue.py`，旧记录按原时间进入共享对话，不重新提取用户事实。
