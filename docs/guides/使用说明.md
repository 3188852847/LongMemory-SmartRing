# 智慧圆屏使用说明

更新：2026-10-14。日常从 `D:\03-项目\01-正式项目\智慧圆屏\启动智慧圆屏.cmd` 进入 React 启动面板。本文说明操作与生效边界；[统一启动](统一启动.md)负责启动排障，[本机目录](本机目录与依赖.md)负责环境归属。

## 开启陪伴与结束使用

1. 双击中文入口，选择文字聊天或圆屏陪伴，再点击“开启陪伴”；打开面板本身不会自动启动服务。
2. 核对各项服务状态，再进入陪伴空间。面板优先使用 Edge 应用窗口，控制台是正常网页，不需要常驻 Vite。
3. 文字模式不要求圆屏在线，并暂停圆屏定时联系；圆屏模式加载保留的主动交流设置与事件账本。
4. 修改启动选项先停止，再保存并重新启动；模型/后端/圆屏角色按各自提示核对生效，不只刷新网页。
5. 结束聊天后用“停止服务”；需要退出控制主机时用“停止服务并退出面板”。关闭浏览器窗口保留服务，下次双击重开同一面板。

当前保留圆屏、CosyVoice3、官方模型、模型辅助提取与关键词＋BGE 混合召回；以面板和聊天运行配置为准，不照抄旧终端默认值。低频整理和 L1/L2 影子复核继续关闭。服务就绪、模型可用、圆屏连接、声音播放是不同检查项，不能相互代替。

## 文字聊天、会话和记忆

网页聊天页支持新聊天、会话切换与恢复。新聊天清空当前短期上下文，不删除长期记忆；网页和圆屏通过共享 Runtime（常驻记忆处理服务）访问同一日用库，但双方短期上下文独立。网页回答不会自动由圆屏播放。查看会话操作见 [聊天会话](聊天会话.md)。

记忆管理可查看 L0（原始来源）、L1（原子事实）、L2（生活场景）、L3（用户画像），检查来源与有效期。漏记时可明确添加以“我/我的”开头的完整事实，保留管理来源；错误用“纠正错误”，过去正确但后来变化用“记录变化”，不会原地改写旧事实。删除须逐条确认，删除 L1 不等于擦除原始对话、备份或日志。

### 本次运行的记忆模式

记忆生成和回答使用是两个独立开关：关闭生成仍保存 L0；关闭使用不检索/注入已有记忆，也不删除数据。页面明确应用后从下一轮作用于网页和圆屏，本次进程有效，重启恢复开启。电脑合成验收使用隔离数据库并暂停主动调度，不往个人库写测试句。

### 圆屏自然纠正与来源操作

以下是保守的固定表达；系统不把任意近义说法当作授权。以实际操作回执和记忆详情为准，不以模型口头承诺为准。

| 目的 | 示例 | 数据含义 |
|---|---|---|
| 明确记住 | `请记住：我叫小林` | 保存 L0，生成/去重单条自指 L1 |
| 纠正错误 | `不是豆包，是年糕` | 唯一命中旧 L1 后追加纠正并取代旧条目 |
| 记录变化 | `我以前喜欢喝咖啡，现在不喝咖啡了` | 旧/新 L1 分别记录现实有效区间 |
| 问来源 | `你怎么知道豆包？` | 查看对应用户 L0，不新增事实 |
| 本轮跳过 | `不要记住：我今天想喝茉莉花茶` | 仍保留 L0，本轮不生成 L1 |
| 请求删除 | `请忘掉豆包` | 只回读待删目标 |
| 确认/取消 | `确认删除这条记忆` / `取消删除` | 两分钟内、目标未变且未插入其他对话才执行确认 |

## 圆屏使用与设备状态

圆屏负责采集、传输、显示和播放，电脑负责记忆与语音服务。开启圆屏陪伴后，在设备页核对活动连接，再开始对话；局域网配网或服务器监听不等于设备已连入。日用主链路为 Silero 判停 → SenseVoice 听写 → 共享记忆 → 所选回答模型 → CosyVoice3 → Opus → 圆屏。

音量、设备状态和有限控制在设备页查看；声线与助手表达见 [声音设置](声音设置.md)、[助手角色设置](助手角色设置.md)。参考录音上传、草稿试听、保存互相独立，默认声线已恢复，新克隆听感另验收。电脑圆屏预览不代表设备画面已切换；0013 新表情只离线编译，未烧录。网络问题先读状态和当前 IP，按 [统一启动排障](统一启动.md#电脑-ip-变化后的操作)处理，不照抄旧 IP 或重刷设备。

## 主动交流设置

控制台 `/settings` 的“主动交流”可查看总许可、周期问候、频率、允许时间、勿扰、跟进与账本。当前以页面分类为准，布局优化不改变策略含义。

周期问候需要独立开关；新配置默认关闭，已恢复日用配置保留所有者原选择。频率范围为 1–1440 分钟，24 小时模式保留每日时刻；短周期从下一个允许分钟检查。频率表示尝试上限，不保证发声：离线、忙碌、勿扰、时段外、待回应等条件会阻止，错过/过期不补发。网页或圆屏的明确频率命令只改周期，不暗中打开许可或周期开关。

严格一次性请求例如 `我明天下午三点要提交毕业设计汇报，到时候问我汇报进展`，须形成唯一新增 L1；总许可开启时原子安排一次跟进，关闭时只保留候选并提示核对。模糊时间、重复事实和问题句不会猜测。最近 30 分钟只有一条未执行的自然跟进时可用明确改时或取消；已处理、多条或新时间过期会拒绝。候选、已安排与已发送的状态分开显示。

“发送一次测试问候”是明确手动动作，仍有许可与设备护栏，不自动开启后台，也不读取 L0–L3 或调用回答模型。`queued` 表示服务端接收，不证明扬声器已播放；亲耳听到后才可“确认已听到”，这是人工观察证据。习惯时段候选和离线门控不自动变成已启用策略；以版本选择、当前许可与事件账本为准。技术边界见 [运行流程](../architecture/workflows.md#主动交流与一次性跟进)。

## 实验中心

先选择已有冻结检索档案，再选择 Fake（本地规则模拟器，只验证流程）或已配置的真实模型，预检预算并明确确认后执行。结果按组/题查看，停止后续请求不会抹掉已完成结果。实验生成独立报告，不重新提取个人记忆，不覆盖旧报告；Fake 分数不代表记忆质量，真实模型和网路可用性另验。详见 [实验中心与复核](../deployment/experiment-console.md)。

如果只想离线查看报告，可在确认日常控制台未占用 8767 后，从项目根用已有环境启动只读报告入口：

```powershell
Set-Location 'D:\03-项目\01-正式项目\智慧圆屏'
uv run --no-sync python -m longmemory.entrypoints.api --port 8767
```

需运行合成实验才显式加 `--enable-experiment-runs`；需模型配置才显式选择 `--env-file local/config/.env` 或 `local/config/.env.deepseek.local`。这里没有 `--enable-chat`/日用库参数，不作为共享日常聊天启动命令。与面板不同时启动同一端口；终端长期服务保持窗口开启，停止用 `Ctrl+C`。完整历史命令见 [归档](../history/current-docs-before-20261014/docs/guides/使用说明.md)，仅供追溯，现行日用用面板。

## 我的数据保存在哪，怎样排障

| 内容 | 位置与边界 |
|---|---|
| 日用记忆 | 面板显式选择 `data/databases/` 内已有库；不自动建空库/迁移 |
| 会话与角色 | 对应旁库，和个人 L0–L3 各有职责 |
| 人工配置/偏好 | `local/config/`；不拿模板覆盖现有密钥或选择 |
| 参考声音 | `local/config/voices/`、`data/audio/voice-references/`，不入 Git |
| 实验 | `experiments/runs/`、`experiments/results/`、`experiments/jobs/`，各次独立 |
| 日志/状态 | `data/logs/`、`data/control/`，状态/服务回执不作播放证明 |

页面连接失败先核对控制台进程；模型失败查配置/网络/鉴权，设备离线查设备连接，TTS 不就绪查 18770 和预热。端口占用先确定所有权，不批量杀进程。停止/新聊天不删除记忆，重启后刷新页面建立新会话。缺依赖按锁文件与恢复指南由所有者安装，不删除锁、环境或库来碰运气。

本轮文档检查没有读写个人数据、启停日用服务、联网请求模型或操作设备；既有恢复结果见 [文字恢复](恢复文字与记忆-20261013.md)、[语音恢复](恢复语音-20261013.md)。历史源码、ADR 和测量保持原文，不以旧数字证明当前版本。
