# 学校模型与官方 DeepSeek 配置分流

## 目的

本项目在同一台电脑上保留两个互不覆盖的模型配置档：

| 配置文件 | 使用者与用途 | 网络 | 是否提交 Git |
| --- | --- | --- | --- |
| `.env` | 用户日常体验、校园网内手工验证、小智与圆屏 | 学校服务当前要求校园网，且可能使用 HTTP | 否 |
| `.env.deepseek.local` | 助手代执行的自动化或受控真实模型验证 | 官方 DeepSeek HTTPS API | 否 |

这是一种**配置隔离约定**，不是操作系统权限隔离。任何能够读取相应文件的本机进程，理论上都能读取其中的密钥。两个文件都被 `.gitignore` 排除，不应复制到日志、截图、Issue 或聊天中。

## 第一次填写官方密钥

打开项目根目录的 `.env.deepseek.local`，只填写这一项：

```dotenv
LONGMEMORY_LLM_API_KEY=你的官方_DeepSeek_API_Key
```

其余官方配置已经预填：

- API 根地址：`https://api.deepseek.com`
- 模型：`deepseek-v4-flash`
- 明文 HTTP：关闭

不要改动 `.env`；它继续保存学校模型配置。不要把真实密钥写入 `.env.example` 或任何受 Git 跟踪的文件。

## 你使用学校模型

日常统一启动仍双击根目录的 `Start.cmd`，它继续读取 `.env`。

需要在终端单独检查学校模型时，在项目根目录执行：

```powershell
uv run --locked --env-file .env python -m longmemory --provider openai_compatible --check-model
```

学校地址当前使用 HTTP，因此终端出现明文传输警告是预期行为；只在你已经接受风险的校园网环境使用。

日常控制台的聊天页会显示本次进程最近观察到的模型状态。设置中心的“模型与服务”页还会集中显示实际模型名、无凭据服务地址及 HTTP/HTTPS 状态；网页永远不显示 API Key。刚启动时是“尚未验证”，不会为了启动而自动发送请求；点击“检测模型连接”才会发送固定合成短句，且不读取、不写入个人记忆。失败会区分鉴权、部署地址不存在、网络、超时、限流、服务端故障和响应格式变化。状态只保存在当前进程，重启后重新变为“尚未验证”。

学校重新部署后，新地址、模型名或 Key 可能同时变化。拿到新配置后：

1. 更新项目根目录 `.env`，停止并重新启动控制台；仅刷新网页不会重载环境变量。
2. 如果还使用圆屏语音，再将同一份学校配置同步到 Xiaozhi 私有 YAML。两份配置不会自动互相覆盖：

```powershell
Set-Location "D:\02-项目\LongMemory-SmartRing"
uv run --offline --no-sync python scripts/development/xiaozhi/sync_model_config.py --project "D:\02-项目\LongMemory-SmartRing" --server "D:\ESP32-Workspace\xiaozhi-esp32-server\main\xiaozhi-server"
```

该命令读取本机 `.env`，修改前会给 Xiaozhi 私有配置创建备份，不输出 Key。同步完成后需要从启动面板重启圆屏语音服务。

## 助手使用官方 DeepSeek 做测试

助手代执行真实模型测试时，必须显式指定官方配置档：

```powershell
uv run --locked --env-file .env.deepseek.local python -m longmemory --provider openai_compatible --check-model
```

后续评估命令也遵循同一规则：把 `--env-file .env` 换成 `--env-file .env.deepseek.local`。命令必须显式选择配置档，不根据网络状态、密钥是否存在或当前时间自动猜测。

为避免误调用和意外费用，执行规则如下：

1. 第一次只做一次连接检查，失败后先读错误，不自动反复重试。
2. 真实评估先核对数据集、请求数量和模型，再开始调用。
3. 依赖安装、模型权重下载和仓库拉取仍由用户执行；这里的委托只扩展到官方 DeepSeek API 测试。
4. 测试报告可以记录供应商、模型和配置摘要，但不得记录 API Key。
5. 日常启动、小智服务和圆屏不读取 `.env.deepseek.local`，除非将来另行明确修改启动配置。

## 快速判断当前命令会用哪一个配置

- 命令含 `--env-file .env`：学校模型。
- 命令含 `--env-file .env.deepseek.local`：官方 DeepSeek。
- 命令没有 `--env-file`：不作为真实模型测试的规范命令，先停止并补全参数。

填写官方密钥后，只需告诉助手“官方配置已填写”；不要发送密钥本身。助手随后可以先运行一次连接检查，再按已说明的调用预算执行测试。
