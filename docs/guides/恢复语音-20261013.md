## 用户执行：全新取得资源

先停止当前统一启动器管理的服务。打开 PowerShell，先进入允许本次脚本执行的独立进程：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass
```

在该新进程执行下面完整的块。代理使用已登记的机器会话入口；`finally` 恢复该会话原值，任一阶段报错后不会继续下一阶段。命令中的项目根应替换为当前实际目录；本机为 `D:\03-项目\01-正式项目\智慧圆屏`。

```powershell
. 'D:\10-开发配置\网络与代理\开发代理.ps1'
Enable-DevProxy
Set-Location -LiteralPath 'D:\03-项目\01-正式项目\智慧圆屏'
try {
    & '.\scripts\development\restore_voice.ps1' -Stage Sources
    & '.\scripts\development\restore_voice.ps1' -Stage Environments
    & '.\scripts\development\restore_voice.ps1' -Stage Models
    & '.\scripts\development\restore_voice.ps1' -Stage Tools
} finally {
    Disable-DevProxy
}
```

Sources 下载固定小智、CosyVoice 与 Matcha，不覆盖已有不同提交。Environments 使用 uv 安装 Python 3.10.20，分别建立两套环境、安装固定包并执行 `uv pip check`；主项目环境不变。版本表位于 `scripts/development/voice_restore/`，不直接使用持续变化的上游 requirements.txt。

Models 下载正常推理所需 CosyVoice 权重、BlankEN 子模型及分词文件、SenseVoice 和四个 WeText FST，合计 6,377,386,285 字节，约 6.38 GB；不下载未使用的 RL、批量 tokenizer 和 ONNX 优化训练变体。Python 包、源码、下载包和展开工具占用另计。

Tools 全新下载约 112 MB 的 FFmpeg ZIP 和 Opus 包，校验后部署到表中位置；使用机器已登记的 7z 解码 Opus，不安装 conda、不修改全局 PATH。完整原包保留供核对许可证与来源。

下载清单 `voice_restore/assets.json` 固定长度、SHA-256 或官方 Git 文件摘要。WeText 没有已验证可直接使用的不可变下载 URL，使用官方 master 文件端点并强制校验历史 SHA-256；不能把同名更新当作原版本。其 HEAD 探测返回 403，随后 GET/Range 响应头检查为 206、长度符合清单；未读取或保存模型正文。实际资源下载仍由用户执行，遇到错误时保留文件并反馈。

脚本不自动重试。重新运行已经成功的阶段会检查既有内容；下载中断保留 `.part`，服务器接受 Range 时可续传。不接受续传、摘要不符或已有环境版本不对时保留文件并报错，反馈最后一段错误后再处理。
