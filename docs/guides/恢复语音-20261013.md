# 智慧圆屏：恢复原日用语音

更新：2026-10-14。当前源码已全新下载，小智 222 个包和 CosyVoice 159 个包的兼容检查通过；CosyVoice 的 torch 2.3.1+cu121、CUDA 12.1 已完成 RTX 4080 GPU 张量运算检查。CosyVoice 和 SenseVoice 的 22 个完整资源摘要通过，尚缺四个 WeText FST 与 FFmpeg/Opus；未加载语音模型或完成圆屏验收。

所有者要求外部源码、依赖、模型及工具全新取得。旧备份只用于识别固定版本、包版本表和文件摘要；不从备份部署源码、DLL、模型或虚拟环境。主仓库已有的适配器继续使用，私有模型档案与个人数据库保留。

本轮恢复原主链路：Silero 判停 → SenseVoice 听写 → LongMemory 混合召回 → 官方模型回答 → CosyVoice3 合成 → Opus → 圆屏。VoxCPM2、sanoTTS、AuK、豆包备用与固件重建不属于本轮必需资源。
