## 所有者现在怎么验收

使用现有日用圆屏模式与语音服务，不需要重新烧录、保持串口monitor或改声音/记忆设置。

| 操作 | 观察与反馈 |
|---|---|
| 核对整屏黑底 | Otto 模式外围白圈是否消失、主题重设后是否仍保持黑底、字幕和图标是否清楚 |
| 静止看约30–60秒 | 当前是否显示期望的Otto效果，动画是否持续自然；有无卡住、闪烁或裁切 |
| 正常发起一轮对话 | 聆听 → 思考 → 说话的表情是否对应、切换是否连续，声音是否正常 |
| 说话中插话 | 声音是否及时打断、表情是否切回聆听，下一句能否接收 |
| 连续聊两三轮 | 屏幕、麦克风、回答和声音是否稳定；有无重启、明显延迟或状态错位 |
| 自然问到已有记忆 | 原日用记忆是否在真实回答中保持；不以助手合成模型测试替代 |
| 核对原配置与壁纸 | 原偏好、壁纸和日常入口是否保持 |

主会话收集“正常/异常＋发生在哪个状态/切换”的反馈。默认应显示 Otto；若仍显示原壁纸，先反馈现象并检查资源回退或当前临时视图，不自动改NVS或壁纸。没有异常不代表未观察的项目都通过。
