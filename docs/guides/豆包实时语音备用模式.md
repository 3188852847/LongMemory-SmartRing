# 豆包实时语音备用模式

这个模式让豆包负责听、理解、回答和说话。原有 CosyVoice 模式保留，停止并重新
启动后可以切回。它是完整语音模式，不是“只把声音换成豆包”。

当前账号尚未开通：先提供配置和接入代码。离线测试不代表真实 API、网络或圆屏
听感已经验收。本版备用模式不读取、写入或使用个人长期记忆；网页记忆功能仍保持
原样。声线使用豆包提供的音色，与本地 CosyVoice 不同。

## 配置与切换

1. 重开根目录 `启动智慧圆屏.cmd`，选择“文字聊天＋圆屏语音”。
2. 在“圆屏与声音”选择“豆包实时语音（备用）”，打开豆包配置入口。
3. 尚未开通时可以先保存模式；缺少 Key 时启动会提示配置未完成，不会试连。
4. 开通后把专门的豆包语音 API Key 填在本机配置窗口。不要发到聊天或写进源码。
   需要的是“豆包语音 → 端到端实时语音 3.0 / 全双工”服务，普通文字模型 API
   并不能证明已具备语音权限。以[官方接入文档](https://www.volcengine.com/docs/6561/2549778)
   及其控制台入口为准。
5. 停止正在运行的服务，再启动。网页模型仍单独选择；豆包选项不会把网页模型
   自动改成豆包，也不会替你连接校园网。
6. 切回时停止服务，选择“现有语音链路”，再启动；原来的 TTS 与记忆选择继续使用。

本机配置文件为根目录 `.env.doubao.local`，被 Git 忽略。面板读取时不回显 Key；
保存后的状态只表示格式齐全，不证明服务权限、余额、网络或音色可用。
选择豆包并实际交谈后，圆屏采集的当次语音会发往豆包服务；本地桥不保存原始录音。
手动配置可参考根目录 [.env.doubao.example](../../.env.doubao.example)，其中空 Key
是占位，不能启动；也不需要再填写旧版的 App ID / Access Key 组合。

## 现在保留哪些能力

| 项目 | 豆包备用模式 |
|---|---|
| 圆屏采音与播放 | 使用现有 Opus 协议，经项目侧桥接 |
| 识别、回答与声音生成 | 豆包全双工服务 |
| 设备音量、亮度等控制 | 保留现有本机设备控制入口 |
| 本地 CosyVoice / FunASR | 不随备用模式加载 |
| LongMemory 长期记忆、记忆主动播报 | 本版不接入 |
| 网页文字聊天与记忆管理 | 沿用现有独立设置 |
| 自动改用云端 | 不启用，需主动选择 |

“本机语音进程运行”和“圆屏在线”都不证明豆包已鉴权成功。连接失败时先核对
语音服务权限和 Key，再检查网络；不会悄悄切回另一种声音，也不会自动重放上一段录音。

两个尚未通过实机验证的限制必须保留：圆屏的回声消除（AEC）与实时监听开启时，
才有边播边听的基础；如果豆包还没给出回答标识、你就开始第二次补充，当前桥会
结束连接，避免把无法分辨归属的旧回答播出来，需要重新唤醒。这种“还在想时继续
补充”的体验是开通后优先修验的项目，不能把本版当成自然打断已经全面完成。

队列满、音频格式错误或取消未确认也会结束当前连接，重新唤醒后再试。
首版只在内存保留有限待播音频，长回答的云端输出速度和网络抖动仍须实测。

## 开通后最小验收

使用不含个人信息的固定问题，例如“介绍一下春夏秋冬，每个季节说一句”。在同一
电脑、网络、圆屏和音量下，对现有模式和豆包模式各做 10 轮；两种模式都先做一次
预热，单独记录首次连接的额外等待。

| 指标 | 记录方法与候选目标（不是已测结果） |
|---|---|
| 停嘴到首声 | 用同一录音同时记录测试者停嘴与扬声器首声；中位数目标 ≤ 1.5 秒，P95 ≤ 2.5 秒 |
| 连续性 | 记录不属于自然标点停顿的最长静默；目标无词中突停、异常连续空档 ≤ 300 ms |
| 打断 | 回答中自然插话与按键停止各 5 次；目标扬声器停止 ≤ 500 ms，旧回答不再冒出 |
| 完整性 | 数字、中文、英文混合固定句，不丢开头、尾字或重复播放 |
| 声音质量 | 同一音色保持稳定，主观自然度至少 4/5，无明显变速、爆音或音高异常 |
| 多轮与恢复 | 连续 10 轮后，再测试待机、重新唤醒、正常停止；故障后明确提示且能重启 |
| GPU | 豆包模式没有新加载本地语音模型，单独记录其他常驻进程；不要把整机占用归给豆包 |

豆包不暴露本地三段式的“LLM 首字 / 每段 TTS RTF”同等内部时间，不能把云端
首块或转写完成当成停嘴到首声。记录可观测的转写结束、首个云音频、首个设备包，
同时保留扬声器实测。若仍不能满足目标，就切回现有模式，按实际差异决定是否继续。

架构边界和本阶段范围见 [ADR-0170](../adr/0170-doubao-realtime-fallback-mode.md)。
