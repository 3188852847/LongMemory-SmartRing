# TTS 测试台使用说明

## 用途

这个页面用于在同一台电脑、同一项目适配链上比较当前声音后端的等待时间与基础音频有效性。它不会读取或保存聊天、记忆、用户录音，也不能代替圆屏实机试听。

## 启动

在项目根目录双击 `Start.cmd`，选择包含控制台的启动方式。启动完成后进入：

```text
http://127.0.0.1:8767/settings?tab=voice
```

## 操作

1. 在“声音”页先核对当前实际后端与服务状态。
2. 在“TTS 测试台”选择一条固定文本：短回复、数字与时间、中英混合或陪伴语气。
3. 点击“运行一次测试”。运行期间按钮会锁定，不并行、不重试。
4. 查看“首个可用音频”和“本次完成”。当前后端若标为“完整音频缓冲”，二者相同是正常事实，表示完整音频回来之前无法开始播放。
5. WAV 后端还会显示时长、采样率和是否疑似近静音；这只是故障检查，不是自然度评分。
6. “网页朗读”用于听感，和计时测试是两次独立合成，不把试听等待冒充同一次测量。
7. 成功计时会写入 Git 忽略的 `data/control/tts-benchmark-history.json`。切换后端并重启后选择同一用例继续运行，页面最多保留最近 120 条跨启动指标；档案不保存音频、聊天、记忆或密钥。
8. “同条件探索性汇总”只把后端、固定用例和缓存策略都相同的记录放在一起，显示样本数、首音频中位数、完成中位数、实时率中位数和近静音次数。至少三次才标为“可初看”；不足三次只表示样本不足。

## 如何比较

- 切换声音后端后要按启动面板的生效说明重启，再使用相同测试文本。
- 每个后端至少人工运行三次。当前档案尚未单独标记冷启动与热启动，因此自动汇总会如实混合两者；正式判断前应人工识别第一次模型加载的冷启动结果。
- VoxCPM2 的日常对话保留重复句缓存，但测试台会显式绕过这层本地缓存；历史中的“提供器默认”和新测试的“绕过本地缓存”不会混在同一组。Edge 和 sanoTTS 当前保持提供器默认行为。
- 不要只看总耗时：日常对话最影响体感的是首个可用音频。
- 实时率 = 完成耗时 / 音频时长；小于 1 表示生成完整音频所需时间短于该音频的播放时长。它不是首句延迟，也不包含圆屏播放链路。
- 页面数字不包含浏览器真正开始播放、圆屏网络、Opus 编码、设备缓冲和扬声器出声时间。圆屏体验仍以分阶段日志和实机试听为准。

## 当前限制

- EdgeTTS、VoxCPM2 与 sanoTTS 的项目适配器目前都是完整音频缓冲。
- 页面保存并按同条件汇总本机测试历史，但不自动排名，也不评价音色自然度；少量非受控运行仍不能包装成正式性能实验。
- sanoTTS 已完成独立适配和本机固定句验证；上游源码/模型仍在项目外。CosyVoice 和 GPT-SoVITS 只有完成相同边界后才会出现在能力目录。

## 下一批候选与进入顺序（2026-09-12）

候选不能因为项目宣传“流式”或“克隆”就直接加入日常下拉框。依次完成“项目外独立环境 → 固定四句无缓存测试 → 人工听感 → TTS V2 适配 → 圆屏实机”五道门槛，上一道不合格即可停止投入。

每个新后端至少记录：固定源码版本、模型身份/许可证、显存峰值、冷/热启动、首个有效音频、完整耗时、音频时长、近静音检查、中文数字与中英混合表现、取消能力及圆屏实际出声。EdgeTTS 继续作为日常稳定对照；新增候选失败时不自动改用另一个后端掩盖结果。

### CosyVoice 独立试验

CosyVoice 使用项目外独立环境和权重，不加入主项目依赖。源码、依赖和模型准备完成后，先检查本地快照：

```powershell
$cosyPython = "D:\ESP32-Workspace\CosyVoice\.venv\Scripts\python.exe"
& $cosyPython "D:\02-项目\LongMemory-SmartRing\scripts\development\cosyvoice\trial.py" inspect
```

检查通过后关闭其他占用显存的模型服务，再运行一次固定四句流式试验：

```powershell
& $cosyPython "D:\02-项目\LongMemory-SmartRing\scripts\development\cosyvoice\trial.py" generate
```

结果保存到 Git 忽略的 `data/audio/cosyvoice-<随机编号>/`。其中包含四个 WAV 和一个 `report.json`；不会写入聊天、记忆、声音设置，也不会切换圆屏后端。只有独立结果通过人工试听和工程门槛后，才设计常驻服务与 TTS V2 适配。
