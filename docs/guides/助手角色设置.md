# 助手角色设置

## 怎么操作

1. 通过启动面板启动控制台，在原端口打开“设置中心 → 助手角色”（例如 `/settings`）。
2. 查看当前名称和保存版本；聊天页不再单独放置角色编辑按钮。
3. 如需常用调整，开启“结构化表达偏好”，填写希望使用的称呼，并选择回答长度、互动方式和表情频率。旧角色首次打开时保持关闭，不会自动改写。
4. 需要直接改角色文本时，展开“高级：编辑完整角色提示词”；也可选择 `plain_v1` 或 `elysia_v1` 填入预设草稿。选择预设本身不保存，并会关闭尚未保存的结构化偏好草稿。
5. 点击“保存并用于网页下一轮”。保存成功后，下一次开始处理的网页消息使用新版本，无需再次重启。
6. 要恢复预设，重新选择预设并保存即可。老版本保留，不删除聊天或记忆。要只取消结构化偏好，可关闭开关后保存，其他手写提示词保持不变。

正在生成的回答继续使用开始时的版本。旧会话的最近六轮仍可能影响表达风格，想清楚体验新角色可以新建会话。逐轮证据中的 `role`、`role_revision` 可核对实际版本；这里的生效指请求使用了对应配置，不保证模型完全遵循。

## 两端的区别

- 网页：保存后下一轮使用；Fake 只用于工程测试，不模拟人格表现。
- 圆屏：网页保存不自动同步。需使用下方单独的检查/确认按钮，之后重启小智；不会更换音色。
- 原版 `/chat` 也使用同一后端新角色，但旧页面配置文案需刷新；编辑入口只在 React 页面。

保存冲突或网络失败时，不要重复点击保存。先复制保留草稿，再点“重新读取”核对服务器最新版本；重新读取会替换编辑框草稿。

## 保存位置与隐私

设置保存在当前记忆库路径后追加 `.role.sqlite3` 的旁库。未保存时使用启动器选择的预设；已经保存后，保存版本优先，单改启动器预设不会覆盖它。

它不是个人记忆，称呼和表达偏好也不会被提取成 L3 用户画像或用户事实；但完整角色提示词会随后续网页模型请求发送到已配置模型服务。不要填写密钥或敏感个人资料。历史角色版本也保留在旁库，改掉当前文本不等于彻底删除历史文本。

当前限制：没有圆屏运行版本自动回执、角色历史列表、语音试听或图片上传；不改变记忆算法。自动测试只验证工程行为，校园模型表达质量由实际体验判断。

## 把角色同步给圆屏

1. 重开启动面板并启动控制台，确保新参数已经加载。打开 `/settings` → “助手角色”。
2. 先保存想使用的角色；同步使用保存版本，**不使用编辑框中的未保存草稿**。
3. 点击“检查小智配置”。检查不会改文件；需要小智目录和记忆库配置匹配。
4. 点击“确认同步已保存角色”，核对目标目录和版本后确认。原配置会备份到小智私有目录，只有 `prompt` 字段改变。
5. 看到“已写入配置并回读核对”后，在启动面板停止服务，再启动“文字＋圆屏”，重新唤醒圆屏聊一句。不要在生成回答时停止。

“配置匹配”只指磁盘文件，不代表正在运行的小智已加载。页面没有设备运行版本回执，因此仍显示运行未验证。已有会话缓存也可能延续旧风格，重启小智比只刷新网页可靠。

确认凭据有效两分钟且只能使用一次。超时、失败、其他页面改角色或配置变化后，先重新检查；不要边同步边手改配置或进行网络地址同步。

如果自行用终端启动控制台，需在原命令中增加：

```powershell
--xiaozhi-server "D:\LongMemory-local\runtime\xiaozhi-esp32-server\main\xiaozhi-server"
```

这是追加参数，不是单独执行的命令；通过启动面板操作不需要输入它。

受管实例备份文件名为 `xiaozhi.yaml.role-随机标识.bak`，位于项目 `local/archive/config-backups/`；显式其他小智实例仍保存在其 `data` 私有目录；其中包含原有密钥，请勿上传。恢复旧人格优先载入预设、保存并再次同步；不要随意恢复整份备份，以免回退后来修改的 IP 等配置。
