# 助手角色设置

## 怎么操作

1. 通过启动面板重启控制台，在原端口打开 `/chat-react`。
2. 点击左侧“助手角色设置”。查看当前名称和保存版本。
3. 修改名称和提示词；也可选择 `plain_v1` 或 `elysia_v1` 填入预设草稿。选择预设本身不保存。
4. 点击“保存并用于网页下一轮”。保存成功后，下一次开始处理的网页消息使用新版本，无需再次重启。
5. 要恢复预设，重新选择预设并保存即可。老版本保留，不删除聊天或记忆。

正在生成的回答继续使用开始时的版本。旧会话的最近六轮仍可能影响表达风格，想清楚体验新角色可以新建会话。逐轮证据中的 `role`、`role_revision` 可核对实际版本；这里的生效指请求使用了对应配置，不保证模型完全遵循。

## 两端的区别

- 网页：保存后下一轮使用；Fake 只用于工程测试，不模拟人格表现。
- 圆屏：尚未同步，继续使用小智已有配置。此按钮不会修改小智文件、重启小智或更换音色。
- 原版 `/chat` 也使用同一后端新角色，但旧页面配置文案需刷新；编辑入口只在 React 页面。

保存冲突或网络失败时，不要重复点击保存。先复制保留草稿，再点“重新读取”核对服务器最新版本；重新读取会替换编辑框草稿。

## 保存位置与隐私

设置保存在当前记忆库路径后追加 `.role.sqlite3` 的旁库。未保存时使用启动器选择的预设；已经保存后，保存版本优先，单改启动器预设不会覆盖它。

它不是个人记忆，提示词不会被提取成用户事实；但角色提示词会随后续网页模型请求发送到已配置模型服务。不要填写密钥或敏感个人资料。历史角色版本也保留在旁库，改掉当前文本不等于彻底删除历史文本。

当前限制：没有圆屏同步、角色历史列表、语音试听或图片上传；不改变记忆算法。自动测试只验证工程行为，校园模型表达质量由实际体验判断。
