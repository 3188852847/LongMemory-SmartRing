# 参考声音与克隆

当前沿用已恢复的 CosyVoice3 模型与独立环境，不需要新增模型、训练或安装依赖。首次升级须在启动面板停止并重新启动服务；旧服务不支持新声音档案时，页面会明确提示，不能把旧声线试听当成克隆成功。

## 操作

1. 打开网页“助手设置 → 声音与克隆”，核对声音服务状态。
2. 在参考录音区域选择 PCM16 WAV，填写名称及录音中的准确原文，再明确上传。支持 3–30 秒、16–48 kHz、单/双声道，最大 4 MiB，最多 32 份录音。使用本人或已获授权的声音。
3. 上传只加入本机参考库，不自动选择或改变日用声音。在“参考声线”中选择录音。
4. 表达指令可留空，或尝试温柔、开心等语气。参考录音主导音色；文字指令不能保证生成任意声线或准确复现全部风格。
5. 点击“试听草稿”，使用固定测试文本合成。试听不保存档案，也不写入个人记忆。
6. 听感合适后点击“保存日用声线”。新版声音服务的下一次合成读取同一份档案；已经开始生成的片段保持开始时的声线。页面若提示需重新启动，则保存尚未在旧进程生效。

“恢复原日用声线”只修改草稿，需要明确保存才生效。设置冲突保留草稿并要求重新读取，不自动重试覆盖另一页面。

## 存储与语义

- 声音档案：`local/config/voices/CosyVoice3.json`。
- 参考录音与元数据：`data/audio/voice-references/`，使用内部 ID 与摘要；浏览器不指定本机路径。
- 模板：`config/examples/CosyVoice3.json`，无参考音频或个人原文。
- 旧 TTS 后端在高级兼容区；界面精简没有删除引擎、模型和历史记录。
- 助手表达仍控制回答方式，声音档案控制合成，二者独立。圆屏角色提示词同步继续明确预检与确认，不自动覆盖。

自定义声线启用时，原声线的预生成寒暄与等待音频暂不使用，避免同一轮混入旧声音。默认声线的原快路径保留。声线、原文和风格共同决定提示缓存身份，并限制常驻缓存数量。

当前合成测试和接口测试验证文件、配置、缓存与调用边界；音色相似度、语气遵循、真实延迟及圆屏播放仍须实际试听验证，不能由测试通过推断。
