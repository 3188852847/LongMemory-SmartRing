# 圆屏记忆后端切换

更新：2026-09-08。该功能切换电脑端 Xiaozhi 服务使用的记忆算法，不修改或
重新烧录 SmartRing-Plus 圆屏固件。

## 原来的圆屏怎样记住对话

圆屏只把语音发给 Xiaozhi，并显示、播放返回内容。Xiaozhi 在一条设备连接中
保存当前对话列表，回答时会把这段短期上下文交给模型；连接结束后，这段列表
不会自动成为可审计的长期记忆。

本机 Xiaozhi 快照默认是 `nomem`，即没有跨会话长期记忆。它另带一个可选的
`mem_local_short`：断开连接时在后台用 LLM 把“本轮完整对话＋上一份摘要”压缩
为每台设备一份 JSON，写到 Xiaozhi 私有目录 `data/.memory.yaml`；后续每次问题
都注入整份摘要。它没有 LongMemory 的 L0/L1/L2/L3、逐条来源、检索排名、
SUPERSEDE 纠错链或管理页。

因此，“原来的记忆”有两个不同含义：原厂默认是**无长期记忆**；小智自带但
默认未启用的轻量能力是**本地摘要记忆**。

## 三种选项

| 页面名称 | 实际提供器 | 跨会话 | 适合用途 |
|---|---|---:|---|
| LongMemory（当前系统） | `LongMemory` | 是 | 日常使用、来源追踪、分层记忆和纠错 |
| 小智本地摘要 | `mem_local_short` | 是 | 体验小智自带轻量方案、做非正式对照 |
| 无长期记忆（速度基线） | `nomem` | 否 | 判断长期记忆阶段增加了多少延迟 |

三者仍使用相同圆屏、ASR、回答模型、助手角色和 TTS。各自数据完全隔离；切换
不会把 LongMemory 事实复制进小智摘要，也不会删除旧数据。

## 操作步骤

1. 双击项目根目录 `启动智慧圆屏.cmd`，先按日常方式启动服务。
2. 打开控制台“设置中心 → 记忆后端”。
3. 在“下次圆屏启动”选择一种后端并点击“保存选择”。
4. 页面显示“需要重新启动”时，回到启动面板点击“停止服务”。
5. 再点“启动并打开控制台”。启动器会先确认 8000/8003 空闲，再备份并同步
   Xiaozhi 私有配置；它不会改记忆数据库。
6. 回到“设置中心 → 记忆后端”，核对“本次运行”和“小智磁盘配置”。
7. 唤醒圆屏开始新连接。切换到“小智本地摘要”后，至少完成一轮对话并让连接
   正常结束，摘要才有机会在后台保存；立即切换或强制结束进程可能来不及写入。

启动面板的高级设置也有“圆屏记忆后端”下拉框，适合在启动前直接选择。网页
设置和启动面板写入同一个下次启动指针。

## 怎样比较速度

先选 `none`，再选 `xiaozhi_local`，最后选 `longmemory`；每次重启后用同一句
问题，保持模型、角色、TTS 与网络不变。小智日志会出现：

```text
记忆查询后端=nomem 耗时=...ms
记忆查询后端=mem_local_short 耗时=...ms
记忆查询后端=LongMemory 耗时=...ms
```

断开连接后还可能出现“记忆保存后端”的耗时。日志不包含问题或记忆正文。
比较时同时看现有的首句分阶段日志：如果记忆很快但整体仍慢，瓶颈更可能在
ASR、回答模型或 TTS。一次体感只能用于排查，不能作为论文结论。

## 限制与恢复

- 当前不支持运行中热切换；半轮对话跨后端会破坏解释性。
- 当前网页文字聊天固定使用 LongMemory；此开关只控制圆屏 Xiaozhi 链路。
- 小智摘要依赖回答 LLM，在连接关闭时生成；模型不可用时可能保存失败。
- `none` 仍保留当前连接内短期上下文，所以它不是“每句话都失忆”。
- 要恢复日常配置，选择“LongMemory（当前系统）”、保存、停止并重新启动即可。
- 未来论文方法会按受控注册表加入；不能直接在页面输入仓库地址或 Python 类名。
