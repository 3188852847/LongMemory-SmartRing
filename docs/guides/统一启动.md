# 统一启动：不用自己开两个终端

更新：2026-09-14。P1 的日常启动入口；页面已按日常启动、模型与记忆、圆屏与声音、本机维护四类任务分层。

2026-10-14 入口整理：根目录唯一用户入口为 `启动智慧圆屏.cmd`；原 `Start.cmd` 已移至 `scripts/development/launcher/Start.cmd`，由中文入口调用，启动行为保持原样。

## 第一次使用

1. 如果之前手动启动过控制台或小智，先在对应终端按 `Ctrl+C` 停止。启动器不会接管或关闭这些外部进程。
2. 在资源管理器中打开项目根目录，双击 **`启动智慧圆屏.cmd`**。出现“智慧圆屏 · 日常启动”面板；不要求管理员权限。
   窗口较小或系统显示缩放较高时，使用页签右侧的纵向滚动条或鼠标滚轮查看底部内容；滚轮只滚动当前页签，不会改变下拉框选项。
3. 在“日常启动”选择“文字聊天”或“文字聊天＋圆屏语音”；模式区会直接显示“当前选择”。再选择启动后打开系统总览、聊天、设备状态、记忆管理或设置中心。这里只接受五个本机页面，不能填写网址；选择会在下次沿用。模型与召回、圆屏声音、路径与网络分别进入同名页签；“本次配置”会按网页、圆屏和实验边界分行显示实际选择，不要求理解内部枚举。
4. 核对日常数据库。默认沿用 `data/databases/xiaozhi-demo-v1.db`；必须是已有文件，不要填一个新名字期待自动建库。
5. 语音模式额外核对小智目录与电脑局域网 IP。面板自动发现本机 RFC1918 地址；唯一地址自动选中，多网卡需要选择。点击启动后，面板先确认 8767/8000/8003/8766 等监听位没有被外部服务占用，再检查网络配置；不一致时自动在原私有目录保留备份并只同步固定网络字段。防火墙和圆屏 OTA 地址不会自动修改。“同步小智地址”按钮继续作为单独排障入口。
6. 网页角色选择“爱莉希雅风格”或“普通助手”。面板保存和启动时仍使用兼容的内部角色标识；这个设置不改变小智自己的角色。
7. 圆屏模式可选择 `EdgeTTS（联网标准音色）`、`VoxCPM2（本地 plain）`、`sanoTTS（本地中文小雅）`或 `CosyVoice3（本地高质量）`。点击启动就是本次明确选择：端口预检通过后，面板会检查并备份同步 TTS 固定字段，不再要求额外弹窗确认。“检查并同步”保留为排障工具。本地后端都由面板一起启动和停止；sanoTTS 与 CosyVoice3 分别需要核对项目外固定源码、环境和模型目录。
8. 选择“圆屏记忆后端”。日常使用选 LongMemory；“小智本地摘要”在连接结束时调用 LLM 更新一份摘要；“无长期记忆”只保留当前连接上下文。三者不共享或迁移数据，切换只在停止并重新启动后生效。也可在“设置中心 → 记忆后端”保存下次选择，详见[圆屏记忆后端切换](圆屏记忆后端切换.md)。
9. 选择长期记忆提取策略。`规则提取（基础/对照）` 用于稳定基线与实验对照；`模型辅助提取（日常推荐）` 更适合自然陈述，会增加一次模型候选请求。它先保存 L0，提取失败时仍可回答并在 React 页面提示 L1 失败，不会暗中切回规则。该选项只在圆屏后端为 LongMemory 时影响圆屏记忆。
10. 选择长期记忆召回策略。`关键词召回（基础/对照）` 用于稳定基线与实验对照；`关键词＋BGE 混合召回（日常推荐）` 使用本地固定模型快照，在 CPU 内存中融合关键词与语义排名。它不联网下载模型、不改数据库；BGE 失败会显式回退关键词。语义相似不等于事实可信，也不保证未知问题零召回。该选项只在圆屏后端为 LongMemory 时影响圆屏记忆。
11. 当前本机单用户启动面板的“L1 单条删除权限”状态按钮默认显示“已允许”，仍可在“模型与记忆”中点击改为“未允许”。删除时记忆详情仍会确认；它保留 L0 原话、备份和日志，不等于彻底遗忘。命令行和服务端默认仍关闭；非本机、多用户或正式发布前必须恢复面板的安全默认。
12. 若启动后打开“系统总览”，最上方“受管服务”会分别显示网页控制台、小智语音和本次选择的本地 TTS；没有选择本地 TTS 时对应项不会冒充运行。这里的“进程运行中”只说明启动面板仍拥有该进程；圆屏是否连入看设备卡片，模型是否可用看模型卡片。手动从终端启动控制台时显示“非启动面板模式”是正常现象。
13. “低频自动整理”的状态按钮默认显示“已关闭”。点击为“已开启”后，只有产生新 L1 才向唯一后台线程发送信号；它按门槛和每日预算依次尝试 L1→L2、L2→L3，并为非 NOOP 候选额外调用一次独立风险复核。聊天不等待整理，但会增加模型请求并可能自动接受低风险 L2/L3；建议先在合成库验收，控制台场景/画像页可查看运行原因与账本结果。
14. “L2 证据旁路质检”的状态按钮也默认显示“已关闭”。点击为“已开启”后，每个检索到 L2 候选的用户问题最多增加一次后台模型请求，把“哪些候选真正支持回答”写入审计账本；正式回答仍使用原策略，不会被旁路结果拦截或重写。启动后在“记忆质量”页打开记录，核对候选后可将整轮判断标为正确、错误或暂不确定；这只追加人工审计事件。需要控制调用量时保持关闭。
15. “L1 证据旁路质检”的状态按钮同样默认显示“已关闭”。它在正式 L1 刚召回后冻结候选，只判断候选是否包含回答所需信息，不读取随后加入的 L2/L3。点击为“已开启”后，每个存在 L1 候选的普通问题最多增加一次后台模型请求；无候选不请求。结果在“记忆质量”页的独立 L1 卡片中查看和人工复核，不过滤、降权或重排正式 L1。
16. 圆屏选择 LongMemory 时，面板会给控制台和小智注入同一个临时 Runtime 身份。无需填写令牌：它只存在于本次受管进程环境中。网页和圆屏共用同一个记忆引擎、提取/召回策略与数据库，但短期聊天记录仍各自独立。选择其他后端时，网页仍使用 LongMemory，圆屏改用所选后端。
17. 首次使用时阅读明文 HTTP 风险提示，点击“待确认”使其变为“已了解”，然后点“启动并打开控制台”。当前学校接口只建议用于已确认风险的非敏感体验。
18. 控制台实例就绪后自动打开 React 版 `http://127.0.0.1:8767/chat-react`；之后可用“重新打开网页”再次进入。原版 `/chat` 保留回退。运行区分别显示网页控制台、小智语音、声音服务和网页入口；“小智进程运行”不等于圆屏已经连接，后者仍到设备页确认。VoxCPM2 模式还需等待声音服务显示就绪。

校园模型由你连接校园网后实际聊天验证。启动不测试模型，不把“控制台已就绪”当作“模型可用”。语音进程运行不等于圆屏在线，可在网页设备页核对；待机可能无活动连接。

启动完成后，在 React 聊天页点击“声音设置”可以只读核对当前后端。本地模式应显示对应后端、固定音色、配置匹配且服务已就绪；这仍不代替圆屏实际播放与听感验收。切换后端继续使用启动面板，不在网页里暗中改配置。

## 怎样停止、重新启动

- 保留启动面板，关闭浏览器不会停止服务。
- 结束聊天后点击“停止服务”，会直接结束本面板创建的整棵进程树，包括 uv 和小智后代进程；关闭仍在运行的整个面板时才会再次确认。
- **这是进程终止，不是等待所有聊天请求优雅完成。** 正在生成的回答/音频会中断，当前轮可能已写入用户消息或记忆，不能直接认定没有发生写入。
- 关闭启动面板会询问并停止受管服务。异常退出时 Windows Job 也会清理其子进程；不删除数据库。
- 停止后可修改模式再启动。Windows 可能短暂尚未释放端口，提示占用时稍候再试，不要批量杀 Python。
- 若 8000/8003/8766 或所选本地声音的 18768–18770 持续被先前排障、独立试听或异常退出留下的服务占用，点击底部“清理遗留服务”。Xiaozhi 仍须满足三端口同属一个 Python；本地声音还须通过固定 `/health` 提供器身份、端口 PID 前后不变和 Python/Node 类型核验。它只处理当前所选声音，不批量结束其他 Python/Node，也不关闭 8767 控制台或 8768 壁纸服务。显示拒绝或状态未知时不要连续点击，应人工核对占用者。
- 模式、页面、角色、提取/召回、模型、圆屏记忆后端、声音和拾音等有限选择会在选中时立即原子保存；路径与 IP 在成功启动或显式同步后保存。相关非敏感首选项位于 Git 忽略的 `data/control/`。API Key、令牌、对话和 L1 删除权限不会写入；运行中的服务不会热切换，也没有开机自启、托盘常驻或跨面板接管。

### 本机受限控制接口

新版面板复用单实例端口 `127.0.0.1:18767`，允许本机自动化查询状态，并执行与面板按钮相同的启动或停止。启动仍使用面板当前可见选择和原有检查；停止仍结束本面板拥有的 Windows Job 进程树，也会中断正在生成的回答或音频。

```powershell
.\.venv\Scripts\python.exe scripts\development\launcher\control.py status
.\.venv\Scripts\python.exe scripts\development\launcher\control.py start
.\.venv\Scripts\python.exe scripts\development\launcher\control.py stop
```

面板每次打开都会生成新的随机令牌，保存在 Git 忽略的 `data/control/launcher-control.json`，客户端读取但不显示令牌。`status` 同时返回当前面板所选的模型、提取、召回、圆屏记忆后端、声音和拾音档位等非敏感枚举，不返回本机路径。接口只接受 `status`、`start`、`stop`，不开放配置修改、遗留进程清理、防火墙、数据库、固件烧录、网址、路径或任意命令。更新到此版本后，应关闭旧面板并重新打开一次。设计边界见 [ADR-0158](../adr/0158-authenticated-local-launcher-control.md)。

## 默认没有开启的功能

- 命令行和服务端的 L1 单条删除默认关闭；当前本机启动面板作为单用户便利例外默认开启，但网页仍需每条确认。
- 新实验作业（仍可看报告，运行实验请用原终端指南）。
- 自动切换语义检索或历史 L0 自动重处理、声音克隆/训练、主动交流。混合召回只能由面板显式选择。
- 未经一次“启动圆屏语音”意图的后台配置同步、数据库迁移。点击启动后只在端口空闲时备份同步所选网络、TTS、模型和记忆后端；网页会话列表恢复已支持，见[聊天会话](聊天会话.md)。

当前核对语音模式下 LongMemory 的数据库、项目、解释器路径与本面板一致，并同步明确选择的圆屏模型、TTS 和记忆后端；不自动同步网页角色到小智角色。

## 电脑 IP 变化后的操作

### 推荐：面板操作，不需要终端

点击主面板“网络与防火墙”。圆屏已能正常聊天时无需添加规则。

1. “检查监听与规则”只检查电脑侧；规则不存在不等于连接被拦截，可能已有其他规则放行。权限不足显示未知。
2. 确需放行时，先启动小智，再填写圆屏单个 IP（优先）或已确认来源网段，例如此前的 `192.168.120.0/21`，点击“添加圆屏放行规则”。来源不默认填写，避免猜测范围。
3. 确认范围后，在 Windows 管理员授权窗口同意。只有规则助手提权，整个启动面板不提权。取消会明确提示未确认修改。
4. 操作结束重新检查。已有规则不覆盖；地址不匹配时，核对后点击“撤销本项目规则”，再按新地址添加。撤销可能影响圆屏连接，但不影响其他应用规则。
5. 监听正常/规则存在不代表圆屏已连上，仍到控制台设备页确认。

下方终端命令仅作为排障备用，并非日常必做步骤。

1. 停止旧服务，关闭旧启动面板，重新双击 `启动智慧圆屏.cmd` 加载新版。
2. 点击“刷新地址”，选择圆屏能访问的有线网卡地址。普通启动会在端口空闲后自动同步；只有单独排障时才需要点击“同步小智地址”。
3. 选择圆屏语音，并把风险确认状态切换为“已了解”，然后点击启动；面板不会强制停止外部小智，检测到端口占用会直接拒绝。
4. 若项目防火墙规则不存在，在**管理员 PowerShell**执行（下例为 2026-09-04 已核实地址；之后变化请替换）：

```powershell
& "D:\02-项目\LongMemory-SmartRing\scripts\development\xiaozhi\firewall.ps1" -Action Allow -ListenAddress 192.168.124.93 -RemoteSubnet "192.168.120.0/21"
```

规则只开放小智实际监听程序的 8000/8003，限定当前地址和原校园来源网段。提示规则已存在时，不要重复新增；先检查旧规则，再按原指南显式撤销并重建。不要关闭系统防火墙。

5. 在圆屏配网页把 OTA 地址改为 `http://192.168.124.93:8003/xiaozhi/ota/`，保留原 Wi-Fi 信息并保存；不重新烧录、不清空记忆库。进入配网页方式沿用当前厂商 B_V2 固件说明，不假定所有固件按键相同。
6. 唤醒圆屏，在控制台设备页确认在线，再进行一句合成对话。电脑侧配置同步成功不等于圆屏已重连。

已定位故障：旧地址 `.45` 已不在本机网卡上，绑定失败；当前为 `.93`。新版区分 IP 不存在、端口占用及系统拒绝绑定，不再统一归因为“旧服务”。备份含原配置凭据，不要上传或分享。

## 常见问题

### 更新代码后语音仍走旧的逐轮子进程

项目模板不会静默覆盖小智目录中的代码副本。停止服务后，在项目根目录执行一次：

```powershell
& "D:\LongMemory-local\runtime\xiaozhi-esp32-server\main\xiaozhi-server\.venv\Scripts\python.exe" `
  "D:\02-项目\LongMemory-SmartRing\scripts\development\xiaozhi\setup.py" update-memory
```

该操作只会把已知的旧版 LongMemory 提供器升级为仓库版本；不会修改 `.config.yaml`、数据库、角色、声音或固件。检测到陌生/手改内容时会拒绝覆盖。升级后重新打开启动面板并启动服务。

若手动绕过面板运行 `setup.py start`，适配器会继续使用旧 `subprocess` 回退。这种模式没有共享常驻 Runtime，只用于排障和兼容。

2026-09-04 已修复：`console（退出码 2）` 的一次实际原因是 uv 对反斜杠/空格绝对 `.env` 参数的解析，导致环境文件找不到。新版在明确项目工作目录中使用相对 `.env`；更新代码后必须关闭旧面板并重新打开。退出码 2 也可能来自其他参数/配置错误，不能一概归因。小智未启动时运行防火墙 Allow 会提示无监听，应先解决启动错误。

| 提示或现象 | 处理方式 |
|---|---|
| 面板已打开 / 18767 被占用 | 找原启动面板；18767 同时承担本机单实例锁和受令牌保护的 `status/start/stop`，仍不修改防火墙或接管未知进程 |
| 8767 无法绑定 | 停止之前手动启动的控制台；不自动改端口或接管未知服务 |
| 8000 / 8003 / 8766 不可绑定 | 若是本项目小智遗留进程，点底部“清理遗留服务”；不符合三端口共同归属时会拒绝，需人工核对；不是重新烧录的理由 |
| 18768 / 18769 / 18770 不可绑定 | 先确认面板选择的是对应本地声音，再点“清理遗留服务”；按钮只在健康身份、监听 PID 和进程类型都吻合时停止它 |
| 缺少 `.env`、数据库、uv 或 Python | 按原使用说明准备已有环境；本工具不安装、不自动建库 |
| `console` 退出 | 常见为已有库版本、依赖、模型配置或角色资源无效；按原指南在终端启动查看脱敏提示 |
| 选择 BGE 后 `console` 退出 | 检查 `semantic` 可选依赖是否已安装、快照目录是否仍完整；启动器离线运行，不会替你下载或修复模型 |
| `voice` 退出码 3 | 私有配置、数据库/项目/解释器路径或 LongMemory 提供器版本校验失败；启动器只自动升级精确列入清单的已发布旧版，陌生/手改文件仍拒绝覆盖 |
| `voice` 退出码 4 | 当前选择的本地 TTS 在 90 秒内未就绪；面板会按 VoxCPM2、sanoTTS 或 CosyVoice3 显示对应环境与 18768、18769 或 18770 端口，不要按旧文案检查错误后端 |
| `voxcpm2` 退出 | 固定权重校验、CUDA、模型加载或本机端口失败；不会自动退回 Edge，需明确切回后重启 |
| 18768 提示占用 | 新版只在存在真实监听者时拦截；旧版可能把刚停止后的 `TIME_WAIT` 误判为占用，请关闭旧面板并重新打开最新版 |
| `voice` 其他退出码 | 检查原小智启动命令和 `check-config` 的本地检查；可能缺模型文件、FFmpeg、提供器或端口冲突 |
| 控制台 90 秒未就绪 | 面板停止受管服务；按原指南核对，不继续反复拉起进程 |
| 网页开了但回答失败 | 模型/网络尚未通过验证，控制台启动成功不代表校园模型可达 |
| 双击没有窗口 | 先确认 `.venv/Scripts/pythonw.exe` 存在；必要时用下面命令查看面板自身错误 |

仅在排障时，在项目根目录 PowerShell 执行：

```powershell
Set-Location "D:\02-项目\LongMemory-SmartRing"
.\.venv\Scripts\python.exe scripts/development/launcher/app.py
```
