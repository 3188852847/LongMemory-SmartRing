# 统一启动：日常入口与停止

更新：2026-10-14。根目录唯一日常入口为 `启动智慧圆屏.cmd`，内部实现是 `scripts/development/launcher/Start.cmd` → `web_app.py`。完整界面说明见 [React 启动面板](React启动面板.md)，业务操作见 [使用说明](使用说明.md)。

## 第一次使用

1. 在 `D:\03-项目\01-正式项目\智慧圆屏` 双击中文入口。只打开面板，不自动开启陪伴。
2. 已安装 Edge 时使用独立应用窗口；失败则回退默认浏览器。聊天控制台继续是普通网页。
3. 选择文字聊天或圆屏陪伴，点击“开启陪伴”。核对各项服务状态，再进入陪伴空间。
4. “就绪”是本机服务检查；设备是否在线、模型账号是否可用、实际声音如何须分别核对。

保留的日用偏好是圆屏、CosyVoice3、官方模型和混合召回；实际以面板本次显示的选择为准。三套 Python、模型与配置已恢复，不需要每次安装或激活环境。若缺构建资源，先核对 `web/react-chat/dist`，由所有者按锁定环境执行构建/依赖步骤，不让启动器自动下载。

## 怎样停止、重新启动

- 关闭应用窗口或网页保留服务；再次双击入口重新打开同一面板。
- “停止服务”停止本启动器拥有的进程树；“停止服务并退出面板”还退出回环控制主机，均需明确确认。
- 改启动选项先停止，再打开“启动设置”，保存并重新开启；停止可能中断正在进行的回答，先结束聊天或实验后续请求。
- 面板不会接管/终止外部终端进程。切换旧 Tk 时，先在旧面板停止并退出，再开中文入口。

## 配置和生效范围

私有配置及共享偏好在 `local/config/`；小智人工 YAML 是 `local/config/xiaozhi.yaml`，厂家 `data/.config.yaml` 只作消费副本，不直接编辑。模型/后端/小智角色等磁盘配置的回执不等于运行中进程已热更新，按页面提示停止重启。CosyVoice3 新声音档案保存后由支持档案的服务在下一次合成读取，详见 [声音设置](声音设置.md)。

网页角色和圆屏角色独立，圆屏同步必须预检并明确确认；更改音色不更改回答角色。文字模式暂停圆屏定时联系；圆屏模式按既有主动交流设置和账本执行。低频整理和 L1/L2 影子复核保持关闭，不为验证界面自动打开。

## 本机受限控制接口

React 主机使用独立回环 HTTP 端口，启动器控制单实例端口是 18767，两者不同。浏览器会话令牌只留内存；固定 API 支持状态、白名单设置与 `start/stop/open_console/shutdown`，动作由控制器工作线程串行执行，不接受任意命令。旧本机控制客户端仍使用 18767 的令牌通道，不因此获得 HTTP 设置权限。详见 [启动器契约](../development/launcher-contract.md)。

`data/control/launcher-status.json` 是最小状态快照，不是控制令牌；`launcher-control.json` 和 `launcher-web.json` 用于本机发现，不分享、不提交。请求已接收仍需等待状态完成，服务已发送不代表设备已播放。

## 电脑 IP 变化后的操作

先只读核对本机 IPv4 和圆屏连接；不要照抄历史 IP，不新增宽泛规则。当前连接可用时不用调整防火墙。

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Select-Object InterfaceAlias, IPAddress
```

React 日常面板不提供旧 Tk 的网络/防火墙管理页。确需排障时按 [React 回退步骤](React启动面板.md#构建与回退)停止并退出当前面板，再使用旧兼容入口检查地址、同步小智三个网络字段和备份。添加/撤销窄范围项目防火墙规则需明确来源与 UAC 授权；只读监听/规则检查不证明设备已连接。服务切换和实机网络修改由所有者/协调会话统一安排，B 文档任务未执行这些操作。

## 常见问题

| 现象 | 下一项检查 |
|---|---|
| 无窗口或提示构建缺失 | `.venv/Scripts/pythonw.exe`、`web/react-chat/dist/launcher.html`；不安装新运行时 |
| 已有面板 / 18767 占用 | 使用已有面板，核对未知占用；不批量杀 Python |
| 8767、8000、8003、8766 占用 | 核对进程所有权和已有终端，停止自己的服务；不接管未知服务 |
| CosyVoice3 / 18770 不就绪 | 独立环境、固定模型、预热与健康状态；不自动切回其他 TTS |
| 服务 ready 但不能回答 | 分别查模型连接、圆屏连接和声音服务，ready 不证明这些可用 |
| 保存设置冲突 | 保留草稿、重新读取当前修订，不自动覆盖另一页面 |
| 更新后仍是旧行为 | 停止并退出旧代码进程，再重开入口，不只刷新页面 |

仅在项目根排查面板自身错误时，可用控制台 Python 运行 `scripts/development/launcher/web_app.py`。旧 Tk 回退为 `scripts/development/launcher/app.py`，不是日常主入口。历史“清理遗留服务”、页签、关闭 Tk 窗口的语义见 [整理前全文](../history/current-docs-before-20261014/docs/guides/统一启动.md)，不作为新面板步骤。
