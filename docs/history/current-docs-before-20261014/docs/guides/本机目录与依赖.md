# 本机目录与依赖

更新：2026-10-06。所有者选择“集中项目专属依赖，保留共用开发工具；第一轮只归档、不删除”。

随后所有者进一步明确：**主仓库保留当前位置，只集中圆屏相关外部文件**。
因此第二轮将 ESP-IDF 框架、FFmpeg 和两处早期 ESP32 示例也纳入同一总目录。
随后按所有者“不需要旧位置的兼容联接”的决定，更新当前入口并移除全部 9 个旧路径联接。

两轮已逐项整理 18 个目录、289,517 个文件，文件逻辑长度合计约 64.42 GiB。
其中第一轮 14 个目录约 62.73 GiB，第二轮 4 个目录约 1.68 GiB。
这个数字不是释放空间，也不是去重后的磁盘占用；没有删除、重新下载或重装依赖。
前两轮只移动文件；最后的路径收尾更新了启动脚本、环境命令入口和路径配置，重新构建了固件。
个人数据库、密钥内容与固件源码没有改写，也没有烧录设备。

## 后续文件放置规则

新增项目专属源码、独立环境和模型先在上述集中目录确定归属，不再散放 D 盘根目录。
长期保留的原始测量应放在项目已有实验产物目录，并保留脱敏报告引用；测试临时目录只放可再生夹具。
环境继续按项目依赖隔离，不把不同 Python / CUDA 版本合并进一个环境，也不移动其他项目共用工具。

临时缓存内容删除、AuK 权重删除和权限修复不属于本次执行范围；撤销兼容联接按后续明确指示已完成。
