# V0.1 版本记录

- 状态：开发中
- 当前阶段：首个确定性纵向闭环已实现，正在补齐 V0.1 管理、日志和评估能力

## 已验证

- L0 原始用户消息和 L1 原子记忆具有稳定 ID、时间及来源关系。
- SQLite 能在应用关闭并重新创建后恢复消息和记忆。
- 简单第一人称陈述可以由确定性规则规范化为 L1 记忆。
- 基础关键词检索可以召回与问题相关的合成记忆。
- 检索结果可以构造成受控上下文并影响 Fake 回答。
- 单元、SQLite 集成和最小端到端测试已经建立并通过。
- L1 记忆可以列出、按 ID 查看、追溯 L0 来源并持久删除。
- 删除后的记忆不会继续参与召回，数据库重开后仍保持删除状态。
- PC 端 CLI 可以进行聊天、查看记忆、删除 L1 记忆和安全退出。
- 项目可以通过 `python -m longmemory` 或安装后的 `longmemory` 命令启动。
- 完全相同的规范化记忆会复用已有声明，同时保留每次用户陈述的来源证据。
- SQLite V3 已区分记忆主体、系统记录时间、事实有效时间和取代生命周期。
- V1/V2 测试数据库可以非破坏性升级到 V3，并保留已有来源关系。
- 检索只使用尚未退役的当前记忆。
- 用户输入和助手回答都会以各自角色保存为 L0 原始对话；助手回答不会自动成为用户事实。
- 非流式兼容模型适配器已通过模拟接口测试；用户完成了校园网真实接口与 v1 合成验证。
- JSONL 元数据审计日志可追踪一轮输入的写入、召回、上下文和模型失败。
- 固定合成数据上已运行有/无回答上下文的对照；词面代理不是通用模型能力指标。
- 两个独立 CLI 进程之间已验证持久记忆重启召回。

## 尚未达到 V0.1 完成标准的部分

- 针对现场暴露的无问号误写与拒答词面误判已修复；修复后 v2 真实模型复验待执行。
- v1 报告已人工复核，仍需复核 v2 回答；不能用 Fake 结果代替真实模型验收。

## 验收后的近期里程碑

V0.1-Demo 圆屏演示已前移至 PC 最小验收之后，详见 ROADMAP.md 和 ADR-0005。
语义重复、撤销/恢复、隐私级彻底删除属于后续能力，不列为当前 V0.1 必备验收项。

完成标准见 `docs/requirements/v0.1.md`。当前实现使用确定性规则、关键词检索和 Fake 回答生成器，只证明最小架构闭环，不代表通用长程记忆能力。
