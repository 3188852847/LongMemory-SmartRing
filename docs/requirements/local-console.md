# 本机控制台里程碑

> 后续顺序由 ADR-0008 调整：新增文字对话，先提供实际逐轮过程，再扩展角色/完整记录页。下文保留原四页范围和已完成的记忆页验收；新文字入口仍未实现，详见 research-platform.md 的阶段 B。

用户已决定先补齐基础控制台，再回到 V0.2 记忆研究。整体边界见 ADR-0007；本文件说明分步验收，不将占位导航当作已实现页面。

## 范围

- 设备与状态：连接、手动读取音量、受限设置、回执/读回核对。用户已确认网页可控制实机。
- 记忆管理：显式指定已有 V4 SQLite 库；分页、字面搜索、原始来源、时间与状态、人工错误纠正、单条删除确认。
- 助手角色：后续接入助手侧提示词；不能与 L3 用户画像混淆。
- 运行记录：后续接入元数据及显式授权的实验轨迹；不把日常日志自动混入评估集。

## 不在本轮记忆页范围内

新建/自动迁移数据库、批量删除、彻底擦除 L0/备份、恢复、原地编辑事实、事实变化、自动冲突更新、向量搜索、云托管、多用户认证、任意文件浏览。人工错误纠正的追加式 SUPERSEDE 已按 ADR-0030 纳入。

## 记忆页完成标准

1. 没指定数据库、路径错误、版本不符、数据库异常均给出错误，不假装空库，不自动创建或迁移。
2. 列表只返回当前页摘要；点击详情后按真实来源展示 L0 原文及角色，缺失来源明确标记。
3. 支持未退役/已退役/全部筛选、文字包含搜索、分页。此功能不改变聊天召回。
4. 默认只读。启用删除需要启动参数，具体操作还需页面列出内容/ID/影响后显式确认。
5. 删除沿用现有管理用例：L1 和来源关联移除，L0 保留；其他记忆指向此条的取代链接依原有外键语义置空。
6. 删除前在同一写事务里校验详情快照，来源/内容变化时拒绝旧确认；断线或超时不自动重发。
7. HTTP 保护、合成 SQLite 删除/重开/不再召回、原文保留、非法参数、文字作为数据等自动化验证通过。
8. 真实浏览器视觉、删除对话框和用户实际库体验需单独记录，不用纯逻辑测试冒充。

当前：上述服务端及页面实现已完成，合成自动化验证通过；记忆页真实浏览器体验未验证。运行中的旧网页服务需要重启才会加载新路由。助手角色和运行记录仍待实现，不要求用户批准普通后续编码步骤。
