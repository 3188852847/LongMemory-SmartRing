# 可替换方法研究平台：分阶段验收

决策依据为 ADR-0008。本文件区分设计目标与已实现范围，不以目录存在作为完成标准。

## A：现有方法入口（已完成）

- 中立 contracts 不引用核心 L1 类型或存储技术。
- 显式方法名和状态路径，未知方法先拒绝再接触数据库。
- `longmemory_v1` 复用现有提取、精确去重、来源与关键词召回。
- observe 不生成回答，recall 不写入查询；关闭只释放资源。
- 保存原消息角色/时间，助手原文不提取为用户事实；会话字段暂不支持时明确拒绝。
- 不支持的能力明确报错；不同状态文件隔离，重开召回，旧 CLI/小智管道保持兼容。
- 239 项 Python、9 项 Node 合成回归通过；非性能或论文指标。新增方法测试 16 项。

## B：本机文字对话（离线实现完成，实用验收待进行）

- 后端共用记忆实现、模型与角色配置；网页不持有密钥，不自动重发有副作用请求。
- 网页/圆屏共享同一日常记忆空间，但当前会话互不污染；新建会话不删长期记忆。
- 逐轮展示实际写入/检索/注入/回答与来源，未知过程不伪造。
- 明确并发写入、重复提交、回答失败后的状态及重试行为；不以文件共用代替一致性设计。
- 本机安全策略继续生效；不默认播放到圆屏，不自动收集日常实验集。
- 合成离线测试之外，双入口实机/校园网验证由用户执行，不冒充已验收。

实际实现：`/chat`、显式 `--enable-chat`、已有 V3 库不迁移、当前网页会话最近六轮上下文；每会话最多 40 轮、全局最多 32 个临时会话/8 小时，最多两个并行回答请求。刷新另开聊天、服务重启不恢复会话列表；L0 双方原文和 L1 长期记忆仍持久化。

验证：全量 254 项 Python、11 项 Node 测试通过；临时合成库的离线预览 `/chat` 返回 HTTP 200。未进行浏览器点击/视觉验收，未访问校园模型或个人库；实用验收未据此标记完成。

同一会话同一 request_id 的重复请求返回原结果；处理中拒绝重复、失败不自动重试。幂等记录只在临时会话存活期间有效，不能宣传为跨进程崩溃的 exactly-once。每条 observe 的 L0/查重/L1/证据使用同一 SQLite 写事务；模型调用不持写锁，召回与来源使用同一读快照。冻结整个实验状态仍未实现。

复用现有模型环境变量和角色文件，网页明确显示模型/角色/完整库路径，但不会读取小智含密钥的配置并自动同步；双入口使用者仍需核对。设备不自动播音。逐轮过程暂留服务器会话内存，不是完整、持久、可复现的实验运行记录。

## C：历史回放与冻结问答（最小版及首次真实模型运行完成）

- 指定数据/样例/会话时间与顺序、方法/模型/提示版本、预算和评分器；评分标签不进入方法输入。
- 完整历史直接回放，不生成替代历史，等待构建就绪；不同方法/运行隔离，每题临时上下文隔离。
- 冻结时禁止永久更新，验证状态前后不变；阶段 A 的独立 recall 不是完整冻结能力。
- 对照方法至少两种不同结构，包括现有方法与简单分块检索；不使用 L1 文本相等判定其他方法质量。
- 报告包含运行 manifest 和逐题过程，区分错误/答错/不支持/中断；提供覆盖率，不选择性删除失败。
- 保留旧 smoke runner 和历史报告，不能把上下文消融改名为跨论文公平比较。

当前交付：`evaluation.comparison.runner`、14 条合成历史/3 会话、8 道开发题/4 道保留题；原始元数据归档、两个方法专属状态、只读冻结和逐题状态摘要、相同 4000 字符预算、来源集合覆盖与答案词面初筛。新增 16 项测试，全量 270 项 Python、11 项 Node 通过。本轮仅运行开发题 Fake，不调用学校模型、不运行保留题、不迁移个人库。

旧基线不消费 session_id，平台显式保存该元数据后适配输入；分块方法实际消费会话边界。会话在实验数据中完整保留不等于日常聊天的会话持久化已完成。来源覆盖检查完整召回，不冒称截断后的注入充分性。模型故障保留分母、错误正文脱敏；强制终止/断电可能损失最后检查点。见 ADR-0009 和运行指南。

追加实际验收（2026-09-03）：用户完成学校模型开发集两方法各 8/8，原初筛均 5/8；来源覆盖为 4/6 与 5/6。助手独立附页记录措辞误判与提取/检索缺口，不修改原报告。附页可离线校验报告哈希、全部题目清单及复核者类型；不是独立盲评或论文指标。见[复核记录](../research/comparison-dev-review-2026-09-03.md)。

## D1 / D2：LongMemory 升级与论文复现交替迭代（D1 候选边界已实现，其余待实现）

D1 首步交付：来源绑定的候选生成协议、ADD/NOOP 整批验证、问句/助手/空输入过滤、受控失败和原文摘录校验，以及独立兼容模型适配器。仅离线替身验证，不是 LLM 提取质量验收；未装配进 v1、个人库或圆屏。下一步为新实验方法装配（网络调用在写事务外），随后验证提取/检索各自贡献，见 ADR-0010。最新全量 310 项 Python、11 项 Node 通过。

- D1 先根据开发集差距升级我们自己的提取/检索/上下文方法，保留旧基线，不把当前规则方法当成熟研究方案；保留题用于有限的独立验收。
- D2 选择论文方法作适配共同任务的比较，与 D1 交替，不以完成所有论文复现为算法升级的前提。

- 先核查对应代码、模型、数据协议、许可证和预算，再选择共同任务。
- 区分忠实复现、统一条件改编、完整系统比较、组件消融。
- 反馈学习单独定义环境、反馈可见性、尝试次数、更新时机、状态边界及冻结迁移；不强行沿用每题重置。
- 参数/潜在记忆、任意论文热插拔、云部署、多用户和训练平台不在第一版范围内。
