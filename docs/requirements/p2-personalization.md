# P2 最小实现范围与设置归属

## 实施顺序

1. 聊天网页外观：浅色/深色/跟随系统、字号、恢复默认。已实现，不动记忆路径。
2. 助手角色：网页已实现编辑、版本保存、预设恢复与下一轮读取；新增明确确认的小智配置同步，磁盘匹配与运行生效分开显示，实机待验收。
3. 声音：四种 Edge TTS 音色、联网试听与确认保存已实现；CosyVoice 3 当前为日常推荐和首次默认，Edge 是联网稳定回退。VoxCPM2 本地常驻适配支持受控参考 WAV、表达指令、CFG、三档质量和网页朗读；sanoTTS 保留为音质较低的实验速度基线。切换 TTS 后端会立即保存下次启动选择，但运行中的语音不热切换；同一 VoxCPM2 后端内保存声音方案后动态生效。声音训练不在当前范围。
4. 表达偏好：称呼、回答长度、互动方式和表情频率已作为可选受管区块进入现有角色版本；不另建人格配置库，不等同于 L3 用户画像。
5. 恢复边界：外观可在当前浏览器即时恢复；表达偏好和 VoxCPM2 声音只恢复为未保存草稿，用户再次保存后才生效。主动交流是持久许可与定时策略，不纳入一个笼统的“全部恢复默认”；圆屏真机设置也不由个性化概览自动下发。

## 设置矩阵

| 设置 | 保存位置 | 生效范围 | 重启要求 |
|---|---|---|---|
| 本次主题、字号 | 浏览器显示偏好 | 聊天网页，不改其他页和圆屏 | 即时生效，刷新保留；同源标签同步 |
| 当前网页角色 | 未保存时用启动预设；保存后用 `.role.sqlite3` 旁库版本 | 网页回答，不影响实验和 CLI | 保存后下一轮读取；进行中的回答版本不变 |
| 当前小智人格/声音 | 小智私有配置 | 圆屏语音链路 | 本阶段按重启小智处理，不声称热更新 |
| 角色编辑入口 | React 页、受保护 API | 网页设置可用，圆屏另行检查/确认同步 | 原目录备份；需重启小智，不自动声称生效 |
| 结构化表达偏好 | 现有角色提示词中的版本化受管区块 | 与对应角色版本一起用于网页和显式同步后的圆屏 | 网页下一轮；圆屏仍需同步并重启小智 |
| TTS 后端 | 控制台/启动面板共用非敏感选择指针，选择时立即保存，启动时同步到小智私有配置 | CosyVoice 3 为日常推荐和首次默认；EdgeTTS 是联网稳定回退，VoxCPM2 `plain` 与 sanoTTS 为实验候选 | 停止旧服务后同步，下次启动加载；配置匹配不等于圆屏验收 |

## 验收与边界

外观枚举值严格校验；存储禁用时本页仍可使用，明确告知无法保存。浏览器不保存正文/密钥；显示偏好不当作用户事实写入长期记忆。消息和证据仍为纯文本，证据保留可展开入口。

当前不包含头像上传、背景图、主题色选择、圆屏角色运行版本回执、声音训练、任意路径参考音频或记忆升级。实际视觉、听感、参考音色相似度、网页麦克风打断和圆屏打断由用户体验，不以纯函数测试代替实机验收。
