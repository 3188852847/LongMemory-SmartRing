# P2 最小实现范围与设置归属

## 实施顺序

1. 聊天网页外观：浅色/深色/跟随系统、字号、恢复默认。已实现，不动记忆路径。
2. 助手角色：需要服务端版本化设置、当前生效值、恢复默认，以及网页和小智的同步边界。尚未实现编辑入口。
3. 声音：先核对现有 TTS 提供器可选音色与参数，再做合成文本试听和应用。尚未实现，不引入克隆模型。

## 设置矩阵

| 设置 | 保存位置 | 生效范围 | 重启要求 |
|---|---|---|---|
| 本次主题、字号 | 浏览器显示偏好 | 聊天网页，不改其他页和圆屏 | 即时生效，刷新保留；同源标签同步 |
| 当前网页角色 | 启动参数及提示词资源 | 网页回答 | 当前需重启控制台 |
| 当前小智人格/声音 | 小智私有配置 | 圆屏语音链路 | 本阶段按重启小智处理，不声称热更新 |
| 拟议角色设置页 | 待设计服务端设置 | 需分别显示两端有效版本 | 接入时明确，不静默覆盖私有配置 |

## 验收与边界

外观枚举值严格校验；存储禁用时本页仍可使用，明确告知无法保存。浏览器不保存正文/密钥；显示偏好不当作用户事实写入长期记忆。消息和证据仍为纯文本，证据保留可展开入口。

当前不包含头像上传、背景图、主题色选择、全站主题联动、角色编辑、声音试听、记忆升级。实际视觉和浏览器交互由用户体验，不以纯函数测试代替视觉验收。
