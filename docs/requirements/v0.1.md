# V0.1 需求与完成标准

## In Scope

- PC 端 CLI 文本交互和单用户实验
- L0 原始对话与 L1 原子记忆
- SQLite 持久化和来源追踪
- 基础提取、检索、上下文注入和回答
- 查看、删除和撤销记忆
- 固定测试集、无记忆 Baseline 和必要日志

## Out of Scope

- SmartRing-Plus 实机、Xiaozhi、ASR、TTS 和 Web UI
- 向量数据库、知识图谱、多模态和多用户
- L2/L3、复杂冲突处理、遗忘、衰减和主动提醒

## Definition of Done

一次合成对话可以写入 L0/L1；程序完全退出并重新启动后，新问题仍能检索该记忆并生成正确回答；来源可查看，记忆可删除；关键路径具有自动化测试，并与无记忆 Baseline 使用相同数据运行。
