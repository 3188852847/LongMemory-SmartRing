# 陪伴助手：自定义功能清单

更新日期：2026-09-08

## 这份清单怎么用

面向你自己的日常使用：让助手的外观、声音、表达、记忆和主动交流符合你的喜好。

这是一份**供挑选和讨论的候选清单，不是已经全部实现的功能，也不是全部承诺开发**。先选影响使用意愿的项目，其他逐步增加。圆屏与网页是不同入口，网页能实现的设置不代表现有圆屏固件也能实现。

状态说明：

- **已有网页入口**：现有控制台已经提供对应操作；不意味着所有场景都经过实机验收。
- **已有基础，需做设置入口**：已经有配置或部分底层能力，但还不能在页面完整管理。
- **候选新增**：需要开发，目前不能直接使用。
- **需验证**：取决于固件、服务或模型支持情况，不能保证直接实现。

当前产品顺序：P1 日常入口 → P2 个性化体验 → P3 日常记忆 → P4 可控主动交流 → P5 习惯驱动陪伴。见[产品阶段与验收](companion-product.md)；本清单的具体选项仍是候选，不替代已有版本历史。

| 可自定义项 | 你可以设置什么 | 当前状态 | 建议阶段 |
|---|---|---|---|
| 页面主题 | 浅色、深色、主题色、背景风格 | 全部 React 页面已共享浅色/深色/跟随系统；自选主题色/背景待实现 | 体验优化 |
| 助手形象 | 名称、头像、本地背景图片 | 角色名称可编辑；头像与本地背景待实现 | 体验优化 |
| 阅读体验 | 字体大小、行距、聊天气泡宽度 | 聊天字号三档已有；自选行距/宽度待实现 | P2 |
| 首页 | 默认打开聊天、设备状态、记忆管理或设置中心 | 启动面板固定白名单选择已有 | 已有 |
| 信息密度 | 普通聊天视图；需要时展开写入、检索和来源过程 | 已有逐轮折叠过程展示；全局密度设置待实现 | 体验优化 |
| 会话整理 | 会话名称、置顶、搜索、继续历史聊天 | 名称/切换/同浏览器历史恢复已有；置顶/搜索待实现 | P1 后逐步扩展 |
| 输入习惯 | Enter 发送或换行、快捷键说明 | 已有网页入口：默认 Enter 发送，可切换 Ctrl+Enter 发送；中文输入法组词不误发送 | 已有 |
| 动效 | 跟随系统、减少动画、完整动画 | 已实现；当前覆盖控制台导航过渡与圆屏预览装饰动画，不改变真实固件 | P2 |

边界：先美化和改善网页，不默认同步更改圆屏 UI；不为了换主题立即重写整个前端。上传资源应限制类型、大小，不允许上传并执行脚本。

## 2. 声音与语音交互

| 可自定义项 | 你可以设置什么 | 当前状态 | 建议阶段 |
|---|---|---|---|
| 圆屏设备控制 | 读取和调节音量、亮度、明暗主题 | 音量、亮度、主题已有网页入口；仅实时上报的工具可用 | 已有 |
| 圆屏状态 | 查看电量/充电、Wi‑Fi 信号、芯片温度 | 显式读取快照；不暴露 SSID，不是持续监测 | 已有 |
| 音色选择与试听 | 先试听，再选择喜欢的声音 | Edge 标准音色；VoxCPM2 支持受控参考 WAV、表达指令、CFG 与质量档 | 已有 |
| 语速、音高等 | 调整朗读节奏与音高 | 需验证各 TTS 服务支持的参数 | P2 |
| 网页朗读 | 网页朗读回答、停止播放 | 使用当前 TTS，在电脑播放，不驱动圆屏 | 已有 |
| 输出位置 | 只显示文字、网页播放、圆屏播放 | 需验证；当前网页回答不会默认送圆屏播放 | 分阶段接入 |
| 打断方式 | 说话打断、按钮停止、继续聆听 | 网页按钮停止与本地麦克风能量打断已实现；麦克风只在朗读期间占用并在所有结束路径释放；圆屏说话打断待实机验收 | 部分已有 |
| 本地语音模型 | 将现有 TTS 替换成适合本机的方案 | VoxCPM2 独立适配层与统一启动已实现；定制声线仍需合法素材与专项验收 | 声音专项 |

注意：音量、音色、语速是不同设置；同一音色参数不能保证在不同服务间通用。声音试听默认使用合成文本，不发送个人记忆。声音克隆只使用有权使用的素材，不能因能下载就视为已获授权。

## 3. 助手角色与表达方式

| 可自定义项 | 你可以设置什么 | 当前状态 | 建议阶段 |
|---|---|---|---|
| 角色提示词 | 编辑助手角色；切换现有爱莉希雅风格或普通助手文本 | 设置入口、版本保存、预设恢复和圆屏显式同步已有 | 已有 |
| 相互称呼 | 助手名字、它怎么称呼你 | 角色名称与用户称呼入口已有 | 已有 |
| 表达风格 | 温柔、活泼、简洁、轻松等偏好 | 仍主要由角色预设/完整提示词控制；独立风格枚举待扩展 | 逐步扩展 |
| 回答长度 | 简短陪聊、自然平衡、需要时详细 | 结构化入口已有；不等于单纯修改 Token 上限 | 已有 |
| 陪伴方式 | 倾听为主、先询问是否需要建议、直接讨论解决办法 | 结构化入口已有 | 已有 |
| 表达细节 | 表情、语气词、称呼的使用频率 | 表情频率与称呼入口已有；语气词仍由角色提示词控制 | 已有基础 |
| 角色预设 | 保存多套配置、预览、恢复上一版 | 版本保存与内置预设恢复已有；多套自定义命名预设待实现 | 体验优化 |
| 临时模式 | “今天只听我说”“这次直接给建议”，不覆盖长期偏好 | 候选新增 | P3 |

角色设置影响表达，不保证模型逐句严格遵循。**助手角色不是用户画像**；角色故事不能作为你的个人事实。当前明确需求应优先于长期风格偏好。不提供通过制造负罪感、排斥现实人际关系来提高黏性的设置。

## 4. 记忆：记什么、怎么用、怎么改

| 可自定义项 | 你可以设置什么 | 当前状态 | 建议阶段 |
|---|---|---|---|
| 记忆查看 | 浏览、文字筛选、查看原始来源 | 已有网页入口 | 已有 |
| 单条记忆删除 | 删除指定 L1 记忆 | 已有网页入口，需显式启用；L0 原文仍保留 | 已有 |
| 记忆模式 | 暂停生成新 L1；“只在我要求时记”另行设计 | 运行期开关已实现；重启恢复开启，L0 仍归档 | P3 |
| 显式记忆指令 | “记住这件事”“这句不要记” | 候选新增，不能只靠角色提示词保证 | P3 |
| 手动添加偏好 | 在页面明确录入偏好，并标明是你主动填写的 | 候选新增 | P3 |
| 纠正记忆 | 修改错误事实，说明是纠错还是情况发生变化 | 错误纠正与事实变化均已有，并保留取代链和来源 | 已有 |
| 禁记范围 | 指定不长期记忆的内容类别或本次话题 | 候选新增；自动分类不能承诺零漏记 | P3 |
| 记忆使用开关 | 本次不使用长期记忆，与停止写入分别控制 | 运行期开关已实现；网页与圆屏共享 | P3 |
| 提取方式 | 规则或模型提取；日常优先提供易理解的预设 | 已接入日常启动选择；模型失败保留 L0 | P3 |
| 召回方式 | 关键词或混合语义检索；先通过预设开放 | 已接入日常启动选择；混合故障显式降级 | P3 |
| 推测的习惯 | 查看、确认、否认或停止使用某个推测 | 时间候选、离线回放、版本激活/停用/回滚和运行来源已有；自然语言反馈仍待扩展 | P5 已有基础 |
| 保留与清理 | 设置保留策略，查看删除会影响哪些数据 | 候选新增；完整隐私删除未实现 | P3 起分步设计 |

重要区别：

- 不写长期记忆 ≠ 不保存聊天记录。
- 不使用记忆 ≠ 删除记忆。
- 删除一条 L1 ≠ 删除相关原文、备份、日志和所有衍生信息。
- 清空当前聊天 ≠ 清空长期记忆。

因此不直接用一个含糊的“隐私模式”包办所有语义。上线前应明确列出写入、留存、调用与删除范围。

## 5. 主动交流

当前已实现总开关、后台定时问候、星期/时段、固定时刻与短文本、临时勿扰、每日次数、最短间隔、记忆话题素材、圆屏问候测试和运行记录。P5 已能从跨日时间证据形成候选，经固定离线回放生成不可变版本，并允许激活、停用和回滚；当前只实现一种保守的“常见时段缺席”策略，不等于通用自进化。

| 可自定义项 | 你可以设置什么 | 建议阶段 |
|---|---|---|
| 总开关 | 是否允许助手主动联系 | P4 |
| 允许时段 | 哪些时间、工作日或周末可以联系 | P4 |
| 勿扰与暂停 | 临时暂停、休息时不出声 | P4 |
| 频率限制 | 每天最多几次、两次之间的最短间隔 | P4 |
| 主动话题 | 日常问候、接续未聊完的话题、询问近况 | P4 |
| 联系方式 | 控制台提示；圆屏主动播报需另验通道 | P4 |
| 无回复策略 | 没回复就结束，不连续催促 | P4 |
| 过期策略 | 错过时段不积压、不在下次启动集中补播 | P4 |
| 触发原因 | 查看为什么现在联系，并一键停用该规则 | P4 |
| 习惯观察 | 是否允许用聊天时间等记录总结习惯 | P5 |
| 习惯确认 | 发现午后聊天规律后，先问你是否启用问候 | P5 |
| 反馈调整 | “这个时间不合适”“少主动一点” | P5 |

例子：你可以明确设定“下午一点到两点，如果今天还没聊过，问候一次”。这是时间规则，不应包装成系统已经学会了你的习惯。

习惯学习需要区分“没有聊天”“设备离线”“服务没运行”，不能把缺少记录解释成你故意不理助手。仅观察本系统内明确允许记录的互动，不默认监控电脑活动、定位或其他应用。

| 可自定义项 | 你可以设置什么 | 当前状态 | 建议阶段 |
|---|---|---|---|
| 一键启动模式 | 文字聊天，或文字＋小智语音服务 | 统一启动和圆屏模式已完成实际使用；视觉与信息层级继续优化 | 体验优化 |
| 自动打开页面 | 启动后是否打开控制台、打开哪个页面 | 面板自动打开控制台；聊天、设备、记忆、设置四个目标页可选 | 已有 |
| 服务管理 | 查看运行状态、停止、重启，避免重复启动 | 面板可停止自有进程树、停止后再启动；不接管旧终端进程 | P1 |
| 登录后自动启动 | 是否随系统登录启动 | 候选新增；需要单独启用，不默认修改系统 | P1 后补 |
| 模型连接 | 模型名称、地址、超时等 | 已有配置基础，需安全设置入口 | P1–P2 |
| 数据位置 | 明确当前日常库，避免两端用错数据库 | 已有启动参数，统一管理候选新增 | P1 |
| 故障行为 | 模型不可达时明确提示，不假装正常回复 | 已有错误处理基础，产品化提示需完善 | P1 |

配置页面不展示明文密钥，不把密钥存入前端缓存或配置导出包。换数据库不等于自动合并或迁移数据；迁移前必须说明影响。默认维持本机控制台访问边界，不通过一个开关直接暴露到公网。

## 7. 圆屏专属设置：先验证，再列入承诺

| 候选项 | 当前判断 |
|---|---|
| 音量 | 已验证网页控制，但待机可能没有活动连接 |
| 亮度与自动熄屏 | 需检查厂家 B V2 固件是否提供接口 |
| 主题、表情、背景 | 需检查资源格式与固件支持，可能需要编译和烧录 |
| 圆屏状态预览 | 已有按板级配置 360×360 制作的浏览器模拟器，可检查交互、情绪、系统覆盖和中央安全区；尚未接入真实固件 |
| 字体、字幕与显示布局 | 需检查显示实现，不等于网页 CSS 设置 |
| 唤醒词与聆听方式 | 需检查语音方案和固件，不能保证任意词可用 |
| 待机主动播报 | 已通过受控主动问候链实机播报；播放完成仍主要依赖人工观察 |
| 电量与充电信息 | 不应作为可随意设置的数据；需要真实硬件读数支持 |

不为增加设置项直接改动或烧录固件。优先使用已支持的接口，需要改固件时另行说明、保留恢复方式。

## 8. 数据与使用安全

候选新增：配置预览、恢复默认值、配置版本回退、数据备份与恢复、授权范围内的导出、聊天记录保留设置。

这些功能需分别设计，不能默认承诺“删除后所有副本永久消失”。真实个人信息不进入 Git；导出和备份可能含隐私，应明确位置与内容。开启主动语音前应考虑同屋人员可能听到，不默认朗读敏感记忆。

## 9. 第一批建议开放的设置

优先做这组能直接改善当前痛点的内容，而不是一次实现整张清单：

1. 双击启动、自动打开聊天页、服务状态和停止入口。
2. 页面主题、字体大小、头像和助手名称。
3. 助手角色文本、称呼、回答长度、倾听或建议偏好。
4. 音色试听与选择、现有圆屏音量控制。
5. 记忆查看、暂停写入和纠正入口；配合日常提取与召回升级。

主动交流在上述日常链路可用后推进；圆屏外观、声音克隆、自动习惯推断和复杂专家参数不作为首批阻塞项。

## 10. 你可以直接这样给我反馈

- “页面我想要浅色，背景能换图，先不用动画。”
- “助手设定我要自己编辑，也要能一键恢复。”
- “声音试听优先，没有合适的再看本地模型。”
- “记忆我希望自动存，但能关掉，也能改错。”
- “主动交流我想先按时间，不要一开始自动推测。”

你不需要决定数据库、检索阈值或前端框架。先选你真正想用的能力；技术实现、依赖和风险由后续方案逐项说明。
