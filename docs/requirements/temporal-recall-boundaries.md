# 历史召回边界校准

## In Scope

- 同一分句同时具备明确问句和历史/变化时间表达才允许读取历史；保留常见无问号问句。
- 历史适配器在读取时重新核对锚点未退役、未被取代且现实有效。
- 事实链与 L0 来源关联来自同一个 SQLite 只读快照。
- 保留原有最多 10 条历史补充、当前锚点约束与 L1 影子隔离。

## Out of Scope

- 通用语义时间理解、指定日期推理、全历史搜索与 L2/L3 历史召回。
- 修改个人数据、迁移数据库、增加模型调用或调整个人召回策略。

## Definition of Done

- 合成用例证明历史陈述、跨分句借用历史词和失效锚点不解锁旧事实。
- 原有历史问句与变化时间问句继续通过；覆盖无问号表达。
- 双连接并发写入测试证明历史内容和来源不会跨快照拼接。
- 定向及完整 Python 回归通过；文档同步，检查差异后提交推送。

真实模型对证据的遵循与圆屏 ASR 识别继续留待日常体验，不以离线回归代替。
