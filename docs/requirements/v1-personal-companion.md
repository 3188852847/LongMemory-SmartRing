# V1.0 个人日用陪伴助手：范围与发布验收

日期：2026-09-13。

## 1. 版本定位

V1.0 是面向当前所有者、单用户、本机运行的正式日用版本。SmartRing-Plus 圆屏终端
是主要产品入口，React 控制台用于文字聊天、设置、检查、纠错与回退。LongMemory
Core 继续与设备、模型供应商和 Xiaozhi 实现解耦。

V1.0 的完成含义是：用户能从一个入口稳定开始日常对话；系统能可靠保存、召回和
纠正明确个人事实，区分当前事实、历史变化与未知信息；语音、设备和主动交流具有
明确状态、安全门控与回退路径。它不表示系统已经理解任意时间、自动学会所有习惯，
也不表示项目已经成为可公开分发的多用户产品。

## 2. 正式范围

### 2.1 日常入口与运行状态

- `Start.cmd` 提供文字或文字＋圆屏的单一启动入口，并只管理自己启动的进程。
- 重复启动、端口占用、模型未验证、TTS 未就绪和设备离线必须分开呈现。
- 网页与圆屏可使用独立模型档案，但共用明确的日常记忆空间。
- 网页会话可以恢复；网页和圆屏的短期会话不互相拼接。

### 2.2 个性化与圆屏体验

- 助手角色、用户称呼、回答长度、互动方式、表情频率、网页外观和圆屏外观可检查。
- 设置的网页生效、下轮生效、重启后生效和真机下发必须明确区分。
- CosyVoice3 作为已验收的本机高质量分块语音；EdgeTTS 保留稳定回退。
- 圆屏日常链路覆盖聆听、思考、说话、停止和自然插话；动态壁纸高级发布与硬件负例
  不阻塞核心对话，但必须如实显示验证状态。

### 2.3 正式记忆主链

- L0 原始证据先保存，L1 原子事实承担正式日常记忆。
- 网页和圆屏通过同一常驻 Runtime 完成提取、召回和上下文构建。
- 明确事实可跨会话与重启召回；改写问题可召回常见偏好；无证据时不硬补。
- 支持明确记住、跳过、暂停写入、暂停使用、来源追溯、人工补录和双轮确认删除。
- 纠错与事实变化分开；当前事实和沿精确取代链得到的历史事实分开。
- 严格重复可安全复用；复杂重复必须复核；有完整证据账本的新合并可以恢复。
- V1.0 的最后一个新增记忆范围是明确日期定位的历史事实召回。完成后不再扩展通用
  时间推理或开放全历史扫描。

### 2.4 受控派生记忆

- 已接受且当前有效的 L2 生活场景和 L3 用户画像可在独立开关、数量及字符预算内
  参与回答，并保留 L3→L1/L2→L0 来源轨迹。
- L2/L3 候选、复核、取代、失效和版本记录属于正式管理能力。
- 无人审核的低频整理保持默认关闭；它不是 V1.0 正式日常行为。

### 2.5 可控主动交流

- 主动交流默认关闭，显式开启后仍受勿扰、时段、频率、待回应、会话和设备门控。
- 固定时间问候、所有者批准的记忆话题和明确时间的一次性事项跟进进入正式范围。
- 错过、离线、繁忙和失败不补发；候选、拦截、排队及人工观察可追溯。
- 习惯时段的证据、候选、离线回放、版本和回滚保留为受控实验能力；只有所有者
  明确激活的版本才可能运行，不将沉默或回复速度解释为情绪与满意度。

### 2.6 数据与恢复

- 个人库结构迁移必须先形成一致性备份，并在迁移后检查 `quick_check` 与外键。
- 发布前至少把备份恢复到独立验证路径并完成一次只读完整性检查；不得覆盖活动库。
  操作流程见[数据库恢复演练](../guides/数据库恢复演练.md)。
- 停止记忆、停止用于回答、删除 L1、删除原始对话和删除所有副本继续保持不同语义。
- 模型通道和外发边界可见，密钥不回显到网页或日志。

## 3. 实验能力

以下代码可以随 V1.0 保留，但必须标为影子、预览、候选或默认关闭，不得冒充正式
智能：

- L1/L2 证据充分性影子判断及阈值回放；
- L1 语义重复、冲突和变化关系预览；
- L2 语义召回、无人审核的 L2/L3 低频整理；
- 习惯时段推断与缺席策略；
- 论文方法比较、冻结实验和外部方法复现入口。

影子判断只记录“若启用会怎样”，不改变正式上下文或答案。候选只有经既定复核或
所有者激活后才生效。

## 4. V1.0 明确不包含

- 新增 IndexTTS、GPT-SoVITS 等 TTS 后端或声音训练；
- 任意自然语言时间理解、全历史搜索和自动真值裁决；
- 未经复核的语义冲突合并、自动画像改写或记忆自我训练；
- 多用户、云部署、移动端、公共安装器和 Windows 登录后自动启动；
- 日历、待办、天气、课程表、Zotero、音乐和智能家居；
- OTA、IMU 手势、通用硬件自检和隐私级全副本擦除；
- 论文复现、大规模正式基准和对外性能宣传。

## 5. 发布验收

### 5.1 自动回归

- Python、前端组件和浏览器验收全部通过；必要的固件覆盖层完成离线构建检查。
- 历史日期定位覆盖正常区间、边界时刻、无匹配、多个匹配、模糊日期、普通问题和
  损坏变化链；所有高风险负例保持关闭。
- 测试只使用合成库，不读取个人数据库、真实对话、密钥或外部模型。

### 5.2 固定日用路径

发布候选版必须逐项记录以下结果：

1. 新事实写入、服务重启与改写召回；
2. 无证据问题拒答；
3. 来源询问、人工纠错、事实变化、当前问答和历史日期问答；
4. 单条删除、重复合并及具备完整账本时的恢复；
5. 网页与圆屏共用长期记忆但保持独立短期会话；
6. CosyVoice3 连续回答、自然插话和中止后的下一轮对话；
7. 一次明确主动跟进，以及重启、错过和重复投递负例；
8. 活动库备份、临时恢复和只读一致性检查。

### 5.3 发布候选观察

`V1.0-RC1` 表示功能范围已冻结、只修阻塞缺陷的第一版发布候选。固定验收通过后，
在至少 7 个实际使用日内观察跨日记忆、重启、语音连续性和主动交流边界；这个周期
用于发现日用故障，不冒充统计准确率。阻塞问题修复后可形成 RC2；没有未解决的 V1
阻塞项后才更新代码版本为 `1.0.0`。
