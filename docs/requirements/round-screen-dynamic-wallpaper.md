# SmartRing-Plus 圆屏动态壁纸需求

## 1. 目标

允许所有者在本机控制台选择一段视频，预览它在 SmartRing-Plus 360×360 圆屏中的裁剪效果，并把服务器生成的轻量循环资源发布到设备。圆屏离线后仍能播放已缓存资源；换壁纸不要求重新编译完整应用固件。

首个候选素材是本机的 `爱莉希雅.mp4`。只记录它作为开发样例，不把视频、截帧、转码产物或个人素材路径提交 Git。该文件实测为 727,445,107 字节（约 693.75 MiB），媒体属性见 5.1；本机现已具备可复现的 FFmpeg/ffprobe 工具入口。

## 2. 为什么不能直接播放原始 MP4

- 设备 Flash 为 16 MiB，其中动态资源可考虑使用的 `assets` 分区只有 8 MiB；原视频比整个分区大约 86 倍。
- 圆屏输出是 360×360 RGB565，一帧裸图为 259,200 字节；10 fps 裸帧约 2.47 MiB/s，8 MiB 只能容纳约 3.2 秒，而且还未给字体、表情和元数据留空间。
- MP4 只是容器；内部编码若是 H.264、HEVC 等，不代表当前 ESP32-S3 固件有可用、可与语音并行的解码器。
- 服务器持续逐帧推流会让壁纸依赖网络，并与实时语音争用带宽、CPU 和缓冲区。断网或服务重启也会直接破坏显示。

因此，正式方案是“服务器离线预处理 + 设备本地缓存播放”，不是把原始 MP4 复制到设备，也不是远程桌面式 UI 推流。

## 3. 用户体验

### 3.1 素材库

- 从控制台上传或导入本机视频。
- 展示原始文件名、时长、分辨率、文件大小、内容哈希和处理状态。
- 支持选择开始位置、循环时长、圆形安全裁剪、静音和一个少量预设帧率。
- 转码前显示估算资源大小；超出设备预算时不给出“仍可发布”的假按钮。
- 支持预览、发布、停用、恢复内置视觉和删除本机派生资源。

### 3.2 真机显示

- 待机时允许壁纸成为主要视觉。
- 聆听、思考、说话和被打断时，保留清晰且一致的状态覆盖；状态不能只靠字幕表达。
- 配网、升级、低电量、过热、网络错误和资源错误具有更高优先级，可暂停或完全覆盖壁纸。
- 壁纸没有音轨，不与 TTS 抢占扬声器。
- 减少动画模式可暂停动态壁纸并显示代表帧。

## 4. 技术边界

### 4.1 服务端负责

- 校验上传内容，不信任扩展名和浏览器声明的 MIME 类型。
- 使用固定转码配置生成目标资源；保留转码日志和工具版本。
- 资源按 SHA-256 寻址，写入临时位置并在完整成功后原子发布。
- 限制单文件大小、时长、像素数、输出帧率和资源包大小，防止本机服务被异常媒体拖垮。
- 只向设备提供已验证、目标板型匹配的版本化资源包。

### 4.2 设备负责

- 下载、校验、缓存、解码和显示资源。
- 报告支持的媒体协议版本、可用资源预算和上次应用结果。
- 在非活动槽或临时区域完成写入，校验后切换；不得覆盖唯一可恢复的内置状态视觉。
- 在内存不足、解码超时或音频任务受影响时停用壁纸并回退。

### 4.3 不在第一版范围

- 直接播放任意 MP4、H.264 或 HEVC。
- 长视频、带声音视频、在线播放和服务器逐帧直播。
- 把用户上传的素材提交 Git、上传第三方云端或默认公开分享。
- 壁纸脚本、网页、任意 URL、动态代码或可执行插件。
- 以壁纸替代配网、升级、低电量和错误等安全状态。

## 5. 第一阶段：技术验证

先从一段 3–5 秒样片开始，不建设完整上传页：

1. 用媒体探测工具记录原视频编码、尺寸、帧率和时长。
2. 生成 360×360、无音频、8–12 fps 的圆形安全裁剪样片。
3. 比较至少两种当前固件可实际接入的压缩资源方案；是否采用 GIF、JPEG 帧包或其他格式，以构建结果和真机测量为准。
4. 记录资源包大小、平均/最差解码耗时、实际显示帧率、峰值 PSRAM、Flash 余量及空闲任务影响。
5. 在待机播放、开始聆听、ASR、LLM 等待、TTS 播放和网络中断下分别验证状态覆盖和回退。

只有技术验证通过，才进入“控制台素材库 → 版本化发布 → 设备回读 → 一键回退”的正式实现。

### 5.1 首个真实样片记录（2026-09-10）

本机探测确认样例原片为 3840×2160、60 fps、H.264、191.383 秒并包含音轨。截取第 60 秒开始的同一段 5 秒画面，按 360×360 中央裁剪、移除音轨后得到：

| 档位 | 帧数/时长 | 文件大小 | 当前判断 |
|---|---:|---:|---|
| 8 fps / 64 色 | 40 帧 / 5.01 秒 | 1,710,998 字节（1.63 MiB） | 最省空间，待比较动作流畅度 |
| 10 fps / 96 色 | 50 帧 / 5.00 秒 | 2,321,851 字节（2.21 MiB） | 首个真机候选，画面与预算平衡 |
| 12 fps / 128 色 | 60 帧 / 5.00 秒 | 2,955,864 字节（2.82 MiB） | 质量上限候选，资源和解码压力更高 |

这些数字只证明服务器侧转码可行，不证明 SmartRing-Plus 已能稳定播放。样片保存在被忽略的 `data/round-screen/wallpaper-spikes/`，没有提交原片或派生图像。

### 5.2 首次固件构建记录（0007）

已把中档 GIF 作为 `round_wallpaper.gif` 加入 SmartRing-Plus 专用 assets 构建，并在板级显示类中接入现有 GIF 解码器。待机 `neutral` 状态以壁纸为主要视觉；聆听、思考、说话和异常状态继续显示既有几何脸。资源缺失、格式错误或尺寸不为 360×360 时保留原来的几何脸，不阻止系统启动。

独立构建目录 `build-wallpaper-0007` 已成功完成：

- 应用镜像 3,968,560 字节，应用分区剩余 160,208 字节；
- assets 镜像 2,674,063 字节，8 MiB 分区剩余 5,714,545 字节；
- 资源索引中已确认包含 `round_wallpaper.gif`；
- 尚未烧录，因此解码帧率、峰值 PSRAM、语音并行和状态覆盖仍是待测项。

这版必须把应用镜像写到 `0x20000`，并把配套 assets 镜像写到 `0x800000`；只写其中一个会形成版本不匹配。无需改写 NVS、分区表或 OTA 数据。

## 6. 第一版完成标准

- 控制台能导入一个受限视频并显示真实探测结果。
- 用户能预览圆形裁剪，生成的资源不含音轨且不超过设备预算。
- 设备应用前后均校验内容哈希和板型，失败不会破坏内置状态视觉。
- 壁纸在设备断开服务器后仍能循环；资源损坏时可自动回退。
- 配网、OTA、低电量、错误以及聆听/思考/说话状态仍清楚可辨。
- 正常语音链的崩溃率和首句延迟没有明显回退；阈值须由技术验证基线确定，不预先伪造数字。
- 上传源文件、派生资源和真实用户路径均不进入版本库。

## 7. 后续但不阻塞第一版

- 多个壁纸档案、定时切换和按互动状态选择不同循环。
- 从视频自动挑选循环衔接更自然的片段。
- 与角色、声音和主动交流配置组合成可导入的“陪伴主题包”。
- SD 卡或更大外部存储支持；只有确认硬件和固件能力后再列入承诺。
