## 圆屏持续显示“说话中”但没有正常回答

- 发现时间：2026-09-14，先后在校园模型和官方 DeepSeek 配置下复现。
- 现象：ASR 已识别用户输入，圆屏一直显示“说话中”却没有正常回答，启动面板也没有给出可见原因。
- 现场证据：15:37 的校园模型轮次曾在回答流阶段返回 HTTP 404，这是独立的模型故障。用户改用官方 DeepSeek 后，16:05 与 16:08 的轮次都在日志中完成了 LongMemory 处理，随后立即报“LongMemory 返回协议无效”；时序到达记忆阶段后结束，没有进入 `llm_requested`。因此后一种复现发生在回答模型调用前，不能归因于校园网络、官方 DeepSeek 或 TTS。独立固定文本测试仍证明 CosyVoice 能生成非静音 WAV。
- 根因：V48 历史证据回执为 L1 增加 `temporal_role / valid_from / valid_to`，并为 L2 保存关键词分数；Runtime 已输出新契约，小智薄适配器的严格字段白名单仍停在旧契约。固定上游又先向设备发送 TTS `FIRST`，再查询记忆，而第一个异常分支直接返回且不发送 `LAST`，于是设备没有收到退出“说话中”的结束动作。
- 修复：小智适配器与当前证据契约同步，并严格核对层级、分数、历史角色和带时区的 ISO 时间；启动器只允许从已记录的精确旧哈希受控升级。记忆阶段异常会暴露固定的脱敏故障分类，并为同一轮补发 `LAST`。设备页明确说明故障发生在模型请求之前，不显示记忆正文、供应商响应或密钥。模型阶段原有的固定故障分类继续保留。
- 恢复与复验：重启统一服务以加载新的薄适配器。让圆屏说一句普通短问；正常路径应先进入回答模型并最终退出“说话中”。若记忆服务再次异常，设备也应自动回到非说话状态，设备页显示“圆屏记忆协议不匹配”或“圆屏记忆处理失败”。校园接口按用户说明不在 Codex 会话期间探测。

## 圆屏切换成功后按钮持续等待且皮肤能力误报

- 发现时间：2026-09-14，0011 首次真机切换为几何皮肤时。
- 现象：圆屏重启后已显示几何皮肤，但“切换为皮肤显示”按钮仍在旋转；此时能力检测显示“没有响应皮肤协议”。
- 定位：设备已确认清除活动壁纸指针，但重启前没有送达 `reboot` 回执；设备桥在同一 HTTP 请求和操作锁内同步等待新连接最多 90 秒。能力检测在设备离线或锁仍占用时失败，页面又把所有失败合并成协议不支持。
- 修复：设备桥返回“正在重启”并释放请求；页面每 2 秒只读核对显示模式，确认后自动复查皮肤能力。离线、控制工具准备中、操作占用与协议读取失败使用不同文案，任何重连检测都不重发切换或重启。
- 验收边界：用户已确认几何皮肤实际可见；当次设备控制连接未恢复，因此在线状态回读和保留壁纸恢复仍须另测。

## 历史召回误开放与来源读快照错配

- 发现时间：2026-09-13，接续 ADR-0151 后的合成边界回归。
- 复现：历史陈述加普通问题也返回历史意图；将已退役 ID 作为当前锚点传入适配器，会返回当前继任项；在内容读取后用另一连接删除证据关联，旧实现会返回正文却缺少原来源。
- 根因：整段子串判断未要求问句；适配器信任先前锚点状态；多个 SELECT 未置于显式读事务。
- 修复：同分句问句门控、锚点生命周期/有效期复核、SQLite 一致读快照，策略版本升级为 V2。并发测试采用临时合成 WAL 数据库，不读取或改写个人库。
- 限制：当前召回与历史读取仍是两个阶段；复杂自然语言和模型是否正确使用历史证据未通过本轮验证。见 ADR-0153。

## 手工创建空 `uv.lock` 导致 uv 解析失败

- 现象：`missing field version`。
- 原因：`uv.lock` 是 0 字节手工占位文件，而不是 uv 生成的 TOML 锁文件。
- 处理：移走空文件后执行 `uv lock` 或 `uv add` 重新生成。
- 预防：`uv.lock`、依赖元数据和构建产物不得用空文件代替命令输出。

## 无问号提问被写为 L1，拒答措辞被评分器漏判

- 发现时间：2026-09-03，用户完成首轮校园网真实验证后反馈。
- 现象：“我的猫叫什么”“我的猫是什么颜色”后显示新增长期记忆；v1 无上下文组自动显示 1/5。
- 原因：提取规则只排除结尾问号，而 v1 数据恰好都含问号；评分器漏掉“没有关于……的信息”“无法回答”等拒答表达。
- 证据：本地复现无问号提取；复核 `smoke-631ac6a7efd5438dae1855d0b0713a87.json` 中两条合理拒答的失败标记。按拒答含义复核，无上下文组为 3/5；这不是模型准确率。
- 修复：问句规则与 Fake 共用；增加无标点/混合输入、正常陈述回归；评分器单独版本化，并增加原因和复核标记。v2 数据增加无问号回归，v1 文件与原报告不修改。
- 数据处理：代码修复只影响后续提取，不删除既有 L0/L1；复验使用独立合成数据库。旧数据清理需另行确认具体记录。
- 限制：规则识别与词面评分均非通用语义判断，不保证覆盖歧义、引述和复杂表达。
