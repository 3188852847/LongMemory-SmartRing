`chrome-headless-shell.exe` 进程，三个用例均在运行断言前以 `browserType.launch:

沙箱外执行后 3 项全部通过。

进程的环境重跑同一命令。只有错误明确表示 executable 不存在时，才按 React 指南由

## 历史召回误开放与来源读快照错配

- 发现时间：2026-09-13，接续 ADR-0151 后的合成边界回归。
- 复现：历史陈述加普通问题也返回历史意图；将已退役 ID 作为当前锚点传入适配器，会返回当前继任项；在内容读取后用另一连接删除证据关联，旧实现会返回正文却缺少原来源。
- 根因：整段子串判断未要求问句；适配器信任先前锚点状态；多个 SELECT 未置于显式读事务。
- 修复：同分句问句门控、锚点生命周期/有效期复核、SQLite 一致读快照，策略版本升级为 V2。并发测试采用临时合成 WAL 数据库，不读取或改写个人库。
- 限制：当前召回与历史读取仍是两个阶段；复杂自然语言和模型是否正确使用历史证据未通过本轮验证。见 ADR-0153。

## Windows 中文 Python 路径导致 Tk 测试找不到 `init.tcl`

- 发现时间：2026-09-10，运行完整 pytest 回归时。
- 现象：其余 1081 项通过，启动面板的 Tk 构造测试报 `Can't find a usable init.tcl`；错误输出中的 Python 安装目录中文显示为乱码。
- 定位：Tcl/Tk 文件实际完整存在于当前 uv Python 的 `sys.base_prefix/tcl`；显式设置 `TCL_LIBRARY` 与 `TK_LIBRARY` 后失败项通过，不是启动面板业务回归。
- 修复：`tests/conftest.py` 在 Windows 且目录真实存在时，为 pytest 子进程补全这两个变量；不覆盖调用者配置，不修改系统环境变量，也不影响正式应用进程。

## Windows PowerShell 5.1 误读中文防火墙脚本

- 发现时间：2026-09-03，执行小智局域网演示的 `firewall.ps1 -Action Allow` 时。
- 现象：中文报错文本变成乱码，同时报告意外标记、字符串缺少终止符。
- 定位：文件为无 BOM 的 UTF-8；Windows PowerShell 5.1.26100.9168 只读解析复现 8 个语法错误。此前仅在 PowerShell 7 检查语法，遗漏了旧版编码行为。
- 修复：为脚本添加 UTF-8 BOM，保留原有规则逻辑和范围；增加编码及 Windows PowerShell 只读解析回归测试。
- 影响：该次失败发生在解析阶段，尚未执行防火墙操作。无需修改执行策略或关闭防火墙；修复后在管理员终端重试原命令。

## ESP-IDF 临时构建路径过长导致依赖文件生成失败

- 范围：2026-09-03，独立 AXP2101 诊断程序的 Windows 离线编译。
- 现象：bootloader 编译 `bootloader_flash_config_esp32s3.c` 时无法打开长路径下的 `.obj.d` 依赖文件。
- 定位：源代码和工具链不变，缩短临时目录后编译成功；不是圆屏硬件故障。
- 处理：构建脚本使用 `%TEMP%\axp-<短编号>\app`，不保留多层源仓库目录前缀，不修改 Windows 全局长路径策略。
- 另一次沙箱编译遇到 SDK Git 所有者检查和构建工具定位失败；使用安装 SDK 的用户环境编译通过，未添加全局 `safe.directory` 例外。

## 手工创建空 `uv.lock` 导致 uv 解析失败

- 现象：`missing field version`。
- 原因：`uv.lock` 是 0 字节手工占位文件，而不是 uv 生成的 TOML 锁文件。
- 处理：移走空文件后执行 `uv lock` 或 `uv add` 重新生成。
- 预防：`uv.lock`、依赖元数据和构建产物不得用空文件代替命令输出。

## 无问号提问被写为 L1，拒答措辞被评分器漏判

- 发现时间：2026-09-03，用户完成首轮校园网真实验证后反馈。
- 现象：“我的猫叫什么”“我的猫是什么颜色”后显示新增长期记忆；v1 无上下文组自动显示 1/5。
- 原因：提取规则只排除结尾问号，而 v1 数据恰好都含问号；评分器漏掉“没有关于……的信息”“无法回答”等拒答表达。
- 证据：本地复现无问号提取；复核 `smoke-631ac6a7efd5438dae1855d0b0713a87.json` 中两条合理拒答的失败标记。按拒答含义复核，无上下文组为 3/5；这不是模型准确率。
- 修复：问句规则与 Fake 共用；增加无标点/混合输入、正常陈述回归；评分器单独版本化，并增加原因和复核标记。v2 数据增加无问号回归，v1 文件与原报告不修改。
- 数据处理：代码修复只影响后续提取，不删除既有 L0/L1；复验使用独立合成数据库。旧数据清理需另行确认具体记录。
- 限制：规则识别与词面评分均非通用语义判断，不保证覆盖歧义、引述和复杂表达。
