# 本地配置与历史资料

2026-10-14 工程骨架整理将人工管理的配置、运行状态、历史证据分开存放。
这些本地内容不会提交 Git；目录归位不会删除、重新计算或改写历史测量结果。

| 内容 | 当前位置 | 管理方式 |
|---|---|---|
| 私有模型、搜索、语音配置和用户偏好 | `local/config/` | 程序和启动器从统一位置读写；具体文件见[配置管理](configuration.md) |
| 公开配置模板 | `config/examples/` | 只声明字段和脱敏示例，不包含真实密钥 |
| 重装备份、原始快照、恢复验收证据 | `local/archive/recovery/` | 原根目录 `LongMemory备份/` 的内容原样归档 |
| 旧测量脚本及原始结果 | `experiments/results/legacy-runtime-20261014/` | 原 `.test-runtime/` 的 7 个文件，保留脚本与结果配对 |
| 旧 pytest 目录 | `local/archive/test-artifacts/pytest-before-20261014/` | 原 `.pytest-tmp/` 的 4 次运行目录，作为历史材料保留 |
| 归位完整性清单 | `local/archive/manifests/` | 本地 SHA-256、原路径、目标路径、大小及迁移收据 |
| 日用数据与数据库备份 | `data/`、`data/backups/` | 继续由现有服务管理，不混入重装档案 |
| 新测试临时文件 | `data/test-tmp/` | 每进程隔离；[测试产物规则](test-artifacts.md) |
| 服务状态、控制令牌、诊断历史 | `data/control/` | 运行时生成，不能当人工配置整体搬迁 |

归档前后逐文件核对字节长度和 SHA-256，并保留空目录信息。恢复备份中的历史
报告和脚本可能记录当时的旧路径，历史原文不改写。现行操作指南和机器环境登记
更新到归档路径；研究报告追加位置说明，不以本次搬迁声称重新复现了旧实验。

Windows 校验使用扩展长路径，避免较深文件被普通 `is_file()` 盘点漏掉；旧 pytest
的两份深层合成源码因此补入清单，实际为 59 个文件。原清单和长路径补充清单
分别保留，未以改写原收据掩盖盘点差异。

旧测量脚本只是历史快照，不是今天可直接执行的开发入口。它们可能依赖当时的
解释器、模型、本机路径和外部服务；使用时另开实验，保存新的代码版本、环境和
输出目录，不覆盖旧结果。报告引用但重装备份未包含的历史测试目录仍标为缺失。

如需回退资料目录，先停止使用对应目录的诊断进程、核对本地清单，再在目标无
碰撞时按映射移动回来。私有配置回退还需要同步代码版本与启动入口，不能只搬文件。
