## 停机确认的并发回归

整合版 `fe4e163d` 与修复前的分支提交 `422559d4` 使用相同的启动器 HTTP 处理器和停机测试。让服务端写完响应后暂停，稳定复现原测试第 421 行失败。客户端已收到 `shutdown_complete=true` 时，处理线程仍可能等待调度，稍后才设置 `shutdown_observed`。

测试现在先核对停止中的响应，再固定客户端先读完最终响应的顺序，核对 `stopped`、禁止启动和确认事件仍未置位。释放处理线程后限时等待确认。在内存中模拟服务端提前置位时，新断言如期失败。修复后用 20 个独立 pytest 进程逐次运行该用例，全部通过，13 文件组合回归 303 项全部通过。
