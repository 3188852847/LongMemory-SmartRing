## 实现审查

- **端口消费**：偏好版本 7 → Options → controller → runtime 预检/命令 → voice.py → setup 的严格匹配 → 人工 YAML 网络五字段 → 实际生成消费副本。核对固定上游 HTTP 服务读取 `server.http_port`、OTA 使用配置的 websocket URL，WebSocket 服务使用 `server.port`；18000/18003 由部署时选择，旧默认仍兼容。回环控制/网页、壁纸与声音端口沿用旧契约。新端口下旧恢复/防火墙入口明确拒绝，Doubao 非默认端口明确拒绝；没有按端口杀进程或操作 Docker 的实现。
- **网络选择**：自动候选仅为在线物理网卡首选 RFC1918 IPv4；可由当前明确地址选中网卡并保存 GUID，此后跟随同一身份。多候选、断网及未知身份保守等待。首次显式启动才建立归属；停止态自动同步要求本面板先成功停止过自有服务。轮询/稳定窗口/提示/冷却/次数限制均独立于聊天轮次。
- **安全重开**：控制器工作线程串行执行；启动中/停止中、排队操作、偏好 revision 变化拒绝自动重开。自有活进程/Job 加实例令牌是前提；设备连接/握手/控制锁、网页活动及断开后的真实处理任务、聊天后台、Runtime 递延工作、网关连接/流必须空闲。语音和网页各加 60 秒租约，再停自有服务；忙或未知时不强停。停止后重新枚举；失败不自动循环重试。已 ready 后的短暂健康失败不套首次启动超时。
- **并发和保护**：人工来源及消费副本有摘要前提、私有备份与读回；停止态只投影网络五字段，保留已核 Hy 网关投影，不生成普通模型直连回退。并发变化会拒绝并进入失败待处理，不能把多文件更新描述为跨文件事务。既有 paused/backend/mode/写权限配置不因网络重开主动放宽。
- **声线缓存**：身份关联已保存档案、参考音频摘要、参考文本/style 和固定引擎编码标识，两种采样率分别存包；不匹配、丢失、损坏或不完整时静默。完整包先写、清单原子替换，发布失败保留原清单；问话路径不合成、不修缓存。准备阶段必须显式维护窗口、携带选中档案，拒绝 HTTP 重定向；该开关本身不隔离生产者，仍由 X 执行维护步骤。
- **话轮与答案优先**：Memory 查询前开启等待，Memory → 模型 → 工具/TTS 共用一个状态；计时/句子身份、关闭、取消、改声线与最终发送检查阻止迟到提示。真音频就绪即丢弃未发提示尾包；固定上游的虚拟流控位置只退还丢弃帧。提示不写答案文本队列、不调用共享编码器/TTS，不算真实首答。socket 发送完成不等于设备播放，细分字段保持进程内日志，不冒充已升级 v6 设备协议。

审查中排除的疑点：上游服务器默认共享 Memory，但正式 `launch_with_memory.isolate_memory_initialization` 在绑定设备前为每连接创建 LongMemory 实例，因此不能把新增 query 包装直接认定为跨连接串用。控制 HTTP 普通入口未统一返回维护 503，不过租约要求连接为空且阻止新连接，真实 DeviceControl 的设备操作仍须 `_connection()`；当前没有成立的新设备操作竞态复现，不作为已发现故障。上游断线 `save_memory` 在 LongMemory 提供器为无重放空操作；不能据上游守护线程名称推断新个人库重写。
