## 实现与设计取舍

采用 frontend-design、ui-ux-pro-max、emil-design-eng、animate；以 review-animations 自查。浏览器样式预览使用 computer-use 能力。UI/UX 的本地设计系统检索返回通用 Swiss/蓝橙配色，未直接套用；只采用其对比度、焦点与减少动画原则，风格以所有者明确的数码世界方向为准。

颜色为深海蓝 `#06111b`、内容面 `#0b1c2c`、青色 `#5ce5ed`、薄荷绿 `#70dfbd`、琥珀 `#efb864`、异常粉 `#ff8395`。使用已存在的系统中文字体，不引入字体下载或依赖。最有识别度的元素仍是圆屏对应的环形状态核心，正文保持静止。

| 层次 | 实现 | 状态与边界 |
| --- | --- | --- |
| 环境 | `DigitalAtmosphere`：边缘光轨、节点与慢速环流，在两个 main 入口挂载 | 明确为装饰；`aria-hidden`、`inert`、`pointer-events:none`；不显示数字、进度或遥测 |
| 服务状态 | `StateCore`：就绪勾形、异常符号、处理中旋转与小波形 | 仅消费已有启动器快照；波形表示处理中，不能解释为音频振幅、设备聆听或硬件播放 |
| 状态文字 | 复用 `StatusIndicator`；只有 busy 状态点呼吸 | 文字保留，颜色不是唯一状态依据 |
| 主动作 | 共享 120ms 按下、160ms 光反馈；启动器强化开启／进入／停止层次 | 操作请求不等待动画；关闭窗口保留服务、停止与退出的原语义和确认流程保留 |
| 详情 | `TransitionSurface` 使用浏览器 Web Animations API，160ms、transform／opacity | 快速替换取消旧动画，从当前帧续接；键盘、减少动画和页面隐藏时直接显示／停止 |
| 启动设置 | 常用／记忆／语音／显示分类，单一草稿跨分类保留 | 仍通过原设置修订号保存，不更改 API、持久化启动配置或服务所有权 |
| 开关 | `AmbientMotionToggle`，浏览器同源显示偏好 `longmemory:ambient-motion:v1` | 立即生效、不需要保存、不写启动配置。各端口属于不同源，不能声称网页与启动器自动共享持久偏好 |

减少动画保留静态状态与轮廓；关闭持续光效只停止环境、状态核心与 busy 状态点循环，常规反馈仍可用。页面隐藏时暂停循环；键盘输入不触发新增位移动效。组件库仍由 AppearanceProvider 的 motion token 管理 Portal 动画。

网页独立开关在桌面左下；窄窗口进入文档流，避免覆盖输入。整合 C 的最终外壳时需核对桌面开关与侧栏页脚是否冲突；如果需要归入外观设置，可复用导出的 `AmbientMotionToggle`，再移除 main 中的浮动实例。本轮未改写任何页面滚动和工作区高度。

## 动效自查

| Before | After | Why |
| --- | --- | --- |
| 启动器只有系统／全局减少动画边界 | 独立关闭持续光效，页面隐藏暂停，保留静态状态 | 用户可减少持续视觉刺激，后台也不继续无用途循环 |
| 就绪状态点线性呼吸 | 4 秒 `cubic-bezier(.77,0,.175,1)` 透明度呼吸 | 低强度状态表达，正文不移动；忙状态仍有明确文字 |
| 启动设置为整张长表单 | 分类详情 160ms、当前帧续接；键盘直接更新 | 过渡用于避免突变，不阻塞高频操作，也不重置草稿 |
| 控件主要靠悬停边框反馈 | 细指针悬停光反馈、指针按下 80ms／释放 120ms | 快速且可中断；键盘不等待位移，触摸不依赖悬停 |
