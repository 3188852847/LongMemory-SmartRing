# 聊天草稿恢复、记忆计数与纠正请求

2026-11-21，分支 `codex/fix-web-20261121`，基线 `40452b25`。

- 网页聊天在当前页面内保留会话、草稿和本次请求号。遇到 `chat_busy` 或断线后，只查询会话快照。即使另一标签发了相同文字，也只有快照中本次请求号匹配的轮次会清空对应草稿。用户手动重发原稿沿用请求号，修改后发送则分配新号。
- 原记忆引擎的有效条数与聊天发送共用查询键前缀。直接收到结果或查询找回本轮实际写入后，已打开的运行状态面板重新读取计数。仅追加来源（`noop`）沿用已有计数。
- Hy 和中立引擎纠正路由的 JSON 正文上限调整为 32 KiB，容纳现有字段及转义后的 1000 字符。保留字段白名单、长度和修订校验。Hy 表单按 Unicode 码点计数，遇到 HTTP 413 显示“操作未执行”并保留草稿供修改。
