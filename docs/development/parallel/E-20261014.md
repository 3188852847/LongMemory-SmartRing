## 实现与理由

| 页面 | 实际改动 | 保留的边界 |
|---|---|---|
| 记忆 | 浏览、每日回顾、整理状态、重复／关系复核、运行期开关分任务进入；列表集中搜索筛选；URL 保存层级、查询、筛选与页位置；详情链接与来源按钮可用键盘打开 | 原删除、重置、清除确认及人工纠错／事实变化流程；关系预览仍只在点击后调用 |
| 记忆质量 | 默认问题队列；日常提取、L1 与 L2 影子判断独立入口；筛选与分页可恢复；所选圆屏／影子详情形成深链接 | 复核与人工支持集合规则未改；读取失败不等于空结果、未启用或判断通过 |
| 场景 | 搜索／状态／列表集中；整理账本独立入口；保留详情抽屉；URL 保存查询、状态与所选条目 | 本地搜索只覆盖当前状态已读取的最多 100 条，页面明确显示范围；候选与模型二次确认未改 |
| 画像 | 统一画像、依据候选、整理状态分开；候选增加已加载内容搜索；URL 保存任务、查询、状态与所选条目 | 用户声明／系统推断与原始证据保留；画像和助手角色保持独立 |
| 设备 | 常用音量、显示、中止与最近操作优先；连接能力可展开；详细时序、预测影子和自然打断另入诊断；快照后置 | 固件未上报能力继续禁用；保留历史快照、超时核对、服务端发送与设备回执区别；没有新增控制 |
| 实验 | 档案与逐题比较优先；运行实验与 L1 回放单独入口；URL 保存筛选、页位置、档案和题目；宽窗同题回答／证据并排，窄窗单列 | 原预算、网络确认、未知写入结果与人工复核保留；各列脏状态分别记录；切档案、题目、署名、前进返回、离页／关闭时保护未保存复核 |

`DataWorkspace` 的任务采用原生按钮导航，隐藏面板保留挂载、草稿与各自滚动位置，隐藏内容不占键盘焦点。局部 `data-workspace.css` 使用既有 `--surface`、`--border-strong`、`--text`、`--accent-soft` 和圆角变量；不覆盖全局 `main`、AppShell 或动态层。

URL 仅保存浏览坐标，不持久化详情正文、模型结果或未保存草稿；按任务切换加入浏览器历史，普通筛选替换当前坐标。现有 `memory_id`、`l0_message_id`、`scenario_id`、`persona_id` 深链接继续可用。质量页新增 `record_type=round|l1|l2` 与 `record`，实验新增 `run_id` 与 `question_id`。无效分类回到默认任务；条目不存在时显示真实读取失败。
