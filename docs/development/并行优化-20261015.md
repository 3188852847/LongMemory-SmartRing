- P：精简每轮聊天常驻操作；首次术语以日常名称解释，研究标识仍可追溯；实验首次空状态能到达真实准备步骤；后台预览接入已经取得的固定 Otto 原图及与 0015 对齐的状态规则。保留原几何/皮肤/壁纸入口与各自生效边界，不把网页选择伪装成真机同步。真实浏览器验证 1366×768、1440×900、390 窄屏、大字号、键盘和减少动态；保留原 R1～R4 修复。
- Q：只用实际调用和显式关联标识串起可观察语音阶段；展示关联缺失、不同进程和未确认设备播放，不用时间相近补出成功。为历次进程日志提供累计容量核对与可执行保留方案，默认只读/预演，不清理既有日用日志。孤立合成服务检验传播、并发隔离、失败/取消/未知结果、无正文/密钥泄露与非阻断降级；未接入的真实阶段如实列出。现有 HTTP 请求 ID 的信任和认证语义保留。
- R：核对既有问题队列、修复/补记和评估接口，提出修复证据→召回验证→回答验证的最小方案，说明版本、状态、成功标准、失败/证据不足、幂等、并发、持久化、撤销和可回退边界。第一阶段不调用模型、不导出个人样本；实现/API/迁移均标为提案。ROADMAP 将 A～J 与 0015 的实际完成状态和本轮进行中区分，保留真实克隆试听、远程 CI 和长周期证据边界。

## 并行接口与运行约束

- 每次终端显式 `workdir` 指向自己的工作树，编辑用绝对路径；检查导入源码来源。不得在主检出编辑、构建、启动或修改产物。主项目解释器可只读复用，Python 3.12 / Node 24.19.0 / pnpm 11.19.0 和原锁文件保持。
- P 的 Otto 资源沿用官方固定提交与既有 `upstream.json` 清单；只允许读取该确定目录的固定资源，需核对指纹、类型、大小，沿用控制台认证与安全边界。可为真实 Otto 资源做一次只读外部输入绑定，其余 `local/`、个人配置/对话/音频/备份均不可读。无现成资源时完成实现并报告，不自动下载。
- P 独占 API `server.py` 注册入口；Q 若需要新工厂参数或共享客户端改动，交付精确建议/独立补丁，由主会话串行安排，不越界提交。P 不改观测接口，Q 不改预览接口。业务契约变更先核实真实调用者，不编造 API、日志阶段或固件控制能力。
- 不触碰日用 8767/8000/8003 等服务，合成数据、Fake 模型、离线设备替身及独立端口验收；不打开串口、不重启/烧录圆屏、不改私有配置或个人库、不启用影子复核/整理/主动调度，不删除既有日志。
- 外部源码、依赖、模型和素材的安装/下载由所有者执行；不得自动联网安装、升级锁文件、联接共享可变 node_modules。缺依赖先做不依赖它的工作，提供精确安装命令，由主会话汇总验证。
- P 用 ui-ux-pro-max、web-design-guidelines 等适用技能及真实浏览器操作复核，动效保留数码世界方向及减少动态设置；所有会话文档按 project-doc-maintenance 技能窄维护。
- 每会话仅提交自己分支，不 merge main、不推送、不向其他会话发消息。报告改动、验证命令/结果、未验范围、源提交及跨会话集成点；主会话审查、整合、回归和推送。交付、验收、合入且无剩余任务后归档，工作树/分支/证据保留。
