# V0.1 评估计划

分别观察：

- 写入：应记内容是否写入，不应记内容是否被过滤。
- 持久化：进程重启后 L0/L1 是否仍存在。
- 检索：相关记忆是否进入候选结果，无关记忆是否被抑制。
- 回答：最终答案是否正确使用记忆。
- 可追溯性：L1 是否能定位到 L0 来源。

实验记录必须包含代码版本、配置、模型、数据集版本和运行时间。

## 当前最小实现

`python -m longmemory.evaluation.runner --provider fake` 在固定合成数据上运行两组：
有回答记忆上下文、无回答记忆上下文。两组保留相同的存储和检索过程，使用相同评分真值。
这是一项上下文消融，不是系统级禁用记忆。无上下文组答不出已记忆事实会如实计为未答对。

写入、持久化、检索逐项精确检查；最终回答用关键词和拒答短语做初筛，保留合成原回答供人工复核。
报告记录源码/数据/提示哈希、Git 版本与脏状态、Python/SQLite 版本、模型参数与运行起止时间。
真实模型的服务端采样策略未核实，不保证确定性；后续需要重复运行与人工评价。
Fake 的小样例结果仅验证工程流程，不作为真实模型的研究结论。

## 问句与拒答回归（2026-09-03）

- v1 保持不变，v2 增加无问号输入，避免把标点规范当作用户或 ASR 的必备条件。
- 评分器 lexical-v2 增加拒答措辞覆盖，输出初筛原因与人工复核标记，并记录评分器哈希。
- “没有匹配到拒答短语”不等于“发生幻觉”；匹配到拒答也不能排除后文猜测、否定嵌套等情况。
- 不根据模型结果修改题目真值；旧报告不覆盖，不将不同数据集或评分器版本的总分直接比较。
- 问句识别仍为有限规则，存在歧义、引述、间接问句等误判风险；混合提问与陈述暂时整段不提取，优先减少错误事实写入。
