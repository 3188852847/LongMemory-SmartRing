# 系统架构总览

更新：2026-10-14。本文维护当前进程、职责与数据边界；操作见 [使用说明](../guides/使用说明.md)，时序见 [运行流程](workflows.md)，计划见 [ROADMAP](../../ROADMAP.md)。[整理前完整总览](../history/current-docs-before-20261014/docs/architecture/overview.md)保留阶段论述和旧状态，历史 ADR 不改写。

## 定位与现状

系统是单用户的长程记忆研究与日用陪伴助手。SmartRing-Plus 是智能圆屏终端，负责采集/传输/显示/播放；设备、小智、供应商与记忆算法解耦。原日用文字、记忆与语音有恢复记录，完整 V1 发布、长期质量与硬件负例不因此自动完成。

个人记忆包含 L0 原始证据、L1 原子事实、L2 生活场景和 L3 用户画像；派生层可追溯、可失效、可取代。助手角色与用户画像分开。外部知识不是用户事实；独立知识提供器、完整系统监控、策略通用学习仍属候选，不能把计划写成能力。

## 部件与进程归属

| 部件 | 当前职责 | 边界 |
|---|---|---|
| 中文 CMD / React 启动器 | 独立回环 HTTP 主机、Edge 应用窗口、白名单设置/动作；复用 Manager 和 Windows Job | 不依赖聊天 API 已启动；关闭窗口保留服务；只停止自有树 |
| 启动控制器 | 一个工作线程串行执行 Manager 动作，发布安全快照 | HTTP 线程鉴权/入队；旧 Tk 只兼容回退，不是当前主线程编排者 |
| React 控制台 | 聊天、管理、设置、实验、设备观察 | Python 静态托管构建产物，无常驻 Vite；认证/CSRF 边界保留 |
| LongMemory API | 网页/管理/实验编排及受令牌保护的回环 Runtime 接口 | aiohttp；未迁移 FastAPI；不自动接管小智 |
| 常驻 MemoryRuntime | 串行网页/圆屏记忆写入与召回，固定临时互动/自然管理，运行期开关 | 依赖中立 MemoryMethod，不生成最终回答；短期会话不合并 |
| Memory Core / methods | 提取、存储契约、来源/有效期、检索/上下文及可替换方法包装 | 日用模型辅助提取、关键词＋BGE 混合召回按选择装配，不绑定语音协议 |
| 小智独立进程 | Silero/SenseVoice、回答模型、设备连接、TTS/Opus 调度 | Python 3.10.20；Memory 插槽经项目桥访问共享 Runtime |
| CosyVoice3 独立进程 | 常驻模型、参考档案、提示缓存、合成/协作取消 | Python 3.10.20；GPU 合成串行，发送与后续合成可并行 |
| 控制/主动交流桥 | 受限设备控制、许可护栏、跟进和追加事件账本 | 服务器接收/发送不冒充设备播放；失败/过期不补发 |
| 圆屏与电脑预览 | 终端采集/播放/显示；浏览器模拟状态与圆形布局 | 电脑预览与0013离线编译不证明新动画在设备运行 |

主 Python 3.12.13 保持 BGE CPU；小智/CosyVoice 各自 `.venv`，不混装 torch。外部来源、固定版本和恢复摘要见 [本机目录](../guides/本机目录与依赖.md)、[语音恢复](../guides/恢复语音-20261013.md)。

## 控制与交互平面

圆屏是日用语音交互入口；网页供所有者聊天、观察、设置、补录、纠错、回滚与研究，不让逐条网页审批成为普通记忆积累必经流程。网页和圆屏共用日用库/Runtime，但短期上下文和角色配置各自管理。

React 启动器与聊天 API 不同端口：浏览器内存令牌保护固定状态/设置/动作 API；18767 保留单实例及旧本机受限控制通道。控制器只管理自有 Windows Job。发现文件、最小状态快照与日志职责分开；状态过期为未知，请求接收为排队，必须观察完成状态。见 [ADR-0177](../adr/0177-react-local-launcher.md)、[启动器契约](../development/launcher-contract.md)。

控制台通常 8767（API 默认 8765），小智设备控制桥 8766，设备 WS/HTTP 8000/8003，CosyVoice3 18770；地址和端口以配置/实际监听为准，不照抄历史 IP。回环服务不对局域网开放任意管理命令，网络/防火墙仍是显式兼容排障操作。

## 代码职责

| 目录 | 职责 |
|---|---|
| `core/` | 领域模型、异常、提取/召回/存储契约 |
| `application/` | 聊天、记忆处理与管理用例，Runtime 编排 |
| `methods/` | 中立方法契约、白名单工厂和具体封装 |
| `adapters/` | SQLite、模型和设备桥等技术实现 |
| `infrastructure/` | 配置、数据库定义/逐版本迁移、媒体和日志 |
| `entrypoints/` | CLI、API、小智入口及装配 |
| `evaluation/` | 隔离实验、评分、报告 |
| `web/react-chat/` | React Router/TanStack Query、页面/功能/公共视觉与启动入口 |
| `scripts/development/` | 启动器、恢复/同步/验证工具 |

Python 目录相对 `src/longmemory/`。入口选择具体方法，用例和 Runtime 调中立契约；L1 模型/Store 在 `core/memory/l1_atomic/`，SQLite 实现在 `adapters/storage/`，连接/定义/迁移在 `infrastructure/database/`。当前部分入口仍有编排职责，不宣称已一次性完成理想分层。见 [方法边界](method-boundary.md)、[代码健康](code-health.md)、[前端模块](../development/frontend-structure.md)。

## 数据与配置归属

| 内容 | 当前存储和约束 |
|---|---|
| L0–L3 | 电脑 SQLite；L0 不原地改字，派生记忆保留来源/时间/生命周期；用户 ASR 与内部结束提示来源隔离 |
| 会话/轨迹、网页角色 | 独立旁库；不混同个人事实，角色保存检查修订 |
| 人工模型/小智配置 | `local/config/`；选定 env 进入子进程环境，Key 不返回浏览器；小智人工来源 `xiaozhi.yaml`，厂家仅消费生成副本 |
| 启动/后端/皮肤偏好 | `local/config/preferences/`、`local/config/display/`，磁盘保存与运行生效分开 |
| CosyVoice 声音 | `local/config/voices/CosyVoice3.json`；受控 WAV/元数据在 `data/audio/voice-references/`，网页/圆屏同服务读取 |
| 状态/令牌/日志 | `data/control/`、`data/logs/`，安全元数据不取代会话或播放证据 |
| 实验/测试 | 合成库/独立端口与日用库隔离；输入、测试代码和输出各有目录 |
| 私有恢复/旧证据 | `local/archive/` 与历史实验目录；原始内容/摘要保留，不运行旧脚本覆盖结果 |

声音上传、草稿试听、保存是三步；保存由新版服务下一次合成读取，已开始片段不变。角色和声音独立，自定义声线暂不使用旧声线预生成寒暄/等待音频。旧 TTS 只精简日常界面，兼容代码/资源/测量保留。见 [ADR-0178](../adr/0178-controlled-cosyvoice-profiles.md)、[声音指南](../guides/声音设置.md)。

## 主动交流、演化和验证边界

确定性许可、定时/周期问候、明确一次性跟进、版本化习惯策略与结果事件已有受控实现；候选、授权、排队、人工已听到分别管理。语音模式沿已保留设置运行，文字模式暂停圆屏联系。通用策略学习、自动硬件播放完成证明和全系统跨进程追踪没有完成。

低频 L1→L2→L3 整理、L1/L2 充分性影子复核有默认关闭实现，当前继续关闭；旁路结果不自动过滤回答、不当训练真值。个人记忆演化与陪伴策略演化经显式编排协作，不共享可任意改写的提示/表。基线、最终问答和持久化按独立指标验收，历史研究数字不推定当前质量。

小智实时优先、只读联网工具和等待提示在语音适配层，外部结果仅在当前请求副本使用，不侵入记忆核心；见 [ADR-0171](../adr/0171-realtime-first-voice-pipeline.md)、[ADR-0172](../adr/0172-web-search-and-voice-waiting-feedback.md)。豆包是独立备用模式，跳过本地识别/回答/TTS/圆屏记忆，账号/实机验收另待，不是默认替代，见 [备用指南](../guides/豆包实时语音备用模式.md)。

SDK 5.5.4 原板型与独立重建有恢复证据；0013 在独立 ASCII 工程离线编译，未改主固件 src、未烧录。新克隆听感、新动画真机、长期陪伴质量和完整 V1 仍须独立证据，本轮文档整理未重跑业务/设备验收。
