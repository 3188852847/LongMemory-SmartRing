# 系统架构总览

更新：2026-09-04。本文描述模块、边界和数据归属；具体执行步骤见[运行流程](workflows.md)，先后顺序见[路线图](../../ROADMAP.md)。采用文字与表格，不维护图形副本。

## 1. 定位与现状

当前优先建设单用户、可定制的日常陪伴助手；独立记忆核心和研究接口保留。SmartRing-Plus 是 ESP32-S3 智能圆屏，不是戒指。已跑通的合成演示不等于长期陪伴质量验收。

已有：本机网页文字聊天、设备音量控制、记忆查看与受限 L1 删除、隔离实验中心、小智语音记忆桥。

新增最小 Windows 启动面板，统一拉起现有服务并核对控制台实例，见 ADR-0016。网页会话列表与持久恢复已实现，见 ADR-0019。未实现：网页与小智完整配置同步、完整角色/声音设置页、日常语义检索、人工纠正、主动交流和习惯识别。

## 2. 部件与进程归属

网页助手角色通过 `RoleSettings` 存入独立 `.role.sqlite3` 旁库，保存采用版本冲突检查，回答开始时固定角色快照。基础提示约束不变；不修改小智、CLI、研究回答器或 L0/L1。见 ADR-0022。

React 聊天预览在 `web/react-chat/`，开发时构建，日常由现有 Python 进程提供 `/chat-react`；不增加常驻前端服务。旧页面保留。后端只公开构建清单中的 JS/CSS，预览 HTML 使用每响应随机样式 nonce，认证与聊天 API 不变。

P2 聊天外观使用独立 appearance 模块和局部 CSS；浏览器仅保存枚举主题/字号，设置即时生效，不写服务端或记忆库。React 网页角色使用版本化旁库，圆屏角色与声音仍走小智现有配置，未同步。见 ADR-0021、ADR-0022。

防火墙面板是启动器的显式管理入口：只读查询无需主动提权；添加/撤销经用户确认，通过 UAC 单独运行原项目规则脚本。普通启动与 IP 同步不改变系统规则，后台等待不阻塞服务状态轮询。

启动面板的网络辅助层通过 .NET 枚举本机地址；显式同步调用小智现有 Python 环境，仅更新私有 YAML 的三个网络字段并备份。同步成功的 IP 保存在忽略提交的 `data/control/launcher.json`。不涉及模型服务请求；不自动调整系统防火墙或固件设置。见 ADR-0017。

| 部件 | 当前职责 | 不负责什么 |
|---|---|---|
| 网页控制台 `web/` | 文字输入、状态和记忆显示、设备操作、实验交互 | 不保存模型密钥，不直接连接圆屏控制令牌，不执行记忆算法 |
| Windows 启动面板 | 默认文字、可选语音；管理自有 Windows Job 进程树并打开网页 | 不接管已有终端进程、不探测校园模型、不迁移数据库 |
| LongMemory 本机 API | 提供本地静态页面与 API，编排网页聊天/管理/实验 | 不是小智语音进程，不自动启动小智 |
| LongMemory 记忆核心 | 当前规则提取、来源绑定、SQLite 存储、关键词召回及上下文构建 | 不负责录音、语音合成、设备播放或主动调度 |
| 方法层 `methods/` | 日常 v1 包装；隔离实验的原文分块、模型提取方法 | 不强迫未来方法使用同一种数据库或 L1 表示 |
| 小智服务（仓库外独立环境） | 语音识别、对话生成、语音合成、设备连接 | 不把专用协议侵入独立记忆核心 |
| 本机记忆桥子进程 | 接收小智传入的用户文本，返回记忆上下文 | 不负责生成小智最终回答 |
| 小智设备控制桥 | 对活动设备连接进行受限音量读写 | 不是已验证的主动播报通道 |
| 智能圆屏 | 采集、传输、显示、播放 | 不存放项目长期记忆库、不运行本项目评估 |
| 模型接口 | 按所选配置生成回答；隔离实验可做提取 | 不自动知道本地库内容，只有收到的上下文可供使用 |

LongMemory 与小智使用独立 Python 环境。共享数据库文件不代表共享同一个进程或临时会话。当前没有额外独立的常驻 Memory HTTP 服务。

控制台默认本机访问，操作指南示例端口 8767（程序默认 8765）；小智音量桥为本机 8766；设备侧 HTTP/WS 使用小智配置的 8003/8000。端口可受实际配置影响，不把说明中的 IP 当永久地址。

## 3. 代码职责

| 目录 | 用途 |
|---|---|
| `src/longmemory/core/` | 领域模型、存储契约、提取/召回职责，不绑定网页或圆屏 |
| `src/longmemory/application/` | 聊天、记忆处理与管理用例 |
| `src/longmemory/methods/` | 可替换方法契约、白名单工厂和具体方法封装 |
| `src/longmemory/adapters/` | SQLite、模型与设备桥等外部技术实现 |
| `src/longmemory/infrastructure/` | 配置、数据库连接、schema 与日志 |
| `src/longmemory/entrypoints/` | CLI、本机 API 和小智管道入口；API 目前仍承载部分网页编排 |
| `src/longmemory/evaluation/` | 隔离实验、评分与报告，不是日常回答路径 |
| `web/` | 当前 HTML、原生 JS 与本地 CSS；框架尚未重选 |
| `scripts/development/xiaozhi/` | 既有小智准备、启动与受限设备辅助工具 |
| `datasets/` | 可版本化的合成或公开评估输入 |
| `experiments/` | 实验配置、独立运行状态和结果 |

依赖原则：入口编排用例，用例调用核心契约，适配器实现技术细节。当前不是一次性完成的理想分层，后续随功能增量整理，不为目录美观重写全部模块。

## 4. 数据与配置归属

| 内容 | 当前归属与限制 |
|---|---|
| L0 原始消息 | 电脑 SQLite；文字路径保存双方角色，小智桥目前仅归档用户 ASR 正文 |
| L1 长期事实 | SQLite，带来源；当前精确去重，未实现完整冲突更新 |
| 网页临时会话/轨迹 | 服务内存；原始消息落库不等于会话列表可恢复 |
| 小智短期上下文 | 小智连接侧独立管理，不与网页自动合并 |
| 助手角色 | 已有提示文本与启动配置；不是用户画像 |
| LongMemory 模型配置 | 本地 `.env`/环境和启动参数；不把密钥交给浏览器 |
| 小智配置 | 独立环境的私有 YAML；与网页未自动同步 |
| 实验数据 | 独立实验目录与状态；日常库不自动进入实验 |
| 网页角色 / 外观 / 未来习惯 | 角色在 `.role.sqlite3` 旁库；外观枚举在浏览器；习惯存储尚未实现 |

网页和圆屏显式指向同一日常库时可以共享长期记忆，但召回失败仍可能导致“不记得”；不能只凭一次答错判断库不共享。日志不是全量可恢复的会话档案。

## 5. 已有实验能力与日常能力的区别

隔离实验已验证过模型提取及本地 BGE 冻结语料检索；当前日常路径仍是规则提取与关键词检索。实验接口、固定档案和报告继续保留，暂停扩建不等于删掉测试。

日常管理页仍围绕现有 L1，不宣称对任意外部论文方法都能直接管理。SUPERSEDE 的预留语义不等于纠正用例已可执行。

## 6. 拟议扩展（未实现）

- P1：运行管理负责启动、状态、停止；会话恢复单独处理持久化。统一配置需明确权威来源，不盲目覆盖小智 YAML。
- P2：设置用例负责保存/预览/回退；外观、助手角色与语音参数分开。具体前端框架后定。
- P3：日常记忆策略升级与纠正入口；迁移、索引建立和旧数据处理另行设计。
- P4：主动触发、投递和取消独立于记忆检索；设备投递通过适配层，离线或过期不冒充成功。
- P5：习惯只来自允许观察的数据，保存推断状态和确认结果；不因没有聊天推断用户情绪或行踪。

## 7. 安全和变更约束

控制台保持本机访问、同源/CSRF 校验、受限资源和动态纯文本渲染。真实数据、音频、密钥与本地配置不提交 Git。当前学校 HTTP 接口存在明文风险，不因产品化自动适合发送敏感信息。

删除 L1 不会删除全部 L0；暂停写入不等于暂停聊天归档。批量删除、数据库迁移、索引重建或固件烧录需说明影响并确认。主动问候、开机自启和新增外部传输默认不启用。
