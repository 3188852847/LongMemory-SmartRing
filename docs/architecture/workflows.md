# 系统运行流程

更新：2026-10-14。本文按当前日用入口组织流程；各阶段的完整技术说明保留在 [整理前流程](../history/current-docs-before-20261014/docs/architecture/workflows.md)和对应 ADR，不重写其历史结论。职责见 [架构总览](overview.md)，命令见 [使用说明](../guides/使用说明.md)。

## 启动、状态与停止

1. 中文 CMD → 内部 Start.cmd → 主 Python 的 `web_app.py`，建立回环单实例及 React HTTP 主机。
2. 读取 `local/config/` 偏好/后端指针，打开 Edge 应用窗口（失败回退默认浏览器）；此时聊天 API 可以尚未运行。
3. 明确开启 → HTTP 白名单鉴权/入队 → 控制器工作线程串行交给 Manager → 预检已有环境、库、配置与端口 → 创建本次拥有的 Windows Job 进程树。
4. 语音模式按所选后端启动声音/小智与控制桥；人工小智 YAML 完成校验后生成厂家消费副本。控制台、桥与声音健康分别显示，不把声线预热/设备上线合并成“已就绪”。
5. 状态快照原子刷新；控制台核对实例和新鲜度，过期/损坏为未知。React 状态轮询只读，不隐式启动或重试。
6. 明确停止 → 停止自有树 → 等终态；停止并退出再结束控制主机。窗口关闭只失去页面，服务继续；外部终端进程不被接管。

React HTTP API 与 18767 本机受限控制通道分开；后者仍仅状态/启动/停止。令牌发现文件不作普通配置，最小快照不含凭据；固定请求 ID/阶段日志只含安全元数据，请求成功可能仅表示排队。详见 [启动器契约](../development/launcher-contract.md)。旧 Tk 主线程流程仅用于兼容回退，不是当前编排路径。

## 网页文字聊天与共享记忆

1. 浏览器使用本机会话/CSRF 发消息，持久会话在旁库管理，服务端冻结本轮角色/请求身份。
2. 常驻 Runtime 先保存用户 L0 来源，按生成开关和方法选择形成/去重 L1；明确控制句走保守管理路径。
3. 按注入开关，在同一查询时刻筛选有效事实；当前默认关键词＋本地 BGE 混合召回，可受控加入 L2/L3 及固定互动指令。
4. 构建有限证据上下文，调用当前回答模型；回答/轨迹保存在会话旁库，来源可检查，模型失败不编造成功。
5. 网页展示回答和实际记忆操作回执，恢复会话不等于合并圆屏短期上下文；新聊天不删长期记忆。

写入关闭仍保留 L0；使用关闭不召回/注入、不删除库。开关仅本次 Runtime 生效，下一轮应用；重启恢复开启。模型辅助提取失败保留来源并显示降级；提取尝试账本追加阶段/原因/数量，不复制正文。失败项显式重提取沿原 L0 增加新尝试，不能把未完成解释为“不值得记”。

## 圆屏语音与实时等待

1. 圆屏连接已配置的小智，采集 PCM/Opus；Silero 判停、SenseVoice 听写在小智环境执行。
2. 可选实时优先预识别仅处理有限快照，正式端点核对通过才沿原路径提交；旧话轮/候选不能冒充新用户输入。
3. 小智 Memory 插槽通过受令牌保护的回环接口访问同一 Runtime/日用库；网页与圆屏长期记忆共享，短期会话仍独立。内部静默结束提示按来源隔离，不写 L0/L1。
4. 小智将召回上下文交给所选回答模型，语音表达/只读搜索工具只作用于当前请求副本。等待提示经适配层缓存 Opus 入队，不入记忆核心。
5. 自然标点切段/短开头合并 → CosyVoice3 本机声音服务 → 音频转换与 Opus 调度 → 圆屏发送/播放。GPU 合成串行，已就绪发送与后续合成可并行；话轮身份过滤过期音频。
6. 用户插话走原打断与取消流程；服务端合成/发送回执不证明扬声器播放。声音协作取消不承诺即时 GPU 抢占。

原主链路恢复与所有者实机结论见 [语音恢复](../guides/恢复语音-20261013.md)；实时优先/联网等待细节见 [圆屏实时优先](../guides/圆屏实时优先.md)、[联网与等待](../guides/圆屏联网与等待反馈.md)。0012 持久会话行为见 [ADR-0174](../adr/0174-round-screen-persistent-control-session.md)，以实际设备版本/能力与验收记录为准，电脑编译不能推定设备已支持；0013 新动画未烧录。

## 声音、角色和外观设置

| 操作 | 流程及生效边界 |
|---|---|
| CosyVoice3 参考声音 | 上传受控 PCM16 WAV/准确原文 → 入库但不选择 → 编辑草稿 → 固定文本试听但不保存 → 修订校验保存 → 下一次合成读档案；旧服务按提示重启 |
| 声音一致性 | 网页/圆屏读同一服务档案；已开始片段保留旧快照；自定义声线不用旧声线预生成寒暄/等待音频 |
| 网页助手角色 | 读取修订 → 草稿/预设 → 明确保存 → 版本检查 → 下一轮冻结角色快照，不改个人事实 |
| 圆屏角色 | 独立预检 → 明确确认 → 私有配置摘要/备份 → 仅写 prompt → 回读 → 按提示重启/实机检查，不由网页角色自动同步 |
| TTS 后端/模型档案 | 保存下次启动指针 → 显式停止重启 → 核对进程当前 provider/档案；Key 读取不返回浏览器 |
| 浏览器外观 | 枚举偏好在浏览器即时生效，启动面板与控制台不同端口，不假定自动跨端同步 |
| 圆屏皮肤/壁纸 | 电脑预览与保存/下发分开；活动壁纸可覆盖皮肤，切换的设备回执另检查，不因此烧录 |

声音相似度、风格遵循、实际延迟与播放另行试听；TTS 固定测试只检查适配器交付能力/音频，不冒充设备 AEC 或首声。详见 [声音设置](../guides/声音设置.md)、[角色设置](../guides/助手角色设置.md)、[外观设置](../guides/外观设置.md)、[壁纸库](../guides/round-wallpaper-library.md)。

## 记忆管理、整理与质量观察

2026-10-19 新后端的替换流程是显式装配 → 平台原文归档 → 方法组合投递 → 方法召回/中立管理；失败保留来源，恢复不自动重放。下表继续描述旧引擎能力；新后端不支持时明确拒绝，不回落旧库，见[方法边界](method-boundary.md)。

| 任务 | 当前流程与限制 |
|---|---|
| 查看/补录 | 按筛选查看来源/时间；明确自指事实补录保留 L0 管理来源，遵守生成开关 |
| 纠错/事实变化 | 校验目标和修订 → 追加新事实/取代旧项或写有效区间，不原地改历史 |
| 自然删除 | 回读唯一目标 → 两分钟内确认且目标未变 → 删除单条 L1；不清空 L0、日志或备份 |
| 临时互动/状态 | 确定性支持表达写有效期或下一轮模式；到期恢复默认，下一轮失败也消费，不猜自由表达 |
| L2/L3 管理 | 来源绑定、候选/复核/生命周期；画像读取时投影，角色与画像独立 |
| 低频整理 | 可选预算/审计/风险门控；当前关闭，不为浏览页面或采样开启 |
| 质量复核 | 网页反馈、圆屏明确反馈/回答轨迹与追加复核分别保存；复核不重答、不改 L0–L3 |
| 影子与回放 | L1/L2 充分性影子当前关闭；冻结离线回放/人工精确标签不自动开启正式门控 |

具体阶段算法/状态表、一次性跟进、临时方式、L1/L2 充分性与质量队列的原说明完整保留在 [技术流程快照](../history/current-docs-before-20261014/docs/architecture/workflows.md)。日用观察、实验代理、研究结论分开，候选充分/零错误样本不等于真实最终问答质量。

## 主动交流与一次性跟进

1. 所有者显式保存总许可、周期/定时开关、频率、时段、勿扰与话题；文字模式暂停圆屏联系，圆屏模式沿保留设置执行。
2. 后台按确定性策略选择一个到点来源，核对当前许可、预算、待回应、设备在线/空闲及有效期；失败、阻止、过期不补发。
3. L1 长期事项可建立候选；明确未来日期/时刻＋“问我”的自然请求只有唯一新增 L1 才形成候选，总许可开启时原子建一次性账本，关闭时仅候选。到点仍经同样护栏。
4. 严格改时/取消只匹配最近窗口唯一未执行自然跟进，追加取消旧安排并创建新安排；已开始不假称取消成功。
5. 小智接收为 `queued`，实机听到后由所有者人工确认才记观察 `played`；当前没有通用硬件自动播放完成证明。
6. 习惯时段候选 → 合成离线门控 → 不可变版本草案 → 显式激活/回滚 → 有限运行接线；时间关系/沉默不当满意度或异常，也不触发训练。

手动验证问候与后台问候分开；重复请求身份不重播，不暗开后台。完整日用操作见 [主动交流设置](../guides/使用说明.md#主动交流设置)，来源/策略/反馈账本的历史阶段见快照及各 ADR。

## 隔离实验、恢复与验证

实验页选择冻结档案 → 预检预算 → 明确确认 → 独立作业/报告 → 逐题比较与人工复核；Fake 只验证流程，不评价记忆质量。不自动打开个人库、不重新提取或覆盖旧报告；真实模型实验须当前授权与网络条件。

数据库恢复先精确路径/服务状态 → 一致性备份 → 版本检查/向前迁移 → 校验，删除/清空/覆盖不含在常规迁移授权。配置迁移须停止旧代码、摘要与回退核对、生成消费副本并重开正式入口，不能只刷新页面。

本轮只更新文档及核对代码，没有重跑模型/日用链路、个人库或设备。旧测量和实机成功引用原记录；新克隆、新动画、完整 V1 与长期质量须另证。固件本轮仅编译边界，无串口/烧录/monitor。
