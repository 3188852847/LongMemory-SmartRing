# React 聊天页迁移清单

## 当前状态

2026-09-04：已完成选型及环境、安全边界核对，尚未安装依赖、构建或替换聊天页。依据 ADR-0021。此文件是实施清单，不是新页面的使用说明。

当前助手环境 Node 为 24.19.0；PATH 中未找到 npm，但随附 pnpm 11.19.0 可执行。此结论仅描述助手环境，不代表用户普通终端也能直接运行这些命令。

官方 Vite 指南要求 Node 20.19+、22.12+；当前 Node 满足该最低条件，不等于完整依赖组合已经验证。antd 官方介绍说明 6.x 不再支持 React 16/17，并自带 TypeScript 类型。具体 React、antd、Vite、TypeScript 补丁版本在安装时核对包元数据并锁定，不使用未核实的“最新版本”组合。

来源：[Vite 安装要求](https://vite.dev/guide/)、[antd 介绍](https://ant.design/docs/react/introduce/)、[ConfigProvider CSP](https://ant.design/components/config-provider/)。

## 实施顺序

1. 在 `web/` 内增加独立应用构建配置与锁文件，不覆盖旧静态页。React 负责组件状态，TypeScript 检查接口形状，Vite 仅开发时构建，antd 提供基础控件。不先引入路由器、状态库或 Ant Design X。
2. 做最小安全兼容切片：按钮、输入框、选择器、弹窗、主题切换。核对生产构建及动态样式，不用开发服务器结果替代生产验证。
3. Python 增加独立预览入口和构建资源白名单；仅公开构建产物，不公开源码、锁文件、工作区或数据库。路径穿越及缺失产物应明确失败。
4. 将聊天 API 调用与页面组件分离；迁移会话列表、消息发送、证据展开和外观设置，保留下面全部语义。
5. 完成合成回归与用户体验后切换 `/chat`；启动面板继续打开同一地址。若失败，保持旧入口，不要求用户重装后端或迁移记忆库。

## 必须保留的行为

| 功能 | 对齐要求 |
|---|---|
| 会话 | 新建、选择、重命名、刷新及重启恢复；不导入未分组历史 |
| 发送 | 每次新请求独立 request_id；重复点击和网络未知状态不自动重发 |
| 恢复 | 未知结果只读查询；不能把超时解释为没有写入记忆 |
| 上下文 | 沿用后端轮数、字符和并发限制；不由浏览器重建不同历史 |
| 隐私 | Cookie 与 CSRF 沿用；本地缓存不存聊天正文、证据或密钥 |
| 内容 | 回答及证据纯文本呈现，禁止 dangerouslySetInnerHTML |
| 外观 | 主题、字号、存储不可用降级、同源标签同步 |
| 圆屏 | 不自动播放网页回答，不改变小智配置或设备连接 |

## 安全兼容检查

现有服务只允许本机地址、准确 Host/Origin 和带 CSRF 的写操作，CSP 的 script-src/style-src 都是 self。React 不要求取消这些限制。

antd 的动态 style 标签需要验证 nonce（每次响应的随机许可值）或静态样式提取方案；nonce 不自动解决 style 属性问题。检查选择器浮层、弹窗和主题切换，发现不兼容时先缩小组件使用范围，不直接全局放开 unsafe-inline。旧页面安全策略不随预览试验放宽。

## 完成标准

- 类型检查、生产构建、纯状态测试和后端安全/静态资源测试通过。
- 使用合成数据验证发送、重复请求、断线恢复、重启恢复和恶意 HTML 文本。
- 页面运行不请求第三方资源，构建资源不越出专用目录。
- 日常不需要启动 Vite；缺少构建时提示明确，不自动联网安装。
- 校园网模型、视觉交互与圆屏验收单独标注，不以自动测试代替。
- 更新指南、README 和变更日志，检查敏感内容后提交推送。
