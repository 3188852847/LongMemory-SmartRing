### 独立电源诊断实测（2026-09-03）

用户确认临时烧录后，向 COM3 写入已编译的诊断 bootloader、分区表和应用，三段均报告 `Hash of data verified`。随后通过 USB Serial/JTAG 接收数据，取得至少 5 组完整采样，寄存器读取均成功。诊断没有写入 PMIC 配置值，也没有调用厂商充电初始化。

| 字段 | 观察值 | 含义与边界 |
| --- | --- | --- |
| 0x03 | 0x4A | 与厂商 BSP 的 AXP2101 识别值一致 |
| 0x00 | 0x38 | 有效 VBUS 输入，检测到电池；未报告热调节/输入限流 |
| 0x01 | 0x33 | 电池电流方向为充电，阶段为恒压；未报告 VINDPM |
| 0x18 | 0x0A | 充电模块和电量计启用 |
| 0x68 / 0x30 | 0x01 / 0x1D | 电池检测及 VBAT ADC 启用 |
| 0x34 / 0x35 / 0x36 | 0x10 / 0x60 或 0x61 / 0x82 | 默认调试通道配置；电池电压 4192–4193 mV |
| 0xA4 | 0x64 | 芯片估算电量 100%，电量计校准未验证 |

**能够支持的结论：** 当前电脑 USB 供电、独立低负载诊断运行期间，PMIC 报告电池处于恒压充电状态，不支持此时“0% 且不充电”的判断。

**仍不能支持的结论：** 不证明之前的线缆/充电器场景都正常，不证明真实可用容量恰好是 100%，也不能直接证明小智固件和被检查源码完全一致。独立诊断替换了应用并发生重启，不能把读数当成此前小智运行时的同步测量。软件电量读取路径不匹配的假设得到加强，具体修复及恢复小智后的界面验证仍待完成。
