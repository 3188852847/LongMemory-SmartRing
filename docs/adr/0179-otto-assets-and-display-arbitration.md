# ADR-0179：Otto 资源追加与显示仲裁

日期：2026-10-14。状态：已接受实现取舍，设备验收待 K 与所有者完成。范围为 0014 固件，不修改记忆核心、音频或连接协议。ADR 是架构决策记录。

## 依据

所有者指定固定 `txp666/otto-emoji-gif-component` 表情，授权必要应用与资源更新，并要求保留配置和壁纸。21 个 GIF 约 1.61 MB，当前应用槽没有此容量；现有 assets 是自定义内存映射表，不能格式化成新文件系统。实际原映像含 23 个有效资源及来源未判定的非空白未索引字节。

## 决定

应用只保存事件仲裁和名称索引，GIF 追加到原 assets 映像。原 index.json、全部原表项逻辑字段、资源字节及整个原 payload 区域保持；新表项增加导致物理资源地址移动，现有代码按资源名称重新读取。源码核查未找到当前板型读取未索引尾部的路径，因此最小必要新增区可以重写那些未索引字节；它们的历史来源仍未核实，不记为空白或已确定的历史残留。新有效长度之后全部原字节保留，末擦除扇区旧字节带入写包，其后不擦写。完整原 assets 备份用于精确回退。容量不够、资源冲突、校验失败或无尾部核查记录时重包器拒绝生成。

Otto 默认优先显示，以 240×240 居中保留原始比例；保留壁纸分区、NVS（设备持久配置）和既有工具，新增只影响当前运行的用户显示选择。没有为了预览写永久配置。继续使用厂商 LvglRawImage/LvglGif 及现有 LVGL 9.4.0，不引入组件依赖、放大图像或双解码器过渡。立即释放旧图、先解码新首帧，避免状态响应等到 GIF 循环结束。

服务端 emotion 经兼容的 SetServerEmotion 显示方法进入本地仲裁，系统提示仍走 SetEmotion。Listening 清缓存并拒绝迟到 emotion；Thinking 缓存供 Speaking 使用；真实 Idle/Connecting 清理缓存；错误有优先级，但后续真实状态可恢复。正常音频通道关闭保持原 Idle。650 ms surprised 是展示期限，不改变真实 abort、采集或音频时序，也不增加连接/思考超时。

## 后果与验证边界

保留原协议无 turnID（回合标识）的限制：上一轮 emotion 在下一轮 Thinking/Speaking 到达时不能准确归属。设备读取旧版资源包时回退到原壁纸或几何脸；回退应用和 assets 均可由 K 按已验证原备份恢复。桌面状态、实际解码器、容量和干净编译证据见 [M 报告](../development/parallel/M-otto-firmware-20261014.md)，操作与实机验收见 [0014 指南](../guides/Otto动态表情固件-20261014.md)。这些不代替设备帧率、语音并发和个人体验验收。
