# ADR-0177：独立本机控制主机与 React 启动面板

状态：已接受。日期：2026-10-14。所有者决定启动面板采用现有 React，与网页共用视觉组件。

## 背景

Tk 的日常操作与大量配置控件同等突出，难以复用网页的视觉与交互。启动面板必须在聊天与语音服务未启动时可用，不能依赖聊天 API 才能管理该 API。

## 决定

保留唯一中文 CMD 入口，新增 Python 标准库回环控制主机与独立 React HTML 入口。沿用现有 React、Ant Design、锁文件和 Python 环境，不引入桌面包装框架。复用既有进程编排和受管服务所有权，不迁移业务或个人数据。

浏览器关闭保留服务；明确停止和退出操作分别确认。原 Tk 实现保留兼容回退，与新主机共用单实例锁，不能同时接管日用进程。旧 TTS 与角色选择退出启动页主要操作，但配置与兼容代码保留。

## 候选与后果

继续定制 Tk 无法直接复用 React 组件；新增 Electron/WebView 会增加环境和包装维护，因此本阶段使用现有浏览器。代价是浏览器页面生命周期与服务生命周期分离，需要重新打开入口和明确退出语义。

样式组件可共用，跨端口浏览器偏好不会自动同步。新的本机 HTTP 控制面需要令牌、跨站限制、静态资源白名单、设置摘要和异步停止回执，合成验收通过后再切换日用服务。
