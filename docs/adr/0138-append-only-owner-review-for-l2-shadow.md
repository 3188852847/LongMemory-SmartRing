# ADR-0138：L2 影子门控采用整轮、追加式人工复核

- 状态：已接受
- 日期：2026-09-13

## 背景

V42 已能旁路记录模型对 L2 候选证据充分性的判断，但机器自评不能直接证明门控质量。若只保存模型结果，真实日常样本无法可靠区分误放行、误拦截、问题歧义和场景正文后来变化。

## 决定

SQLite V43 新增 `l2_sufficiency_shadow_review_events`。所有者在记忆质量页对一整轮完整支持集合标记“正确、错误、暂不确定”，并从封闭原因中选择一项。每次复核追加新修订，旧结论不覆盖；提交必须携带当前修订号，陈旧页面不得覆盖较新的复核。

复核单位选择“整轮”而非逐候选：门控最终需要决定这一轮有哪些 L2 可以支持回答，任何漏掉或错误放行都意味着整轮判断错误。页面仍展示每个候选和机器原因，供所有者定位错误类型。

## 边界

- 人工复核不修改 L2、候选快照、机器原判、正式上下文或回答。
- 只接受固定判定与原因，不在新表复制问题、场景或自由文本备注。
- 写入口沿用本机 Cookie、Origin 与 CSRF 防护；列表和详情仍按需读取已有正文。
- 暂不据此自动切换正式门控，也不把复核数量冒充准确率。

## 后果

真实使用样本可以计算门控人工一致率并分类错误；代价是数据库增加一张追加表和一次 V42→V43 的可恢复迁移。后续若需要逐候选标注，应以新事件类型扩展，而不是改写现有整轮语义。
