# ADR-0146：L1 日常影子复核保存精确人工支持集合

- 状态：已接受
- 日期：2026-09-13

## 背景

V45 的所有者复核只记录整轮“正确、错误、不确定”。如果判断为错误，系统不知道哪些候选实际支持回答，因此无法计算误拦截、无证据误放行、候选精确率或召回率。只选“判断正确”的轮次做统计会造成选择偏差，不能作为门控依据。

## 决定

1. SQLite V46 为每个新 L1 复核事件冻结精确人工支持集合；空集合有独立的 `support_set_recorded` 标志，不与“旧记录没有标签”混淆。
2. “正确”要求人工集合与机器支持集合相同，“错误”要求两者不同，“不确定”不保存支持集合。服务端验证候选均属于当轮快照，并继续使用复核修订号防止旧页面覆盖。
3. 候选新增当时正文字符数，不复制正文。旧 V45 候选不根据可能已经变化的当前正文回填长度。
4. 记忆质量页只用每轮最新且带精确集合的复核计算离线门控代理；旧复核和不确定复核进入排除计数，不伪造为真值。
5. 指标仍不参与正式回答，不触发模型，不修改 L1，也不能替代端到端回答质量。

## 后果

- 新的真实日常样本可以计算误拦截、无证据误放行、不完整/过度放行、候选缩减及有长度覆盖时的上下文缩减。
- 当前开发数据库为空，V46 从零开始采集完整标签；显式 V45→V46 迁移仍保留，未来旧复核会安全显示为“无精确支持集合”。
- 在样本量、题型覆盖和所有者复核稳定性达到预设门槛前，正式 L1 门控继续关闭。
