# ADR-0018：启动面板显式防火墙操作

状态：接受。日期：2026-09-04。

背景：终端命令不符合日常入口目标；管理员权限不能成为要求用户手工敲命令的理由。

决定：新增独立窗口，查询监听和固定项目规则。添加/撤销需 UI 范围确认，再通过 UAC 单独运行现有 firewall.ps1。脚本沿用局域网、来源 /21–/32、实际 Python 监听、固定规则名和不覆盖限制。使用 UTF-8 读取脚本兼容 Windows PowerShell 5；不新增依赖。

边界：普通启动不改规则；不关闭系统防火墙，不接管其他规则，不默认扩大来源。查询失败显示未知；项目规则不存在不等于网络受阻。UAC 取消不报成功。实际 UAC 操作不作为自动测试执行。

补充 ADR-0017：防火墙依然是独立显式操作，但不再要求必须使用终端。圆屏可用则无需添加；IP 变化仍需检查圆屏配置。原终端脚本保留为排障入口。
