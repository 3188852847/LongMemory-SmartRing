# ADR-0191：Hy 等价短输入、请求内批读与网关会话复用

- 日期：2026-10-20。
- 状态：候选实现；隔离验收见 [V 记录](../development/parallel/V-memory-low-latency-20261020.md)，未部署日用。
- 范围：固定 Hy SDK 2.0.3、平台内部数值观测、自有模型网关传输。补充 ADR-0183/0184/0185/0186，不改变来源、轮次、预算或管理授权协议。

## 决定及理由

固定 SDK 的 `EmbedService._truncate_for_embedding` 独立调用 cl100k 分词器，先前 `token_count._encoder=False` 不覆盖这条路径。对普通 Python 字符串、正整数 limit，UTF-8 字节数不超过 limit 是原函数不截断的充分条件：普通 token 至少消耗一个字节，特殊 token 被默认编码拒绝后使用的字符估算也不超过这个边界。因此只在该范围原样返回并增加原 calls 计数；长文本、非法代理字符、非普通参数交还原函数。

快路径仅在实际 distribution 为 2.0.3、完整 embed 源码规范化摘要、原函数来源和常量均一致时安装于独占 worker 的内存引用；不匹配保留原实现。退出恢复引用，所有权变化拒绝覆盖。没有写 site-packages、升级依赖、改变向量输入或跨轮缓存答案。

通过全部固定SDK源码检查后，启动期另做纯本地准备：导入并解析公开 `AsyncOpenAI` 类、用固定非事件文本初始化中文分词。不实例化模型客户端、不调用add/search/LLM/embedding，也不创建事实或来源事件；分词LRU及其原有jieba临时缓存仍位于独占worker与受限TEMP内。准备失败仅记录固定失败标记，原首次调用仍使用原异常/降级路径。启动时间单列，不能把前移的初始化当作总成本消失。

一次 recall 将所有可见版本的管理来源/不确定状态用同一个 SQLite 连接、每批至多350个ID读取；每个ID维持原时间和 request_id 排序。仍处于原方法互斥锁内，管理扩展使用同一锁，跨请求重新读取，不跳过 uncertain 隔离。所有者锁约束仍有效；不声明跨多个 SQL chunk 的独立数据库事务快照。

自有模型网关持有一个端点/凭据独占的 HTTP 会话及事件循环，普通 Hy 提取请求和语音流式回答共用连接池，闲置连接上限120秒。首次实际请求才创建资源，不主动发送 ping 或模型保活；完整消费响应才可回收连接，未读完、取消和失败关闭响应。HTTP/1.0、服务端关连接或闲置超时允许自然重连；一次请求失败不重试。关闭网关取消活动任务、关闭会话并回收线程，失败显式报告。活跃标记继续参加网络维护生命周期判断。

预算 reserve/finish、最坏 unknown、免费政策、usage/DONE 判定、流式逐片转发、固定提示及请求消息顺序保持。不是服务端 KV（键值）前缀缓存，也没有启用校园 HTTP/2；原 `voice_http_transport` 的官方地址守卫保持。

## 数值观测边界

显式内部头 `X-Memory-Observe: 1` 和已有匿名轮次触发一次观测；原响应 body、严格 v6、SDK 方法参数和原业务调用次数不变。匿名关联经 JSONL 顶层字段进入 worker，通过 SDK 既有 loop 传播，再由最多4096字符的内部响应头返回提供器。只接收版本1、同轮次、固定阶段名及有限数值/calls；不含正文、凭据、设备或条目ID。

Runtime 用中立 timing_callback 报告外层锁/入口；API 记录原 to_thread 排队与准备；SDK 观测包装仅在固定版本和五个源码摘要通过后安装。未执行阶段缺省，不能写成零延迟。阶段存在包含关系，不能相加当端到端。消费者取消与迟到线程的物理返回分别保留原轮次；日志不是业务提交回执。

## 迁移、代价与回退

worker/process_client 的源码改变使 `management_primitives_identity()` 更新，并将新增 short_embedding_input/sdk_observation/observation 三个传递依赖一同绑定，不能只证明import语句。旧管理验证文件应按原规则拒绝；整合方需在同一最终代码重新执行真实 SDK 合成管理验收并签发证明，V不修改日用证明或私有配置，也不自动开放管理权限。

持久会话增加一个按需线程和有界行队列（32条），需要显式生命周期管理；连接复用不能保证远端保留连接或降低模型计算时间。不能把本机合成结果外推到校园 TLS、排队、真实 BGE、TTS 或设备播放。

回退可撤回此阶段提交；不删库、清缓存或重建索引。状态身份、库格式和来源账本没有迁移；快路径不匹配时自然保留原SDK行为。需要管理能力时仍须与回退后的代码摘要匹配的新证明。
