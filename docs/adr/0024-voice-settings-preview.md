# ADR-0024：本机音色设置与固定文本试听

状态：接受，2026-09-04。

## 决定

P2 复用已有 Edge TTS，不安装另一个语音模型。React 聊天页提供四个音色选择、固定文本联网试听和显式保存。沿用本机认证及 CSRF，不接受任意文本、路径或进程。

试听通过固定小智 Python 子进程运行，30 秒超时、2 MiB 上限、不自动重试；音频只经内存，浏览器 Blob 播放，关闭和更换时释放。仅 React HTML 的 CSP 增加 `media-src blob:`。

保存仅替换 YAML 的 TTS.EdgeTTS.voice 标量，拒绝远程配置、private_voice 覆盖、歧义 YAML、记忆库或项目不匹配。与角色同步复用排他锁、原文备份、摘要冲突检查及原子替换。不自动重启。

## 后果

不改数据库、记忆算法、固件或依赖。服务商标准音色不是角色克隆；默认参数试听不保证与圆屏一致。配置成功不代表运行生效，需重启和实机验收。网络依赖、私有备份管理仍有成本。
