# ADR-0157：CosyVoice3 固定参考预计算与流式步长复位

## 状态

已接受，2026-09-14。补充 ADR-0126；撤回其中“分块实现已经足以满足日用首声”的阶段性推断。

## 背景

真实日用反馈再次确认声音出来仍然偏慢。当前常驻服务的热态短句探索性测试中，8～12
个汉字从请求到首个模型音频块约为 1.83～2.30 秒，且每句只产生一个块；这还不包含
回答模型、圆屏网络、设备缓冲和扬声器开始播放。

本机固定版本的 CosyVoice3 源码显示两处可避免的请求期工作：

1. 未指定 `zero_shot_spk_id` 时，每次请求都会重新计算固定参考提示的文本 token、语音
   特征、语音 token 和说话人向量。
2. CosyVoice3 流式模型以训练要求的 25 token 为初始步长，但产出后会把实例字段逐步
   放大到 50 和 100。该字段跨请求保留，后续短句可能等到整句结束才返回唯一音频块。

## 决定

1. 服务启动后把项目既有官方参考文本和参考 WAV 注册为进程内命名音色；完整 WAV 与
   分块接口都通过该 ID 复用预计算结果，不改变参考素材、音色或请求文本。
2. 模型加载后保存其原始流式步长，并在每次合成前恢复该值。当前值为 25，来自上游模型
   初始化和训练 `static_chunk_size` 约束，不使用更小的未经验证步长。
3. 健康接口只公开“参考已预计算”和流式步长，不公开参考音频路径或内容。
4. 圆屏时序保留最近一次真正发出音频的脱敏样本；紧随其后的空识别或心跳轮次不再覆盖
   它。仍不记录问题、回答、音频、设备标识或句子 ID。
5. 自动测试只验证复用、复位和状态契约。速度改善必须在重启常驻服务后重新测量，并由
   真实圆屏体验确认；在此之前不得写成已达到日用门槛。

## 后果

- 固定参考的重复预处理被移出日常请求，流式首块行为不再依赖此前回答的长度。
- 模型自身生成首批语音 token 的固定成本仍然存在，本次修改不保证达到目标速度。
- 如果复测仍慢，下一步应分别比较回答模型首输出、TTS 首块、网络与设备播放边界，再评估
  CosyVoice3 可用的推理运行时优化；不通过引入更多 TTS 候选扩大 V1 范围。

## 回退

移除命名音色注册、请求 ID 和步长复位即可恢复 ADR-0126 的原始服务行为；不涉及配置、
个人记忆、数据库或圆屏固件迁移。EdgeTTS 继续作为已有稳定回退。
