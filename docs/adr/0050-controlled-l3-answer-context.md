# ADR-0050：L3 画像通过独立开关受控参与回答

状态：已接受

日期：2026-09-06

## 背景

已接受 L3 此前只能在管理页查看，网页和圆屏回答仍只使用 L1 及可选 L2。直接注入全部画像会放大无关信息、过期事实和上下文成本，也会在升级后无提示改变日常回答。

## 决定

1. 新增技术中立的 L3 召回契约和 SQLite 只读适配器，只读取 `active` 且处于有效期内的画像。
2. 第一版使用可解释的关键词相关性，最多 3 条、总 L3 上下文最多 1200 字符；无关键词重叠时不注入。
3. L3 使用拥有独立运行期开关，默认关闭；网页与 SmartRing-Plus 圆屏终端共享同一个常驻 Runtime 状态。关闭总记忆使用时，L2/L3 即使开关为真也不召回。
4. 每轮轨迹单独返回画像 ID、类型、依据、标签、断言、L1/L2 来源引用和底层 L0 消息 ID；L3 正文不会混进 L1 的 retrieved 列表。
5. 设置仅在当前进程有效，服务重启恢复关闭。此切片不改变数据库、不自动生成画像、不启用 L3 自动整理。

## 后果

用户可以显式体验 L3 对网页和圆屏回答的影响，并能核对本轮究竟使用了哪条画像及其来源。关键词方法可解释但会漏掉改写问题，后续可在冻结回归下替换为混合召回；替换不得改变开关、预算和轨迹契约。
