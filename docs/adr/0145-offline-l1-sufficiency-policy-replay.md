# ADR-0145：先离线回放 L1 充分性策略，不直接启用门控

- 状态：已接受
- 日期：2026-09-13

## 背景

V45 已能旁路记录 L1 候选支持判断，但“影子模型判断正确”不等于把它接入正式回答一定有净收益。正式门控至少会产生两种高风险错误：把原本可回答的问题拦成无证据，以及把并不支持答案的候选继续放行。候选减少也只能表示上下文缩减，不能直接解释为回答质量提升。

## 决定

1. 新增 `l1-sufficiency-policy-replay-v1`，只消费已完成的冻结 L1 充分性报告，不调用模型、不访问个人数据库，也不修改日常 Runtime。
2. 假设策略只保留被判定支持回答的 L1，并分别计算支持集合精确匹配、误拦截、无证据误放行、不完整放行、过度放行、候选数量和上下文字符缩减。
3. 来源报告以 SHA-256 绑定；输出记录代码版本、来源协议、数据集身份、模型身份和固定限制。失败样本保留在固定分母，不自动重试。
4. 实验中心提供本机按钮、冻结来源选择和指标展示。服务只接受白名单目录名与 UUID 请求 ID；结果未知时复用同一 ID，防止重复生成。
5. 开发集结果只用于验证工具链和发现策略风险。它已经参与过标注修订，不能当作最终实验或产品准确率；留出集仍保持锁定。

## 后果

- 当前开发报告回放完成 16/16，误拦截 0、无证据误放行 0；26 条原候选保留 11 条，候选减少 57.7%，上下文字符减少 55.1%。
- 上述数字来自小型合成开发集和已有模型输出，不代表真实聊天、最终回答或端到端延迟改善。
- 下一步可让同一统计协议消费带所有者复核的日常影子样本；在真实或冻结留出证据形成前，正式 L1 门控继续关闭。
