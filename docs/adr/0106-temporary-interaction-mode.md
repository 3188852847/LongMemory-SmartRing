# ADR-0106：临时互动方式使用可追溯固定指令

## 背景

长期“倾听为主/先问再建议/直接分析”已经可以作为助手设置或 L3 互动偏好，但用户在某一天可能只想被倾听。若直接覆盖长期角色，第二天不会自动恢复；若把任意记忆正文当系统提示执行，又会形成持久提示词注入风险。SmartRing-Plus 圆屏终端是产品入口，也不能要求用户到网页审批这种低风险、明确且可自动到期的选择。

## 决定

1. 第一版只接受六条固定完整表达，映射到 `listen_only`、`ask_before_advice` 或 `direct_advice`；句尾标点可忽略，附加文字、近义猜测和模型推断不触发。
2. 明确表达仍按 ADR-0105 保存为带当天有效期的 L1，并保留直接 L0 来源；不新增互动设置表，不覆盖长期角色或 L3 用户画像。
3. 日常 Runtime 每轮从当前有效 L1 的用户 L0 来源中选择最新一次明确设置。最新设置到期后恢复长期默认，不让更早的临时设置重新生效。
4. 交给回答模型的行为上下文只能来自代码内三段固定文本，不复制或执行用户原话。当前消息若明确索要建议，可覆盖“只倾听/先询问”的默认动作。
5. 临时互动来源作为实际使用的 L1 加入回答证据索引；网页与圆屏因此能沿现有 G2 链路核对来源。
6. 暂停“使用已有记忆”时临时互动方式也停用；暂停 L1 写入时不会新建临时设置。它不绕过角色基础约束、安全规则或模型失败处理。
7. 本功能不需要网页确认、数据库迁移或圆屏固件更新。真实模型是否稳定遵循、圆屏措辞和使用舒适度仍需日常体验验证。

## 后果

- “我今天只想让你听我说”可跨会话和服务重启保持到当天结束，随后自动恢复长期偏好。
- 系统能解释某轮为何采取某种互动方式，而不是只留下不可追溯的临时提示词。
- 第一版表达覆盖刻意很窄；自由说法、显式提前取消以及“仅本次回答”仍未实现。
- 这是日常产品编排能力，不改变冻结论文方法或实验条件。

## 状态更新

ADR-0107 已用两条固定表达补充“当天恢复默认”，因此本 ADR 所述“提前取消未实现”不再适用于整日模式；自由表达和“仅下一轮”仍未实现。
