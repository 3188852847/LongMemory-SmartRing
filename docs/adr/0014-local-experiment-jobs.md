# ADR-0014：本机冻结检索回答作业

- 日期：2026-09-03。
- 状态：接受并实现，扩展 ADR-0013 的只读实验范围；不改原报告、方法与评分协议。
- 背景：用户希望在实验中心完成启动和进度查看，而不继续用终端拼接实验参数。

## 本阶段范围与完成条件

In Scope：一条已验证工作流——冻结检索后的回答对照。选择开发集检索档案、Fake/已配置兼容模型、字符预算；预检并确认；单作业进度、停止后续题、返回原结果查看/复核。保留命令行入口。

Out of Scope：任意命令/路径、上传报告、自动提取/编码、留出集运行、自动重试/续跑、并行队列、论文方法管理、费用估价、自动评分裁判、个人记忆库或圆屏算法变更。

Definition of Done：复用 runner 且旧测试不回退；明确确认前不联网；认证/CSRF 和来源校验有效；重复请求不能新建重复作业；中断不续跑；Fake 贯通新报告和现有查看页；文档与 Git 同步。真实校园调用由用户操作，不把 Fake 当质量验收。

## 方案选择

采用现有 aiohttp 进程内的单工作线程，不引入任务队列、数据库、前端框架或子进程命令拼接。核心 runner 仅增加可选的进度通知、停止检查和预检来源摘要约束，旧 CLI 默认行为不变。

前端已经达到状态复杂度复审信号。本次重新评估后保留原生模块：作业流程独立在 `experiment-jobs.mjs`，与人工复核草稿隔离，进度只有单作业轮询，不建通用任务平台。若新增并发队列、多流程动态表单或共享作业编辑器，应重新选型，不继续堆叠状态标志。

## 启动边界与成本

- 启动服务必须显式加 `--enable-experiment-runs`。模型只从后端启动环境读取，网页不能传 URL、Key、模型名或命令；查看/预检不发模型请求。
- 只从固定实验目录选择完整开发集检索报告；根据原报告 SHA256 寻找唯一父比较档案，使用项目固定合成数据集。嵌套文件拒绝链接/junction，目录检查上限 1000 项、256 MiB。
- 复用协议完整校验，预算最多 64 次回答（现有四组 × 8 题为 32 次）、1–16000 字符；固定四组，不任意删组/选题刷分。
- 预检结果绑定来源目录摘要、报告、数据集、模型配置、当前本机会话，10 分钟失效，内存最多保留 32 份；启动重新检查，worker 第一次模型调用前再次核对确认时的冻结目录摘要。
- 确认页展示模型、目标主机、请求上限、字符预算、单次 max_tokens/timeout。真实模型和明文 HTTP 需额外明确接受；没有单价，不能提供真实费用结论。
- 初次打开默认 Fake。网络失败不重试、不自动改模型。模型配置缺失明确禁用真实选项，不用 Fake 冒充真实模型。

## 进度、幂等与中断

- 作业小台账保存到 Git 忽略的 `experiments/jobs/<请求UUID>.json`；新结果由原 runner 写入新的 `experiments/runs/retrieval-answers-<UUID>/`。原报告/复核不覆盖，个人库不打开。
- 台账先写临时文件再原子替换。模型调用前记录尝试数，回答后记录成功/失败；进度不输出模型错误正文、密钥或终端日志。磁盘写失败停止后续工作，不承诺断电事务或自动修复损坏台账。
- `execution.lock` 使用 Windows 字节锁 / POSIX flock；同一实验目录的不同控制台进程也不能同时启动。单作业线程执行，网页刷新仅查询台账，不重复 POST。
- 请求 UUID 和预检 ID 同时去重；响应丢失时再次提交同一次确认返回原作业。服务重启后保留启动记录，但未启动的预检失效。
- 关闭网页不停止作业；“停止后续请求”只能从启动该作业的控制台服务发出，等待正在传输的一次请求结束，不能撤销计费。结果保留全部题目与固定分母，未完成项不算通过。
- 服务正常退出发出停止信号，最多等待工作线程 35 秒；异常退出 OS 自动释放锁。后续查看发现活动台账但无持锁者，保守标为 interrupted，绝不自动续跑或重试。报告可能保存了更多结果，以完整报告为准。
- 最多保留/处理 1000 份作业台账，页面展示最近 20 份中的最新任务进度；全部结果仍在原档案。不是长期海量调度系统，不自动删除历史。
- OS 锁约束只覆盖本网页作业系统，不拦截用户主动从旧 CLI 启动实验；不要并行运行 CLI 与网页实验以免混淆成本/实验条件。

## 安全、迁移与验收

沿用本机 Host/Origin、会话、CSRF、CSP、无 CDN。JSON 动态内容纯文本显示，密钥留后端；新路由正文上限 4 KiB，不放大设备接口限制。不对抗同一电脑上的恶意程序或人为篡改台账。

没有依赖安装、数据库迁移、旧数据/评分变更。原 ADR-0013 的复核并发限制保持不变；新增跨进程锁仅用于作业。

全量 391 项 Python、17 项 Node 通过，含离线预检、真实配置模拟、会话/CSRF、持久去重、跨实例互斥、来源变更/嵌套链接、停止/中断、进度落盘失败。另做本机 Fake HTTP 接口验收；未进行浏览器点击/视觉测试，也未调用学校模型。网站构建技能用于沿用本机工作面和本地资源；不采用云托管/存储。
