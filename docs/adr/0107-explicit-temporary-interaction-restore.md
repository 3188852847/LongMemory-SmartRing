# ADR-0107：明确恢复当天默认互动方式

## 背景

ADR-0106 让固定表达可以选择当天临时互动方式，但第一版只能等待自然日结束。用户如果改变主意，不能被迫继续使用“只倾听”或进入网页修改长期角色。直接删除原选择会破坏来源历史，原地缩短旧 L1 也缺少一条表达恢复意图的新证据。

## 决定

1. 增加“我今天恢复默认互动方式”和“我今天按平时的方式聊”两条固定完整表达；附加文字和近义猜测仍不触发。
2. 恢复表达作为新的当天有效 L1 保存，保留直接 L0 来源，不删除、退役或覆盖此前临时选择。
3. 临时互动读取器始终判断最新一条明确选择；若最新项为 `default`，本轮不注入临时行为指令，回到长期角色/L3/当前请求决定的通常方式。
4. 恢复记录到期后也不得让更早的临时选择重新生效。所有当天临时记录仍保留供审计，并且不进入 L2/L3 自动整理。
5. 这是自然对话中的低风险设置，不要求网页确认；模型仍负责普通确认措辞，存储结果由既有写入轨迹展示。

## 后果

- 用户无需等待午夜即可停止当天临时互动方式，并且历史意图仍可解释。
- “恢复默认”不是删除记忆，也不会重置或改写长期助手角色和用户画像。
- 当前仍不支持自由表达或只作用于下一轮的模式。
- 本切片复用既有 L0/L1 和有效期，不迁移数据库。

## 取代关系

本 ADR 取代 ADR-0106 中“提前取消未实现”的限制；ADR-0106 的固定指令、安全映射和来源追溯决定继续有效。
