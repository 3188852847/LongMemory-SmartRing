# ADR-0089：控制台管理本机模型配置档，切换在重启后生效

- 状态：已接受并实现
- 日期：2026-09-08

## 背景

学校模型会因重新部署而暂时缺少可用 Key，官方 DeepSeek 则可作为独立备用。此前两个配置文件虽已隔离，但只能手工编辑，日常启动又固定读取 `.env`；这使“选择官方配置”和“实际进程使用官方配置”无法从控制台闭环完成。

## 决定

1. 保留两个具名档案：学校模型使用 `.env`，官方 DeepSeek 使用 `.env.deepseek.local`；两者继续由 Git 忽略。
2. 设置中心允许编辑服务地址、模型名、超时、最大输出和新 Key，并把所选档案设为下次启动项。
3. 读取 API 只返回 `api_key_configured` 布尔值，永不返回既有 Key。Key 输入留空表示保留原值，不提供网页读取能力。
4. 配置写入只替换白名单 `LONGMEMORY_LLM_*` 字段，并使用同目录临时文件原子替换。官方 HTTPS 与学校 HTTP 的风险许可分别校验。
5. 启动器读取 `data/control/model-profile.json`，将所选档案真实传给 `uv --env-file`，同时向服务传入本次档案名称用于区分“当前进程”和“下次启动”。不做运行时热切换。
6. 圆屏小智继续读取它自己的私有 YAML。网页保存模型档案不会暗中改写或重启小智，避免把两条配置链伪装成已同步。

## 后果

- 学校服务不可用时，可以在设置中心选择官方档案，停止并重启启动面板后用于网页聊天、记忆提取和后台整理。
- 切换不是零停机操作，但运行中请求不会一半使用旧模型、一半使用新模型。
- Key 仍是本机文件中的明文秘密；本方案降低网页泄漏面，不提供操作系统级密钥保险库。
- 若圆屏也要切换到官方模型，仍需独立的“小智模型同步”动作与重启；该动作不包含在本 ADR 中。

## 验证

- 单元测试覆盖配置档原子写入、保留旧 Key、HTTP 风险校验、响应无 Key、CSRF 防护和启动器 env-file 选择。
- React 组件测试覆盖档案读取、当前连接检测及页面不出现合成 Key。
- 测试不读取真实 Key、不调用学校或官方模型，也不修改小智私有 YAML。
