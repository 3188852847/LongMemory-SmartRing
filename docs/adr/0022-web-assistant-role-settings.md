# ADR-0022：网页助手角色版本化设置

状态：接受。日期：2026-09-04。

## 决定与边界

P2 先打通网页角色编辑、保存、下一轮生效。设置不是 L3 用户画像，不写入 L0/L1，不修改实验回答器和 CLI；小智仍使用独立私有配置，页面明确显示未同步。

采用现有日常数据库旁的 `.role.sqlite3` 设置库，只在用户保存时创建。读取未保存设置时使用启动预设；保存后该库的版本优先于启动预设，重启保留。保留历史版本便于逐轮追溯，暂不提供版本列表和任意版本回滚。预设恢复也作为新版本保存，不删除历史。

SQLite 写事务加 expected_revision 校验避免多页面互相覆盖；请求失败不自动重试。每轮开始处理时固定版本，复制回答器角色配置而非修改共享实例。基础证据约束保留，但不宣称提示词本身能完全抵抗注入或保证人格表现。

## 代价与替代

替代方案是直接改启动提示词文件或小智 YAML：简单但难区分运行版本，并可能覆盖机器私有配置。本方案增加一个小型设置旁库，无需迁移记忆表；旁库可能包含私人文本及旧版本，必须与数据库一起保护和备份，不提交 Git。

本机认证用户均可修改同一库的角色，这是单用户控制台，不提供多用户权限。圆屏同步与回执、声音设置是后续独立切片，不以网页保存冒充已完成。
