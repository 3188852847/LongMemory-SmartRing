# ADR-0159：CosyVoice 3 日用默认与启动选项即时保存

- 状态：已接受
- 日期：2026-09-14
- 取代：ADR-0123 中“EdgeTTS 仍是日常默认”的决定；EdgeTTS 的稳定回退地位不变

## 背景

早期接入 CosyVoice 3 时，EdgeTTS 因资源轻、依赖少而继续作为日常默认。后续真实圆屏验收已经确认 CosyVoice 3 的音质、声线一致性、连续性和自然插话，V1 范围也将它列为正式日用声音；sanoTTS 虽然生成较快，但用户再次确认其音质不适合作为日常默认。

启动面板此前只在服务进程成功建立后统一保存选择。用户虽然已在界面选中学校模型或混合召回，但如果启动失败、直接关闭面板或在共享指针同步过程中被打断，下次打开仍可能显示旧值。界面也没有在选择时给出保存结果。

## 决定

1. 启动面板首次没有任何偏好或共享 TTS 指针时，默认选择 CosyVoice 3。已有合法共享指针继续优先，不擅自覆盖用户此前的明确选择。
2. CosyVoice 3 在启动面板与控制台标记为“本地高质量，日常推荐”；sanoTTS 标记为“实验速度基线，音质较低”；EdgeTTS 标记为联网稳定回退。
3. 模式、起始页面、角色、提取、召回、模型、圆屏记忆后端、声音、拾音和实验开关等有限枚举或布尔选择，在用户改变时立即原子保存，并明确提示下次启动生效。路径与 IP 仍只在成功启动或显式同步后保存，避免键入过程中反复写盘。
4. 运行中的模型、召回、记忆后端和声音仍不热切换。启动瞬间若面板对应下拉框自打开后未被用户修改，则吸收网页控制台更新的共享指针；用户已在面板修改时，以面板当前选择为准。
5. 本机受限控制接口的 `status` 返回这些非敏感选择，方便核对面板真实状态；不返回路径、令牌、密钥或正文。

## 证据

修复前读取本机 Git 忽略配置，已保存值为 CosyVoice 3、学校模型和混合召回。加载新版面板后，通过受令牌保护的本机 `status` 实际回读到同一组选择，证明当前配置文件与新版界面一致；本次只启动面板，没有启动服务或读写记忆数据库。

## 后果

- 日用默认与当前 V1 产品范围一致，sanoTTS 不再因旧共享指针或含糊标签被误解为推荐方案。
- 选择的持久化不再依赖一次完整服务启动，失败时也能保留用户意图。
- CosyVoice 3 的首声延迟仍是 V1 阻塞缺陷；默认它不表示延迟已经达标。
- 缺少 CosyVoice 3 本地环境时，启动器会明确拒绝并提示检查环境，不静默切到其他声音。

## 回退

用户可在面板或控制台明确选择 EdgeTTS、VoxCPM2 或 sanoTTS，停止旧服务后重新启动。回退只改变下次 TTS 选择与小智私有配置，不修改记忆、模型、角色或数据库。
