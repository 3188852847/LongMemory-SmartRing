# ADR-0076：日常交流时段候选与缺席联系策略分离

- 状态：已接受
- 日期：2026-09-07

## 背景

V23 能记录长静默后、近期无主动问候时的用户主动出现时间。重复出现在相近时刻可能表示日常交流规律，但直接把该时刻写成主动问候时间会产生逻辑错误：用户本来会主动来聊，并不意味着助手应该同时打断；某天没有出现也不证明用户异常或需要帮助。

## 决定

新增独立的“日常交流时段候选”，只描述跨日重复时间。按当前 UTC 偏移和 30 分钟区间聚类，同日最多一条；至少三个不同日期才创建，期望分钟取中位数。候选保存逐条 V23 事件引用、稳定指纹和生成器版本，不复制消息正文。

SQLite 升级至 V24；迁移只新增空候选与来源表，不回填。候选默认未生效，可忽略，不能修改 P4 定时设置、触发问候、进入 L3 或推断用户情绪。

## 理由

将“观察到的作息规律”和“系统该采取什么行动”分开，后续才能独立验证：规律是否稳定、缺席阈值是否合理、主动联系是否安全且有帮助。这样即使行动策略失败，原始时间证据仍可重算和回退。

## 后果

- 三个日期只是生成弱候选的最低门槛，不是习惯已经成立的证明。
- 固定 30 分钟分桶仍有边界效应，必须由后续离线回放测量。
- 下一切片需定义回放样本、误触发指标和缺席策略草案；在门控完成前不能激活候选。
