# ADR-0134：先审计 L2 召回分数，再评估语义升级

- 状态：接受
- 日期：2026-09-13

## 背景

当前 L1 已能在关键词和本地 BGE 混合召回之间切换，L2 场景仍使用标题与摘要的关键词重合。直接让稠密检索覆盖 L2，会改变日常回答注入内容，却没有留下可比较的 L2 基线分数，也可能让无关问题召回某个已接受场景。

## 决定

先保持 `l2_keyword_v1` 的选择和排序不变。`ScenarioRecallItem` 暴露本轮实际关键词重合数，小智回答回执把该数值与 L2 ID、排名和内容指纹一起写入现有召回证据表；不复制标题、摘要或来源正文。旧回执继续保持空值，不回填。

只有取得可复核的 L2 日常样本后，才在同一数据和上下文预算下比较关键词、稠密或融合策略。分数只表示匹配过程，不解释为场景真实性、答案存在概率或回答正确率。

## 后果

本切片不改变个人库 schema、召回结果、注入预算或默认设置，但建立了语义 L2 实验所需的基线观测。现有通用证据列可以保存 L2 关键词分；L2 的余弦与融合分继续拒绝写入，直到相应策略和验证同时落地。
