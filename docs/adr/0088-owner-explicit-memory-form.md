# ADR-0088：本机所有者明确添加长期事实

- 状态：已接受并实现
- 日期：2026-09-08

## 背景

圆屏和网页聊天已经支持固定格式的“请记住：我……”命令，但记忆管理页只能查看、纠正、记录变化和删除已有 L1。所有者为了补录一条明确事实仍要切回聊天页；另一方面，若页面直接写 SQLite，会产生第二套规范化、去重和来源规则。

## 决定

1. 记忆管理页提供“明确添加”入口，只接受以“我”开头、无控制字符、最长 1000 字的完整陈述。
2. HTTP 入口只负责严格验证和添加固定命令前缀，随后调用共享 `MemoryRuntime` 的自然记忆命令服务；页面不得直接构造 L1 或执行 SQL。
3. 操作原文以 L0 保存，L1 使用既有确定性自指规范化、内容去重和 `user_stated` 来源。重复事实只增加新的 L0 证据。
4. 暂停 L1 写入时，页面仍只保存 L0 并返回 `write_paused`，不得绕过运行期开关。该操作不调用回答模型。
5. 接口继续受本机会话、同源和 CSRF 保护。它是所有者管理便利入口，不改变“普通用户只通过圆屏使用产品”的边界。

## 后果

- 网页与圆屏的明确记忆语义保持一致，后续修正规则只需修改一个应用服务。
- 管理页可以补录遗漏事实，但这不等于任意文本编辑、批量导入或隐私级删除。
- L0 会记录带“请记住”前缀的实际管理操作，以便区分普通聊天和明确补录。
