# ADR-0131：L1 写入时保守规范化去重

- 状态：接受
- 日期：2026-09-13

## 背景

L1 质量收件箱已能在写入后发现和人工合并重复，但如果模型只是改变主体称呼、空白或句末标点，仍为它创建新 L1 会制造可预防的数据噪声。同时，全标点删除、字面相似度或向量阈值都可能合并含义不同的事实，不能用于无人值守的日常写入。

## 决定

所有规则提取和模型提取在统一的 L1 持久化入口生成保守去重键。只做以下规范化：

1. Unicode NFKC 和大小写折叠；
2. 去掉已知的开头主体称呼：“用户本人”、“此人”、“用户”；
3. 收缩多余空白；
4. 去掉句末的句号、感叹号、问号和分号。

只有规范化键严格相同、主体相同，且旧记忆在新来源发生时仍有效时，才复用原 L1 并追加新 L0 证据。

内部标点、数字、否定词和一般改写全部保留。它们仍创建独立 L1，交由质量候选收件箱复核；系统不根据相似度或模型判断自动合并。

## 后果

日常使用会少产生一类可确定的表层重复，且每次原话仍作为独立 L0 证据可追溯。该规则不是语义去重、冲突消解或事实真值判定，不需要数据库迁移，也不会回填或改写旧记忆。
