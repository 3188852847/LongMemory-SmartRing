# ADR-0079：用单一当前指针与只追加事件治理陪伴策略版本

- 状态：已接受
- 日期：2026-09-07

## 背景

V25 已能保存不可变缺席策略版本，但没有“当前使用哪一版”的唯一事实。如果直接修改版本行的状态，多次切换后难以复原历史，也无法可靠检测旧页面覆盖新操作。

## 决定

SQLite V26 为每个主体增加一条策略选择记录：当前版本可为空，revision 每次变更递增。同时增加只追加切换事件，记录前一版本、目标版本、动作、结果 revision 和时间。

激活只接受通过固定离线回放门控的版本。激活、停用和回滚都必须携带页面看到的期望 revision；指针更新与事件写入在同一 `BEGIN IMMEDIATE` 事务中完成。控制台不再增加二次确认弹窗，但会明确显示当前版本、非当前版本与切换历史。

## 理由

单一指针消除“同时激活多版”的歧义；乐观并发检查避免陈旧页面覆盖；只追加事件支持审计和回滚。三类动作共享同一事务边界，减少实现分叉。

## 后果

- 版本记录仍不可变，停用只把当前指针置空，不删除历史。
- 门控失败版本可保留用于审计，但永远不能被选为当前版本。
- 本切片只治理配置版本，后台调度尚未读取该指针；页面上的“当前版本”不等于已经开始自动联系。
- 下一切片才把当前版本转换为运行草案，并继续经过既有 P4 安全与设备门控。
