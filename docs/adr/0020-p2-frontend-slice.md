# ADR-0020：P2 外观阶段保留原生前端

状态：后续聊天页选型已由 [ADR-0021](0021-react-chat-migration.md) 取代；以下保留原决定。日期：2026-09-04。

依据 ADR-0007 的触发条件重新评审：会话和外观已出现共享状态需求，但目前可以把外观独立为小模块，未发现必须整体迁移框架才能实现的能力。本阶段继续原生 HTML/CSS/JS，保留后端静态白名单、CSP、测试和既有页面。

外观只保存枚举主题和字号；同源标签通过 storage 事件同步，不引入全局业务状态库。聊天为主，配置与证据折叠但不删除。主题仅作用于聊天页，避免未经验证改动实验结果与设备状态颜色。

候选：现在迁移框架会扩大会话/安全/实验页回归范围；完全不抽模块则让 chat.js 更复杂。选择独立 appearance 模块加局部 CSS，不新增依赖。

下一关：角色与声音进入共享编辑/生效状态后再次评审；若频繁出现状态同步缺陷或重复组件难维护，再做框架迁移决定。此次决定不代表整个 P2 永久不用框架。
