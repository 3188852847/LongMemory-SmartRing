# ADR-0019：网页会话持久化旁库

状态：接受。日期：2026-09-04。

## 背景与决定

现有 L0 消息没有网页会话编号，不能可靠回填旧消息分组。P1 新增会话列表、新建、切换、重命名、刷新/重启恢复，沿用当前 HTML/CSS/JS，不引入框架或依赖。

新增与选定记忆库同目录的 `<记忆库文件名>.chats.sqlite3`，只存网页会话标题、轮次结果、请求 ID 与阶段证据。L0/L1 继续按原闭环归档，不改变原库 schema，不执行旧数据迁移。首次创建会话才建立旁库；启动时会创建无个人正文的 `.lock` 文件，生命周期独占，防止两份控制台覆盖同一旁库。

会话以独立随机 HttpOnly、SameSite=Strict Cookie 关联浏览器，服务端保存其哈希；原 Host、Origin、短期会话、CSRF 检查保留。不是多用户认证，不对抗本机恶意程序。浏览器 localStorage 只保存最后选中的会话 ID，不保存正文。

## 失败、恢复与边界

- 先落待处理请求，再运行原记忆/模型闭环，完成后保存完整结果。跨旁库与记忆库不保证原子提交。
- 若崩溃留下待处理请求，展示 interrupted/写入状态未知，同请求 ID 不重跑；不声称原始输入未写入。
- 恢复只将最近六轮成功对话注入，额外总字符预算 24000；不足容纳最近整轮时不拆分伪造内容。模型/角色沿用当前启动配置，历史保留原标记。
- 原 32 会话、每会话 40 轮上限保留；扩展分页/归档/删除界面另行实现。新建不会删除旧会话。
- 同一浏览器 Cookie 保留时可恢复；清除 Cookie、换浏览器暂没有找回绑定入口。旧未分组对话不自动导入。
- 旁库含正文与检索证据，同样不得提交版本库。备份/隐私清理须包含旁库；删除某条 L1 不意味着从所有历史对话中彻底擦除。

## 验收

合成临时库验证列表、重命名、跨服务重启、上下文恢复、请求重放、浏览器隔离、崩溃标记和独占锁；不触碰用户真实库、不调用学校模型。浏览器功能实测由用户体验，本次未请求视觉 QA。
