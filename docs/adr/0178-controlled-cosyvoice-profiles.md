# ADR-0178：受控参考录音与独立声音档案

状态：已接受。日期：2026-10-14。所有者要求并行推进前端声音克隆与助手设置优化。

## 决定

沿用固定 CosyVoice3 模型与运行环境。标准库档案模块供主项目 Python 3.12、小智和 CosyVoice Python 3.10 共用；以受控 PCM WAV、内部参考 ID、内容 SHA-256 和档案摘要管理输入，不接受浏览器提交任意路径。

上传、试听草稿、保存和日用合成分开。保存使用比较并交换（CAS：只有版本仍一致才写入）及操作系统文件锁；进程退出自动释放锁，原子替换避免半份档案。网页与圆屏经同一声音服务读取档案，固定一段生成期间的配置。声音与回答角色保持独立，角色同步的既有授权边界保留。

## 上游依据与缓存

已恢复的 CosyVoice 源码 commit 为 `074ca6dc9e80a2f424f1f74b48bdd7d3fea531cc`。该版本 `example.py` 展示零样本参考声音和 CosyVoice3 `inference_instruct2`；`frontend_instruct2` 会复用已注册说话人的提示缓存。参考声音、原文和风格必须共同参与缓存身份，不能给新风格继续使用旧提示缓存。仅使用已有模型接口，不修改上游源码。

首次升级通过健康契约与响应版本头区分旧进程；不把旧服务忽略草稿后的返回音频视为成功。自定义声线关闭固定原声线预置音频快路径，恢复默认档案后仍保留原路径。

## 验证边界

合成 WAV、模拟模型和本机 HTTP 测试验证权限、输入限制、摘要冲突、崩溃锁释放、缓存隔离及原流式/打断兼容。真实音色与风格效果、GPU 延迟、圆屏声音仍需用户试听；不承诺文字指令能生成任意新声音。
