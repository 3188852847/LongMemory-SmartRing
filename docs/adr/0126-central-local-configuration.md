# ADR-0126：集中本机配置与小智生成副本

- 状态：已接受
- 日期：2026-10-14
- 范围：目录与加载契约；不改变服务协议、记忆数据模型及厂家源码
- 关联：ADR-0125 的顺序同步及摘要门槛继续保留，本记录更新其受管小智配置位置

## 背景

根目录有多个私有 env，持久用户偏好与运行控制文件混在 `data/control/`，小智人工配置又散在外部源码的 `data/.config.yaml`。用户授权集中配置并与前端结构及 CI 并行整理；需要保留当前可运行的文字、记忆及语音行为。

## 候选与决定

保留所有原路径无法实现集中管理。保留根目录 env 副本并双向同步会形成多个来源，密钥和偏好易发生覆盖。改变厂家代码读取路径或新建联接会给源码恢复及 Windows 路径安全增加额外耦合。

采用 `local/config/` 保存唯一人工配置来源：4 份具名 env、`preferences/` 下 4 份持久偏好、`display/` 下皮肤选择/自定义皮肤，以及受管实例的 `xiaozhi.yaml`。运行令牌、控制桥发现文件、启动器状态和 TTS 基准历史继续使用 `data/control/`。公共模板移入 `config/examples/`；数据库、角色存储、音频、模型及研究结果按各自资产归属保留。

所有受管实例的配置同步工具直接读写 canonical（唯一管理来源），原来修改后重启生效的语义保留。小智 `setup.py start` 在本地校验成功后、厂家子进程开始前生成字节一致的 `data/.config.yaml` 消费副本，记录独立来源摘要回执。已有副本的摘要漂移会拒绝覆盖，保留人工修改；生成工具不往 YAML 添加元数据，也不热切换运行服务。显式其他服务实例使用自身配置，避免测试或另一实例隐式读取日用私有配置。

迁移前必须受控停止旧进程。迁移脚本默认只预检，apply 显式确认服务停止；只处理固定白名单、拒绝链接/联接/越界与目标碰撞，字节摘要核对并记录写前意图。env / 偏好同盘移动，YAML 复制保留原厂家消费副本。失败时仅回退本事务拥有且摘要仍一致的内容；半成品和回退 YAML 存入私有归档，不清空资产。

## 后果与验证

控制台、启动面板和 Python 3.10 小智脚本使用同一目录契约，无须增加依赖或机器永久环境变量。现有终端命令须显式带 `--env-file local/config/...`；恢复旧代码前须按私有迁移回执回退，不能让旧进程动态读取已搬走的文件。

目录集中不代表操作系统权限隔离。厂家副本仍含实际凭据，属于忽略的受管运行资源，只能当消费副本维护。配置更新仍须重启并核对真实服务和设备，合成文件测试不能冒充实机验收。验证方法见 [本机配置集中管理](../development/configuration.md)。
