# ADR-0084：圆屏三维状态协议与浏览器模拟器

- 状态：已接受并实现第一阶段
- 日期：2026-09-08

## 背景

SmartRing-Plus 圆屏已经能显示小智固件的待机和聆听界面，但当前项目没有中立的状态协议。若直接制作角色动画，交互阶段、情绪和系统故障会彼此组合成大量页面，且服务端 `queued` 等弱证据可能被误画成“正在播放”。B V2 当前又是预编译固件，本地旧源码不足以证明可实现能力。

## 决定

1. 圆屏表现拆成 `interaction_state`、`emotion_state` 和 `system_state` 三个正交维度；情绪不改变业务状态，也不冒充用户情绪识别。
2. 配网、更新及网络/模型/电脑服务不可用属于阻塞覆盖；充电和低电量第一版只作边缘提示。
3. 在现有 React 控制台增加 `/display-preview`，用 466×466 画布模拟状态、情绪、安全区和覆盖优先级。它不调用 API、不连接设备、不写数据库。
4. 模拟器使用几何占位表情，不引入角色版权素材或新依赖；减少动画系统偏好生效。
5. 真实固件接入前必须核对 B V2 准确源码、显示栈、资源预算和事件证据，不能把模拟器宣称为设备能力。

## 后果

- 状态语义可以先于视觉皮肤和固件移植接受测试，后续更换角色不侵入语音与记忆逻辑。
- 控制台多一个内部设计入口，最终用户仍只接触圆屏；该页面不是产品端设置。
- 目前只能验证浏览器布局与纯状态解析，真实圆屏帧率、字幕、打断、故障恢复和 AMOLED 表现仍未验证。
