# ADR-0017：启动器显式网络地址同步

状态：接受。日期：2026-09-04。补充并局部取代 ADR-0016 的“不修改配置”限制，仅限用户明确点击的网络同步。

背景：校园网分配地址变化后，固定旧地址无法 bind；仅改面板又会与小智配置不一致。

决定：本机只读枚举 RFC1918 地址；单地址预选，多地址由用户选择。同步前展示新旧 IP，确认后在私有原目录备份，精确更新 server.ip、websocket、vision_explain。整份 YAML 语义校验保证其他字段不变；不新增 YAML 依赖，使用小智现有环境。成功选择仅保存到忽略提交的本地文件。

边界：普通启动不写配置；不访问模型、不改数据库/角色/密钥，不自动开防火墙，不修改圆屏。不接管外部进程，用户同步前须停止外部小智。备份含敏感配置，不上传。

替代：手工改三处易遗漏；静态校园 IP 未获管理员分配，不采用；域名发现暂不扩展。

后果：电脑端可显式同步，圆屏仍可能需要更新 OTA 地址，不能承诺无操作恢复。未支持的 YAML 格式拒绝修改，保留人工处理路径。
