# ADR-0061：主动联系设置随个人数据库持久化

- 状态：已接受；后端纵向切片已实现。
- 日期：2026-09-06。
- 承接：ADR-0059、ADR-0060。

## 决定

1. SQLite V15 新增每主体一行的 `proactive_policy_settings`；缺少记录等同安全默认关闭，迁移不自动插入或启用设置。
2. 保存总开关、固定 UTC 偏移、星期、起止分钟、每日上限、最短间隔、消息有效期、临时勿扰截止、策略版本、revision 和更新时间；不保存模型生成内容或设备状态。
3. 本机 API `GET/PUT /api/proactive-policy` 只操作启动时指定的已有当前版本数据库。写入要求同源会话、CSRF 和完整设置，并使用预期 revision 防止旧页面覆盖。
4. 保存设置不创建候选、不唤醒后台、不调用模型、不接触设备。P4.4 后续切片才能把设置连接到事件账本和投递编排。

## 后果与验证

设置与个人记忆一起备份和迁移，但逻辑上仍独立于 L0–L3。第一版使用固定 UTC 偏移，不宣称支持旅行或夏令时自动切换。存储重开、并发冲突、HTTP 默认值、CSRF、严格输入与旧 revision 已由合成测试覆盖；个人库在一致性备份后升级到 V15，设置表为空。
