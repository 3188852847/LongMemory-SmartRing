# ADR-0197：CosyVoice 显式自适应播放缓冲候选

- 状态：候选，CPU 隔离验证通过；未做本轮 GPU 或设备验收，保留 buffered 默认
- 日期：2026-10-21
- 编号：主会话分配，AD 实施；组合接线归 AI
- 阶段：[AD 工作记录](../development/parallel/AD-cosy-continuity-20261021.md)

## 背景

[ADR-0190](0190-cosyvoice-continuous-audio-delivery.md) 保留 v2 块协议、跨块 FIR
重采样、协作取消和正常结束标记。X 的历史测量表明，提前交付原生块可以缩短首包，
却仍有中途供给缺口；自然分段的六个增量样本也有最大 282.879 ms 的缺口。
这些数字属于 X 的历史模型与窗口，不作为本候选的结果。

## 候选决定

1. 默认和显式 `buffered` 保持完整自然片段路径；已有显式 `incremental` 保留为对照。
   只有连接显式设置 `_longmemory_cosy_delivery_mode="adaptive"` 才采用新缓冲。
   不按字数、缓存或是否出现标点自动启用；`adaptive` 发给服务的请求仍为
   `delivery_mode=incremental`，它是客户端策略，不新增模型生成模式。
2. 每次合成由独立线程读取自有 HTTP 连接、严格解析 v2 WAV 块并连续重采样。
   PCM 以 60 ms 为槽，队列最多 3000 ms；正常结束时可以有一个不足 60 ms 的尾槽。
   消费线程独占当前 TTS 的 Opus 编码器；预测下游库存加上下一帧不超过 3000 ms，
   从而限制预取队列和交付队列各自的增长，不改变上游设备发送协议或帧时长。
3. 初始库存目标为 360 ms。后续自然段沿用同一轮供给时间线，把尚可播放的库存计入
   目标，避免每段固定追加 360 ms 延时。库存耗尽后，恢复目标每次增加 180 ms、
   上限 900 ms；重新积累后交付，正常 EOF 允许不足目标的短回复和尾段释放。
   参数是待评测候选，不表示它能消除任意模型停顿，也不保证首声低于一秒。
4. 取消同时检查连接身份、TTS 身份和停止标记。关闭读流自己的 socket、丢弃本地积压、
   join（等待线程退出）后才释放编码器锁。旧调用等待锁时捕获的身份保持不变；
   旧 finally 不得清空新轮编码器。清理超时停止本段，不并发发起完整 WAV 回退。
   帧携带捕获的轮次身份，计时回调、音频队列入口及最终流控出队均拒绝过期帧；
   不在回调时用已经变化的全局编号把旧帧重新标成新回答。
   不扫描或清空其他轮次的共享队列；已有答案/等待提示归属与优先级包装继续生效。
5. 只有 v2 正常结束才冲刷 FIR 尾和最后不足一帧的零填充。协议截断、取消、生产者
   异常都丢弃未交付积压；首包前故障沿用完整 WAV 回退，首包后不重播整句。
6. 保留现有确定性自然分段：合并短开头，在合格自然标点结束，立即排空已就绪段，
   无标点长文在 LAST 统一清空。不修改声线、参考音、语速、模型精度/权重、等待
   提示缓存、推理内容过滤、内部标记过滤或回答优先级。
7. `/v1/capabilities` 与健康响应新增 `audio_stream`，区分协议支持、实例可复用和
   当前增量可用。声线只返回配置摘要与模型上下文摘要，区分二者，读取能力不暖机。
   固定运行时适配未应用、强制 buffered 或 requires_restart 都不得宣称增量可用。

## 观测和边界

`PlaybackTimeline` 记录首个有效回答 Opus 的交付、总可播放时长、预测结束时间、最大/
累计欠载。它以客户端交付时间推算，不是设备扬声器测量；也不包含 ASR、记忆、LLM
或等候提示的收益。同轮后续段的时间线摘要为整轮累计值，时间原点是本轮首次进入
adaptive 合成；缓冲/接收指标属于当前段。`client_receive_rtf` 是 HTTP 读流、重采样和背压等待墙钟除以
接收音频时长，不是纯模型 RTF（生成耗时/音频时长）。

取消摘要另记本地丢弃音频量和读流 join 耗时；它们不能冒充 GPU 整体中止耗时或
设备残音。真实取消验收仍需最后一个旧轮有效声音、用户打断时间及新轮首声。
`VoiceLatencyTracker.continuity_snapshot()` 提供独立脱敏摘要，限制每轮最多 32 条；
旧轮迟到数据拒绝写入，既有 v6 设备/前端字段保持不变。组合展示由 AI 协调。

失败和取消，新轮与旧清理并发，以及随机环回 HTTP、真实 FIR/Opus 的帧数与结束。
