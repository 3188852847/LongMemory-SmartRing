# ADR-0147：L1 证据门控先评估受控试验就绪度

## 背景

V45–V46 已能在不影响回答的情况下记录 L1 证据充分性影子判断，并由所有者标出精确支持集。ADR-0146 要求在正式门控前预先定义样本量和错误门槛，但没有给出可执行的判定器。

不能因为小型合成开发集上没有错误，就自动改变个人库的日常回答。同时，如果只说“以后样本够了再决定”，就会把决策留给当时的主观感受。

## 决定

1. 新增纯计算策略 `l1-sufficiency-controlled-trial-readiness-v1`；它只消费最新的精确人工支持集，不读取额外正文、不调用模型、不修改设置。
2. “有支持证据”和“无支持证据”两个分层各至少需要 60 条精确人工标签。若 60 个样本中观察到 0 个目标错误，对应单侧 95% 二项上界 `1 - 0.05^(1/60) ≈ 4.87%`。60 因此是对“低于约 5%”的工程证据下限，不是经验准确率拍值。
3. 在样本数达标外，误拦截、无证据误放行和支持集漏选都必须为 0；所有标签样本必须具备候选字符数，并观察到正的候选缩减收益。
4. 全部条件成立时只返回 `ready_for_controlled_trial`，含义是“可以单独评审小范围试验”。它不是正式上线结论，也永不自动启用运行时门控。
5. 控制台始终显示两类样本进度和未达条件。空库、旧复核或不确定标签不会被补写成证据。

## 后果与限制

- 启用决策从模糊的“感觉样本够了”变成可重现的检查项。
- 日常样本可能时间相关、题型不均衡，并不满足独立同分布；所以二项上界是透明的工程护栏，不是严格的产品错误率保证。
- 所有者复核不是外部盲评，且本指标不测量端到端回答质量。正式启用前仍需新 ADR，明确试验范围、回滚和实机观察。
