# ADR-0186：所有者确认校园免费与前向独立空间

日期：2026-10-19。状态：接受用户费用决定与主会话批准的前向边界；本轮代码候选待Z复核、主会话合入推送后再部署。追加[ADR-0184](0184-shared-campaign-budget-and-owned-model-gateway.md)和[ADR-0185](0185-verified-hy-management-and-visible-history.md)，不改写官方原池或其真实验收结果。

## 原因与决定

所有者实机反馈字幕和声音可用，但听到共享额度暂停。只读账本确认197次中有一条answer为unknown，保留8388608微元最坏预留，其他196次settled共496332微元；不是已确认花满十元。核价未过期。原网关没有为该次持久保存上游状态/异常阶段/usage，现有元数据不足以倒推真实中断原因或费用，不追认零费用、不释放预留，也不再发官方付费probe。

所有者随后明确学校免费提供，要求复用既有campus配置。这是本次个人费用为0的授权事实，不需要再用官方CNY接口验证学校免费。供应商接入保持同一受控网关和Runtime，只分开调用政策：官方仍用原十元池及未知预留；校园使用独立零个人费用调用审计。校园缺usage、断流或取消仍记未知，不把未知token记0，也不因未知调用制造付费预留或谎称完成。

校园协议保留既有HTTP同意、真实端口/API前缀、请求模型大小写`DeepSeek-V4-Flash`和已有Key。端点/Key只从受控本地档案读；配置回执绑定端点、模型、凭据摘要和所有者确认。免费授权验证与官方账户币种核验分开，不能填currency_verified=true冒充CNY检查。HTTP/HTTPS按真实scheme和端口发送，不跟随重定向、不重试，不自动回退官方。回答保持原512 token/30秒；Hy提取沿其既有显式设置，不扩大通道限额或声称核验了服务器内部权重。

## 传输与验证边界

新网关持久记录调用ID、HTTP状态、受控失败码、DONE/转发/usage出现标记，不存消息、供应商响应或异常正文，不改费用状态。旧未知记录没有这些证据，新增机制不能倒填过去。

关闭验收另复现同步HTTPResponse缓冲读锁阻塞，保留socket和覆盖will_close的两次尝试仍失败；最终仅流式传输改用项目原固定aiohttp3.13.2的可取消读取，逐行转发、禁重定向、原超时、不重试，关闭后收回自有循环/线程。它修复离线可重现的关闭问题，不证明就是旧官方unknown的原因。

Z终审另复现下游停读令wfile.write阻塞、server_close等不到处理线程。X重复原复现后仅补自有下游socket登记/锁外shutdown和回环阻塞读写有界，保留非daemon处理线程及原关闭时限；免费/付费两种慢读者均验证unknown不释放。官方余额核验另在任何网络前拒绝非官方端点/模型，不能因共用选择器支持校园而将学校Key发给官方。

隔离验证包含真实HTTP/厂家提供器＋既有Python3.10 SDK、普通SSE/增量tool_calls/空choices usage/缺usage、取消/关闭/重开、真实Hy SDK提取→重启→召回。最小真实校园探针仅用合成事实，经Hy、网页和圆屏流式三通道；原官方197条逐项不变。探针不重跑V保留集，不将官方17题成绩迁称校园效果；内容只留忽略目录，实际结果见[X记录](../development/parallel/X-hy-roundscreen-20261019.md)。
