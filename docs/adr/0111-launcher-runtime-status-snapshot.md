# ADR-0111：启动面板运行状态只读快照

- 状态：已接受
- 日期：2026-09-10

## 背景

Windows 启动面板拥有控制台、小智语音和可选 VoxCPM2 子进程，网页控制台则拥有模型、记忆和设备状态。网页此前无法区分“由启动面板管理的语音进程没有启动”和“进程已启动但设备未连接”，排障仍依赖观察终端或启动面板。

## 决定

启动面板在 `data/control/launcher-status.json` 原子写入最小运行快照。快照只包含 schema 版本、随机启动实例、启动器 PID、UTC 更新时间、阶段，以及 `console`、`voice`、`voxcpm2` 三项白名单状态；不包含命令、路径、配置、密钥、对话或日志。

控制台新增受会话保护的只读 `/api/runtime-status`。只有文件中的随机实例与当前控制台进程环境一致，且更新时间不超过五秒时才返回组件状态。文件缺失、损坏、实例不匹配或过期时降级为“不可用/过期”，并隐藏组件状态。手动终端启动的控制台明确显示为“非启动面板模式”。

该通道只用于观察，不能启动、停止或重启进程；“进程运行”也不能替代模型连接检查、设备连接或 TTS 健康检查。

## 后果

- 系统总览可以同时呈现受管进程、模型、设备和记忆的不同事实层级。
- 启动器异常退出留下的旧文件不会产生虚假绿色状态。
- 状态文件写入失败不得中断主服务。
- 将来若采用系统托盘或常驻守护进程，应新增决策替代本文件协议，不能把它扩张为无认证控制 API。
