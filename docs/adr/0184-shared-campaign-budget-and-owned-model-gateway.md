# ADR-0184：续用原十元池与日用模型网关所有权

日期：2026-10-19。状态：接受本轮接线候选与隔离验证边界，日用部署仍待主会话/Z组合验收。追加 [ADR-0183](0183-platform-roundscreen-and-hy-deployment.md) 的可信日用装配，不改写其首阶段结果。

## 决定与边界

用户新决定是“先共用本轮10元总上限”，包含V已记录的0.491022元保守上界。日用初期固定续用V树`local/runtime/hy-memory/real-validation-20261019/budget.db`。不创建另一个十元池，不重置日/月，不复制旧账本当新额度，不释放失败/未知预留。V原实验与小样本质量记录保留，X不重新采样/调参保留集。

正式装配复用`selected_model/ModelGateway/SharedBudget/Endpoint/HySettings`，没有新增另一套RealModelConfig。固定部署文件选择资源；Hy设置文件保存托管网关原型。原型端点/口令只作形状占位，启动后由自有随机回环端口/口令替换。稳定provider_identity绑定所选请求模型/端点身份与本地BGE资源身份，不随本次端口/口令变化。供应商密钥只交给网关；SDK、网页回答器和圆屏消费配置只领取回环端点/口令。

预算沿用V的全窗口最坏预留，SQLite事务先预留再发出。X的既有池适配只重开文件；官方核价回执只能延长同策略的有效期，不能改变价格、模型、窗口、总额或尝试，续期另记摘要审计。回执有效期至多两小时，币种证明绑定当前凭据摘要；过期/额度不足/账本异常明确暂停，原话仅归档、不提取或收费回答。没有自动联网续价或自动充值。

2026-10-19只读核对[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：当前Flash高峰输入未命中2元/百万token、输出8元/百万token，仍沿该保守上界，不用空闲/缓存折扣；旧`deepseek-v4-flash`请求名按Flash计费，保持已选请求名。官方服务模型别名映射不等于本地能固定供应商内部权重。X本轮未更新真实账本、未调用余额或付费模型；切换前须保存新的真实核价/币种回执。

## 流式、停止与管理

V原实验非流式通道保留。圆屏新增受控真实SSE通道，逐片转发，不能先收完整回答再伪分块。只有完整usage和DONE都转发成功才结算差额；供应商/客户端断流、关闭、缺usage都保留最坏预留，不自动重试。圆屏SDK客户端显式max_retries=0，另收费服务端工具不放行。源语言提示、V冻结实验条件不被回写；新候选源码身份与V原评估分别报告。

Runtime持有网关关闭责任，SDK先关闭，再停止本次自有网关/端口。初始化任一步失败清理自有资源，保留来源、Hy状态与预算证据。强制进程结束仍可能留下reserved/uncertain，不能按零费用补发。原人工YAML/角色/声音不改成随机网关配置；只生成受摘要保护的厂家消费投影。旧后端保持原路径。

专属管理通过Runtime白名单、串行锁、写开关和真实user来源归档；同request_id复用首次来源时间/会话，不调用observe。serialized_writes默认false；只有绑定当前worker/process源码与SDK版本、真实原语验收和后台语义写关闭证明，且两份独占租约有效，才按RPC实际能力开门。SDKdelete若不能忠实满足单条范围必须继续false。受控串行不是SDK原生CAS，来源/SDK/审计不宣称跨存储事务。

## 证据与回退

合成池测试覆盖原消费和未知预留保留、续价拒绝改策略、过期暂停、真实HTTP首片先于完整usage、流中断不释放费用、运行时重启身份与清理。实际SDK/512维CPU BGE链路使用模拟远端，不能当真实模型全轮延迟或设备体验。结果见 [X记录](../development/parallel/X-hy-roundscreen-20261019.md)。

回退保留原池和新记忆，停止自有服务后改回已验收后端。不能回刷旧数据库/账本覆盖新对话或消费；未来长期预算政策另作用户决策，本ADR不授权扩大十元上限。
