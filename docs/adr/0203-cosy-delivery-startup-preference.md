# ADR-0203：CosyVoice 启动偏好与连接交付事实分离

日期：2026-10-21。状态：ROOT已授权候选实现；隔离软件检查中，未部署。原日用 buffered 保持。实现和验收见 [AI接力](../development/parallel/AI-cosy-mode-handoff-20261021.md)。

## 决定

启动偏好协议从7向前兼容到8，只增加 `cosy_delivery_mode` 的三个固定值，缺省 buffered。读取旧或坏值不写盘；保存验证后原子落盘，其他设置编辑和旧 Tk 兼容入口保留该字段。声音角色、参考音与交付方式独立。

模式在启动前由已保存偏好及显式维护环境覆盖解析一次，仅传给适用的小智语音子进程。启动值独立留存，不由后续偏好或连接回退改写。改变偏好须停止服务后重启；不允许说话期间热切换。环境覆盖不会持久化到偏好。

启动面板同时显示下次选择、本次启动设置、当前连接实际策略。第三项仅用 AD 已加载模块的无副作用 getter 和原控制面检查取得；缺连接、旧模块、未观测、过期或进程退出均显示未知。共享标准库投影在3.10/3.12中严格核验固定13字段与512字节上限；坏旁路不妨碍原状态读取。

连接失败可将后续片段锁为 buffered，不改持久偏好。已开始回调不整段重播；回调可能入队即计 handoff。未确认客户端流退出时 effective=null、禁止追加、要求重连。允许下一片段仍须既有串行入口和服务健康条件，不能把客户端清理写成服务端空闲。物理播放始终未验证，当前失败不由后续成功覆盖。

## 选择依据与回退

固定枚举沿用现有偏好文件与声音链路，不新增依赖、数据表、端口或后台采样。保留 buffered 默认便于回退；移除本候选后旧入口忽略新偏好键。原设备状态最大合法样本与512字节交付摘要共同受原16384字节限制，AC较大数值摘要继续走已实现的独立只读端点，不压缩或删改旧TTS明细。

## 验收边界

合成持久化、启动传递、失效/回退投影与固定上游真实WAV/CPU Opus分别检查。前端完整CI和真实圆屏连续性、声音、插话仍分别验收。候选软件通过不等于漏检根因已修或设备体验通过；不沿用旧GPU窗口许可。
