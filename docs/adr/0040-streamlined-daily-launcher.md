# ADR-0040：启动面板采用日常入口与高级设置分层

- 日期：2026-09-06
- 状态：已实现，真实可见体验待用户确认
- 局部接续 ADR-0016；不改变其进程所有权和安全边界
- L1 删除的本机默认值已由 ADR-0041 取代；其余决定仍有效

## 背景

启动面板从最初的文字/语音开关逐步增加网络、角色、记忆策略、BGE、TTS 和删除能力。把所有字段平铺在一页，并在每次启动重复确认同一风险，已经妨碍日常使用。用户明确要求提前改善启动体验和视觉层次。

## 决定

1. 保留无新增依赖的 Tkinter 启动器，不在这一轮引入 Electron、Tauri 或另一个本地 Web 服务。
2. 页面分为“日常启动”和“高级设置”：前者只显示文字/圆屏模式、本次摘要、运行状态和主操作；路径、网络、算法、声音和 L1 删除能力放到高级页。
3. 成功启动后，只在 Git 忽略的 `data/control/launcher.json` 保存非敏感首选项：模式、路径、局域网 IP、角色、提取/召回、BGE 路径和 TTS。不得保存 API Key、令牌或对话内容。
4. 校园 HTTP 风险按文案版本确认一次；文案版本变化后重新确认。风险确认不代表同意发送任意敏感内容。
5. `allow_memory_delete` 永不持久化，每次打开面板恢复关闭；打开后网页仍需逐条二次确认，且当前只删除 L1、保留 L0。
6. 用户明确点击“停止服务”直接停止本面板拥有的进程，不再追加一次确认；关闭仍在运行的整个面板时继续确认，避免误关窗口中断回答。
7. 同步小智 IP、切换 TTS 和修改防火墙仍会改变外部配置或系统状态，因此保留操作前确认；“配置已经一致”只显示状态，不弹信息框。

## 后果

常规使用在完成一次风险确认后，可以保持默认配置一键启动；高级选项不会占据主页面。偏好文件损坏或含未知值时回退安全默认，不影响密钥配置。该改版只改善启动体验，不代表服务已开机自启、模型已可用、设备已在线或配置可以运行期热切换。
