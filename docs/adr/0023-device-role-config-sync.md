# ADR-0023：圆屏角色显式同步到小智配置

状态：接受；实现与合成验证完成，实机生效待验收。日期：2026-09-04。

## 决定

在 ADR-0022 的网页版本化设置上增加单向同步，不把网页保存自动广播到圆屏。启动器传入固定小智目录，普通 CLI 不传 `--xiaozhi-server` 时关闭同步接口。浏览器不能选择任意路径、执行命令或修改模型目标。

读取已保存角色和小智配置 → 返回两分钟有效的一次性确认凭据 → 用户确认 → 检查角色版本和全配置摘要 → 原目录备份 → 只替换 `prompt` → 回读核对。调用小智自己的 Python/PyYAML，不给 LongMemory 增加运行依赖。输入经 stdin，输出不含密钥或提示词正文。

保留基础记忆约束并确保一个 `<memory></memory>` 插槽。仅支持本地配置和与控制台匹配的 LongMemory 数据库/项目路径；远程配置、YAML 别名、歧义字段拒绝修改。

## 生效边界

已检查本地上游 `app.py`、`core/connection.py` 与 `core/utils/prompt_manager.py`：启动加载配置，连接复制配置并生成/缓存提示词。磁盘匹配不能证明进程加载。页面永远不以此返回“实机已生效”，需要停止并重新启动小智、重新唤醒圆屏确认。不自动关闭用户进程。

本决定扩展 ADR-0022 的“暂不提供同步”边界；网页角色存储和版本快照策略保持不变。

## 风险与恢复

备份 `.config.yaml.role-<随机标识>.bak` 含完整原配置及凭据，仅留在原私有目录，不能提交或分享。失败可能留下备份、临时文件或已写入状态，先重新检查，不自动重试或删除文件。

同步间有排他锁，写入前检查原文件；不宣称能锁住不遵守此协议的编辑器或其他工具。同步期间不要同时手改 YAML 或运行网络同步。恢复旧角色优先选预设保存后再次同步；完整配置回滚涉及其他配置，需单独确认目标，不自动覆盖。
