# ADR-0150：只把明确双时间取代链视为事实历史

## 状态

已接受（第一切片：只读领域服务与 API）

## 背景

当前回答路径只召回现在有效的 L1，这能避免旧事实继续影响当前回答，却不能可靠回答“我以前住在哪里”或展示事实如何变化。数据库同时存在三种外观相似但语义不同的取代：错误纠正、重复合并和现实事实后来变化。仅凭 `recorded_at` 或 `superseded_by_id` 无法把三者安全区分。

## 决定

1. 只有旧 L1 明确指向新 L1、双方主体相同，并且 `old.valid_to == new.valid_from` 时，才把边解释为现实事实变化。
2. 普通纠错没有现实失效时间，重复合并也不产生事实时间边界；二者不进入时间线。
3. 第一切片从任意一条 L1 双向重建完整链并只读返回，不改变现有聊天召回、上下文注入或回答。
4. 同一节点存在两个符合条件的前驱、形成循环或结构不完整时拒绝猜测，返回稳定歧义错误。
5. 下一切片先把时间线接入记忆详情供人核对；历史问答必须另行定义历史意图、候选预算和引用格式，不能让模型自由读取全部退役记忆。

## 后果

- 已由“记录变化”产生的事实可以形成可审计时间线，为以后历史问答提供可靠数据基础。
- 纠错和去重不会被错误描述成用户过去真实经历过的状态。
- 没有明确 `valid_from/valid_to` 的旧数据不会被自动回填；覆盖率会低，但含义保持可信。
