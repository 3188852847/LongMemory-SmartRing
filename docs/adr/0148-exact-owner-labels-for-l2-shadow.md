# ADR-0148：L2 影子复核使用精确场景支持集

## 背景

L2 证据充分性影子链路已能记录模型判定，但 V43 所有者复核只保存整轮“正确、错误或不确定”。当一轮被标记为错误时，系统不知道哪个 L2 真正支持问题，因而无法区分误拦截、无证据误放行、漏选和多选。

L1 在 V46 已解决同类问题。L2 若继续只保存粗粒度结论，两层就无法使用同一测量标准。

## 决定

1. SQLite V47 为 L2 候选追加字符数，不复制场景正文；字符数用于离线上下文缩减估算。
2. 新的 L2 复核事件显式记录是否有精确支持集，支持集只包含当轮候选中的 `scenario_id`。空集合表示“候选均不足以回答”，与旧标签或不确定明确分开。
3. 选择“判断正确”时，人工集合必须与机器集合完全相同；选择“判断错误”时，必须至少改变一个候选。“暂不确定”不生成真值。
4. 事件、支持集和复核修订在同一事务中追加；陈旧页面不能覆盖新修订。
5. L1/L2 共用一个不读取正文的 SQLite 指标聚合器，但分别保留层级特定的候选 ID 和就绪策略 ID。

## 后果与边界

- 控制台可展示 L2 人工标签的有/无证据分层、误拦截和无证据误放行。
- V46 旧复核迁移后保持“没有精确集合”，不根据整轮对/错猜测支持项。
- 这些仍是影子指标，不改变 L2 召回、上下文或回答。达到就绪条件也只能进入另一次受控试验评审。
