# ADR-0092：圆屏记忆后端可切换，数据与运行边界隔离

- 状态：已接受并实现第一版
- 日期：2026-09-08

## 背景

SmartRing-Plus 圆屏终端负责采集、显示和播放，本身没有本项目意义上的长期
记忆引擎。对话上下文和可选长期记忆都在电脑上的 Xiaozhi 服务端处理。固定
快照默认选择 `nomem`，同时提供 `mem_local_short` 插件；LongMemory 通过同一
Memory 插槽接入。

后续需要复现论文方法并做公平比较，因此不能把 LongMemory 写死为圆屏唯一
记忆实现，也不能为切换算法反复改固件。

## 决定

1. 第一版提供三种圆屏服务端后端：`longmemory`、`xiaozhi_local` 和 `none`。
   `none` 对应 Xiaozhi `nomem`；`xiaozhi_local` 对应 `mem_local_short`。
2. 选择保存在 Git 忽略的非敏感指针中。运行中的会话不热切换；停止后由统一
   启动器在端口空闲时备份并窄范围修改 Xiaozhi 私有 YAML。
3. 切换不读取、复制、迁移、合并或删除任何后端数据。LongMemory 使用原
   SQLite；小智摘要使用其 `data/.memory.yaml`；`none` 不产生跨会话记忆。
4. ASR、回答模型、助手角色、TTS、固件和设备控制保持不变。设备控制身份继续
   来自保留的 LongMemory 配置，但不要求 LongMemory 是当前记忆算法。
5. 统一记录提供器查询和保存耗时，只记录后端名与毫秒数，不记录查询、记忆、
   会话 ID 或模型正文。主观回答速度不能替代分阶段耗时。
6. 未来论文方法必须通过白名单注册和适配器加入，不能让任意类名、命令或配置
   从网页直接执行。正式比较还需冻结数据、问题、模型、人格、TTS 和随机设置。

## 后果

- 同一圆屏无需重刷固件即可在三种记忆条件间切换。
- `none` 是无长期记忆速度基线，不应称为“原厂长期记忆”。
- `mem_local_short` 是小智自带的轻量摘要对照：连接期间保留普通对话列表，断开
  时异步调用 LLM，把本轮对话和旧摘要压成一份 JSON，并按设备角色写入
  `.memory.yaml`；下一轮查询直接注入整份摘要，不做检索、逐条来源或纠错链。
- 小智摘要可能比 LongMemory 查询更快，但断开时会多一次摘要模型调用；最终首
  音频延迟还受 ASR、回答模型和 TTS 影响，必须实测。
- 第一版切换只覆盖圆屏日常链路；网页聊天仍使用 LongMemory。研究实验平台的
  方法切换继续使用独立 `MemoryMethod`，不能把日常后端开关冒充论文实验。
