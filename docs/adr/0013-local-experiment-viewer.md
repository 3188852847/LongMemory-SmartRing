# ADR-0013：本机实验结果查看与人工复核

- 日期：2026-09-03。
- 状态：接受并实现；用户已要求实施结果查看与人工复核，实验运行按钮后置。全量 381 项 Python、14 项 Node 通过；本机 HTTP/数据投影验证通过，真实浏览器交互体验待用户进行。
- 延续本机控制台及 ADR-0012，不改实验协议和原有评分。
- 后续扩展：运行按钮后置的决定现由 [ADR-0014](0014-local-experiment-jobs.md) 接续，新增显式启用的单作业运行；以下记录保留首版查看/复核范围。

## 范围与决定

新增 `/experiments`，展示已有比较、仅检索、冻结检索回答三类报告。列表区分 Fake/真实回答/仅检索；支持搜索、类型过滤、分页，详情展示各组完成、词面初筛、证据覆盖与独立复核。逐题并排显示回答、原召回、实际注入和带说话角色的原始来源。

第一版不运行实验、不发模型请求、不下载权重、不控制设备、不打开个人库，不改变数据集/原报告/原评分。不直接开放整个 experiments 目录，不提供任意路径读写和报告上传/下载。

报告仅从固定 `experiments/runs/<白名单运行ID>/report.json` 读取；限制文件 8 MiB、报告 2000 行、枚举 500 个运行目录。损坏/不支持的目录单独提示。源码中的白名单元数据投影避免直接发送完整配置。拒绝符号链接和 Windows junction。

按上游报告摘要在限定目录定位父比较实验，来源从其 history.json 读取，缺失时明确提示；这不是重新执行整个冻结协议、验证模型权重或证明产物真实。旧 smoke 平铺报告及任意论文格式暂不支持，不能把它们误记为零分。

## 复核持久化与安全

- 每次保存生成完整逐题附页的新文件，沿用 target-fact-adequacy-v1。未复核题保留 pending；不修改或覆盖前版文件。
- 保存到 `experiments/results/<run>-<requestUUID>-review.json`，Git 忽略。附页绑定原报告 SHA256，且通过现有复核校验器验证；报告变化或旧编辑 revision 不匹配拒绝保存。
- 网页写入的 reviewer_kind 固定 human，助手附页仍独立显示。署名由本机用户自报，不是账户/身份认证。每个署名展示最近有效版本，历史文件保留；第一版不提供历史版本切换器。
- 同一控制台进程内互斥，避免并发覆盖；request UUID 使相同请求幂等。多个控制台实例同时写同一署名不属于首版并发保证，请只在一个窗口/服务集中复核。连接错误不自动重发，先刷新确认结果。
- 沿用回环绑定、Host/Origin、会话 Cookie、CSRF、CSP 与 no-store。复核正文上限 16 KiB、理由最多 1000 字；设备 API 原 1 KiB 限制不变。
- 全部动态内容用 textContent/value，不用 HTML 拼接、CDN、外部字体、浏览器持久存储。复核保存到服务端文件，刷新/服务重启后可读取。

## 前端选择复审

实验选择、问题选择、过滤/分页及编辑状态已触及原 ADR-0007 的框架复审信号。本轮明确复审：仍沿用静态 HTML + 原生模块，原因是只有一个结果页、没有任务调度或实时图表，核心投影可在服务端完成。将可测试纯展示函数独立为 experiment-view.mjs，异步请求用版本号拒绝过期响应，编辑离开提示保护草稿。

不为此迁移现有三页或新增依赖。后续引入运行队列、实时进度或多个共享复杂编辑页面时重新评估；不把本次选择当作永久禁止框架。网站构建技能用于工作面布局、可读性与本地资源检查，托管/云存储规则不覆盖用户已决定的本机隐私边界。

## 验收与限制

- 合成测试覆盖：报告列表/损坏隔离、分组分母、来源角色、仅检索不可评回答；复核追加、重开、幂等、冲突、报告变更；越界路径、链接、CSRF、跨源和静态白名单。
- 前端测试覆盖：组名/缺失值/类型过滤/恶意文本不作为 HTML、本地资源约束。
- 用真实报告进行只读 API/数据投影检查，不代用户写 human 复核。页面提供本机预览；未自动操作浏览器做点击或视觉验收，不以 HTTP 成功代替可用性验收。
- 磁盘异常可能留下无效新附页，读取会忽略并提示；旧版本不删除。大量实验的索引、报告分页、跨进程写锁和断电事务保证后续处理，不声称生产级档案库。
