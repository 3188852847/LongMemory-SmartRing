# ADR-0192：自有网关区分最终答案与显式推理

2026-10-20。状态：候选，待整合及实机复核。依据是所有者报告圆屏字幕与语音均包含异常推理内容；该报告不算此前版本实机验收通过。本记录不认定现场上游的具体格式。

## 证据与决定

基线 `765ef5a` 网关不将 `reasoning_content` 映射到 `content`，但会原样转发全部SSE数据。固定小智消费端仅取 `delta.content`：独立推理字段不会因此被念出；普通分支的think过滤不能跨chunk，工具分支没有该过滤。合成明确标签样本证明这两个边界有缺陷，详见[V交付记录](../development/parallel/V-reasoning-boundary-20261020.md)。现场未获脱敏样本，不能把候选缺陷直接写成现场根因。

在自有ModelGateway的答案边界统一处理：流式voice答案、非流式answer/probe响应删除独立 `reasoning_content`，从不把它填回空content。仅将答案开头、可有至多64个前导空白的精确小写 `<think>…</think>` 视为显式协议控制块，支持跨增量、嵌套及连续前导块；首次普通正文出现后保持原样，包括正文中的标签示例。工具参数不参与此文本解析。纯HTTP传输、Hy/旧提取协议与回答提示词不变。

解析器只保留至多64个空白加6个未完成开始标签字符，或推理块内至多7个控制标签尾字符；不缓存整个推理或整个答案。网关在一个有界SSE事件解析完成后再输出该事件，role、tool_calls、finish_reason、usage和DONE语义保留。标签未结束、协议错误或客户端取消不伪造DONE、不重试，沿用unknown预留；有效usage和DONE仍走原结算。非流式同类失败返回原固定错误，不返回推理正文。

## 限制与验收

普通content无标签、缺少开始标签的模板预填充推理，或供应商不声明的其他语法，没有可靠判别信息。禁止按“我需要思考”等措辞猜测删除，也不添加未经核实的供应商参数。若现场属于此类，需先核实所选免费端点/模型公开支持的非推理模式或结构化推理字段，再由有正式配置所有权的会话安排最小配置变更与真实验证；不得盲试参数、自动换付费供应商或用提示词宣称保证隔离。

离线测试分别验证JSON、SSE、所有标签切分点、混合/空/工具增量、未闭合和首包取消；真实临时回环HTTP验证UTF-8字节切分、连接复用及原结算。X负责固定真实消费源码的端到端契约复核。合成通过不证明实机原故障已消失；合入后的真实字幕、语音和打断仍需受控验收。回退只撤销本答案投影，不迁移数据库或修改SDK；原始代码与证据保留，不直接改生产检出。
