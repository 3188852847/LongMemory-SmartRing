# ADR-0118：外部 sanoTTS Node/WASM 快速语音适配器

## 状态

已接受，2026-09-11。

## 背景

EdgeTTS 和 VoxCPM2 已接入，但用户在真实圆屏体验中仍感到首声等待过长。用户独立试听 sanoTTS 后认为速度明显更快，并把源码下载到本机。上游当前的中文“小雅”模型只提供浏览器/WASM 路径；Python 包并不提供等价的中文入口。上游仓库及 Web 包的许可也不适合在没有重新分发审查的情况下复制进本项目。

## 决定

1. 新增独立 Node/WASM 适配服务，固定监听 `127.0.0.1:18769`，只提供健康检查、TTS V2 能力声明和 `POST /v1/audio/speech`。
2. 上游运行时、G2P 文件和模型继续位于项目外；Git 不复制或重新分发它们。启动面板只保存外部目录这一非敏感本机首选项。
3. 当前已验证外部内容的组合指纹固定为 `e7adac23b8ae2aefa1623eaa24f6f8049ddfd97e30efd5a377e0f239e6cd7605`，覆盖运行时、模型、中文 G2P 代码、清单和三个字典本体。启动时不匹配即失败，不静默使用另一版模型。
4. 小智继续使用 `CustomTTS`，通过摘要保护和原配置备份，把固定 URL 切到 18769；EdgeTTS 与 VoxCPM2 都保留为明确回退项。
5. 当前能力只声明完整 WAV 缓冲、单一 `xiaoya` 音色和 0.75–1.5 语速。未实现真正音频流、协作取消、声线克隆或训练，因此不作这些承诺。
6. 服务拒绝浏览器 `Origin`、限制请求体和文本长度、拒绝任意字段和非本机监听；一次只执行一条合成。

## 后果

- 同一套启动面板可在三个后端间切换，能用相同测试台比较当前适配链的等待时间。
- sanoTTS 不占用 VoxCPM2 的 GPU 环境，但仍需 Node.js 和外部模型目录。
- 本机固定句真实验证得到 22.05 kHz 单声道 WAV：2.28 秒音频的声学合成约 1.08 秒。它只是一次本机样本，不是稳定性能结论，也不包含模型回答、Opus、网络或圆屏播放时间。
- GPL 等上游许可义务仍需在未来分发产品前由项目所有者单独复核；当前决定不等于获得商业分发许可。
