# ADR-0187：圆屏独立端口与物理网卡自动跟踪

状态：已接受；2026-10-20 所有者授权，X 候选实现 `04f92df`＋消费副本保护 `8b347be`，正式部署与设备验收待主会话交接。ADR 为架构决策记录。

## 原因与决定

电脑保存的 `192.168.120.106` 已不在网卡上，当前以太网为 `.4`；与此同时 Docker 小智服务发布 8000/8003，并连接另一台设备。两项是独立阻塞，旧两笔通用配置失败事件没有保存具体系统错误码。保留 Docker 的容器、映射、配置、数据和另一设备；只给本项目选择独立的 WebSocket 18000、HTTP/OTA 18003。旧默认 8000/8003 仍兼容，不能只改 YAML 而绕过启动校验。

端口选择从白名单偏好贯通 Options、控制器、命令参数、绑定预检、网络同步、voice/setup 校验及实际厂家消费副本。端口必须是合法整数、互异且不占用项目内部端口；布尔值不能充当整数。8766 控制桥、8767 网页、8768 壁纸与既有声音端口保留。新端口目前仅支持 pipeline 本地语音链路；旧 Tk 读取同一端口，自动网络模式要求正式 React 入口。旧恢复/防火墙工具遇到独立端口明确拒绝，不按默认端口操作另一应用。

## 发现与写入边界

使用已有 Windows PowerShell/Get-NetAdapter 能力，不安装库、不修改系统网络。候选只取在线物理网卡上的首选 RFC1918 IPv4，排除虚拟适配器、回环、链路本地、CGNAT 和非首选地址。首次只有一个明确候选，或保存 IP 唯一对应某物理网卡时，可记录其 GUID 身份；之后仅跟踪该网卡。网卡离线不自动切到另一张卡，多地址或多候选有歧义时等待；所有者可在启动设置输入目标物理网卡 IP 重新选择。身份字段由检测维护，HTTP 不能任意写入。

自动跟踪默认关闭，正式受控部署才为本项目开启。独立工作线程每 30 秒枚举一次，不随聊天轮次触发；候选至少跨越 10 秒稳定窗口，运行中另留至少 10 秒可见提示。按默认采样间隔，通常要到下一次相同观测才满足这两个时间条件；不承诺瞬时发现。断网/检测失败只提示并保留配置，不自动猜选地址。

面板首次打开且尚无已确认归属时只检测；首次显式开启陪伴会预检、同步并记录身份。停止状态的后台同步只允许在当前面板已成功停止自己服务之后执行，仍须检查所有相关地址/端口。运行中不直接改人工配置：只允许本面板 Job 进程存活且双端静默租约取得后停止，停稳后重验候选，才同步并受控重开。其他页面已修改启动设置时不擅自把整份新设置带入自动重开。

人工 YAML 同步限于 `server.ip/port/http_port/websocket/vision_explain`；预检摘要必须在写入前仍匹配，备份读回摘要通过再替换。偏好也留备份并核对配置 revision。停止态先验证消费副本/回执及其原人工来源摘要，再只投影同样五字段，保留已有 Hy 网关投影和全部非网络字段，不生成普通模型回退；来源或副本被并发/人工改动时，在写人工配置前拒绝。正式启动沿既有机制生成当次新 Hy 网关投影。任一步失败保留证据、锁定自动重试，不覆盖用户并发保存的偏好。

## 运行中重开的条件

自动重开只覆盖本轮已验证的 Hy 日用：pipeline、旧主动调度/整理关闭、实验作业未启用。设备仍连接、握手仍进行、控制操作占锁、网页请求或聊天任务尚未结束、Runtime 有递延任务或忙锁、网关仍有连接/流时均拒绝重开。未知 Runtime/工作者形态保守拒绝。没有向模型或费用账本发空闲检查请求。

网页维护门保留已开始处理任务的真实生命周期；客户端断开不把仍执行的线程写入当空闲。语音关闭前保留现有线程池和 TTS 工作者句柄，等待实际结束；不根据上游把 `executor` 清成 None 就推定空闲。完成的句柄在旁路状态检查时清除，不复制对话。两个维护接口均只允许本机鉴权客户端及当前实例，禁止浏览器跨源调用；加闸与空闲检查之间没有 await。租约最多 60 秒，释放失败也会过期，不永久阻止新连接。

两端加闸后，仅用现有 Job 所有权停止本面板服务。停止未确认不立刻再停/启动，不写配置。成功自动重开之间至少间隔 60 秒，每小时最多两次；失败后不循环拉起。运行后的暂时健康检查失败显示待确认，不再错误套用首次启动的 90 秒超时取消当前会话；真实子进程退出仍按失败处理，不自动复活。新增两个 LAN 监听探测缓存 5 秒，网卡枚举不进入记忆或首答流程。

## 设备寻址与限制

本地固件读 `wifi.ota_url` 和 `websocket.url`，OTA 响应可更新 WebSocket 配置。现有热点配网页能保存 Custom OTA URL，无需新固件。构建启用了 `CONFIG_LWIP_DNS_SUPPORT_MDNS_QUERIES`，这只证明设备具有查询基础；本项目没有已部署的电脑 mDNS 发布器，主环境无 zeroconf，Windows/ESP 端到端稳定主机名没有实机证据。本轮不安装依赖、不注册全局服务、不配置 DHCP 保留或 DNS，也不把电脑 YAML 更新等同设备自动改址。

因此当前方案能自动维护电脑端地址；圆屏若保存旧数字 IP，仍须所有者通过现有配网页更新 OTA 地址。未来再次变址可能仍需更新设备。稳定主机名、局域网 DNS 或路由器地址保留是后续选择，须单独明确范围并验证完整链路，不能先把 `.local` 当作可用地址交付。
