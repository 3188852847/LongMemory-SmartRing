# ADR-0129：只读 L1 质量候选收件箱

- 状态：接受
- 日期：2026-09-13

## 背景

日常模型提取可能把语义相近的改写保存为多条 L1，也可能在事实变化后留下表面相反的当前记忆。现有精确正文去重只能处理完全相同的文本；直接自动合并、删除或取代则可能因误判损坏个人记忆和来源链。

## 决定

先增加一个只读、按需运行的 L1 质量候选收件箱：

- 只检查同一主体、当前有效的 L1，不检查退役、未生效或已到期事实；
- 第一版用规范化相等、字符二元片段 Jaccard 重合和少量明确肯定/否定词对生成候选；
- 页面展示成对事实、规则原因和字面重合分，并可分别打开 L0 来源；
- 不调用模型，不进入聊天召回，不自动合并、纠正、取代或删除；
- 最多扫描 500 条 L1、返回 100 组候选，并显式显示截断状态。

相似度是筛选信号，不是事实置信度或语义等价概率。“可能矛盾”也只代表需要核对，不能证明哪一条为真。

## 后果

用户可以开始发现重复和显式矛盾，而不会把尚未校准的算法接入个人数据写路径。当前处置继续复用已有的来源查看、纠正、事实变化和删除操作。

候选的接受、忽略或合并尚未形成持久复核事件；因此同一候选重新扫描时仍会出现。下一阶段应先设计可审计的复核账本和非破坏性合并语义，再考虑自动治理或模型辅助判断。
