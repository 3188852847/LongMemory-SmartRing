# ADR-0151：历史问答只沿当前事实的显式变化链扩展

## 状态

已接受

## 背景

ADR-0150 已能从双时间边界重建真实事实变化链，但普通日常召回只读取当前有效 L1。若直接把全部退役 L1 放回检索，错误纠正、重复合并和过期事实会污染“现在是什么”的回答；若只保留当前 L1，系统又无法回答“我以前住在哪里”。

## 决定

1. 先运行既有当前 L1 检索。只有问题包含明确历史表达，且当前检索已经找到锚点时，才尝试历史扩展。
2. 第一版历史意图使用可审计的保守规则，识别“以前、曾经、之前”等历史问句，以及“什么时候/何时”与搬迁、改变、开始等变化词组合；普通当前问句和含糊时间问句不解锁历史。
3. 历史扩展只能沿 ADR-0150 定义的同主体、`old.valid_to == new.valid_from` 显式变化边读取。纠错、重复合并、断链、歧义链和全库退役记忆不进入回答上下文。
4. 单轮最多补充 10 条历史 L1。上下文明确声明旧事实不代表现在仍成立；召回轨迹给历史条目标记 `temporal_role=historical`，并返回 `valid_from`、`valid_to` 和 L0 来源 ID。
5. 现有 L1 充分性影子观察仍只接收历史扩展前的当前候选，保持既有评估单元不变。
6. 这是只读编排能力，不新增数据库表，不修改 L0–L3，也不调用额外模型。

## 后果

- 网页与 SmartRing-Plus 圆屏终端共用的 Runtime 可以回答已有明确变化链覆盖的历史问题，同时普通问答仍隔离退役事实。
- 历史覆盖率受当前锚点召回质量和显式双时间数据约束；当前检索没找到相关新事实时，系统不会扫描全部旧记忆猜测答案。
- 第一版规则不是通用自然语言时间理解。后续若引入模型分类或更广的事件时间推理，必须先冻结数据并单独验证误开放旧事实的风险。
