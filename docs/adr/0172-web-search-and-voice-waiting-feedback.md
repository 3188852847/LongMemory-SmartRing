# ADR-0172：通用联网搜索与语音等待反馈

- 日期：2026-09-15
- 状态：已实现；软件与公开接口验证通过，圆屏听感待验收
- 来源：用户授权实现“真实查询＋等待反馈”，明确新闻只是例子，目标是通用联网；已提供本机 Tavily 配置。
- 替代边界：补充 ADR-0171“不播放无信息垫话”的决定，允许一次由真实处理状态驱动的短提示。

## 范围与完成条件

包含通用公开网页搜索、同一模型决定是否搜索、Tavily/秘塔本机配置入口、同声线
预生成等待音频、提示与答案独立计时、失败及取消验证。不把新闻做成专用模式。

不包含浏览器登录、网站操作、写入第三方服务、自动多步浏览、全文抓取、天气专用
数据接口、付费订阅开通、新依赖或记忆核心变更。没有凭据时明确说明未联网。

完成条件：普通回答不搜索；搜索最多一次；真实接口返回并保留来源；未知工具拒绝；
空结果/失败不冒充成功；等待提示至多一次；快答案跳过提示；过期包丢弃；真正答案
计时不被提示提前；配置不回显密钥；软件和本机受控接口验证通过。圆屏听感须另验。

## 决定

1. 保留上游 `nointent`，只在项目的语音模型适配器向同一模型提供一个只读
   `web_search` 工具，不启用上游全部函数或设备操作。普通回答沿同一流直接输出，
   联网时消费一次工具调用、执行搜索，再调用模型给出答案。原策略和豆包不安装。
2. 查询关键词最终固定为本轮用户明确说出的问句，不采用可能含私人记忆的模型
   改写，不向搜索站发送角色、历史、记忆、说话人或情绪元数据。代词缺少上下文
   时应先问清楚，牺牲隐式个性化搜索以保证记忆边界。
3. Tavily 采用固定 HTTPS `/search`、basic、三条结果、无供应商二次答案、无原文，
   关闭自动提级；秘塔使用已有公开搜索契约，未猜测日期过滤参数。最多一个请求，
   禁止重定向和自动重试，限制响应大小与连接/读取时间。不自动抓返回链接。
4. 结果仅进入本轮 LLM 请求副本，标记为不可信数据，保留来源 URL、摘要、来源日期
   和检索时间；检索时间不代表发表时间。不按新闻标题编造详情。
5. 真正回答处理开始后延迟 900ms，若尚未有答案音频，只播放一次约一秒的本地
   “我想一下”。若已进入实际搜索且尚未提示，改用“我查一下”。提示为同一
   CosyVoice 声线预生成 Opus，不调用额外 LLM/TTS、不阻塞搜索、不进入 Memory。
6. 未开始提示时答案就绪则跳过；已开始的约一秒短句自然说完，避免词中硬切。
   这最多会短暂延后赶巧到达的答案，不能声称绝对零额外延迟。打断或换轮则废弃
   尚未发送的提示与旧答案；已送进设备缓冲的包不能由服务器追回。
7. `voice_feedback` 只显示查询耗时、提示首包、答案首包和有限状态。首包在最终
   socket 发送入口计时；V6 原首包继续指真正答案，不用垫话制造首声变快的假象。

## 配置与回退

密钥只保存到 Git 忽略的 `.env.web-search.local`，不写命令行、文档或日志。
面板提供遮蔽输入框；保存后下一轮读取，关闭搜索仍保留普通等待提示。切回
“原策略（对照）”并重启可同时关闭这轮搜索适配和等待提示。

网络请求和底层模型阻塞读取不能即时取消，但结果不得串到新话轮。来源可用性、
搜索耗时、模型是否合理选工具及真实打断体验都仍需日用观察。
