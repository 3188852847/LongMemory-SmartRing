# ADR-0109：动态壁纸先进入本机可审计素材库

- 状态：已接受并实现第一切片
- 日期：2026-09-10

## 背景

0007/0008 已证明 SmartRing-Plus 可从 assets 分区播放受限 GIF，但原型是构建时嵌入。日常自定义需要从控制台导入视频，而不是每次手工转码和重新烧录完整固件。

## 决定

1. 首先实现本机素材库：浏览器流式上传，服务端使用 `ffprobe` 校验实际媒体，再按白名单参数转码。
2. 源视频、预览 GIF 和 manifest 只存入已忽略的 `data/round-screen/wallpapers/`；源文件不提供下载 API。
3. 素材 ID 由源内容 SHA-256 与转码参数共同决定。只有探测、转码、输出契约和清单全部成功后，才原子进入可见列表。
4. 首版限制单源文件 768 MiB、最长 1 小时、最多 7680×4320 像素和 120 fps；输出只允许 3–5 秒、8/10/12 fps、64/96/128 色、360×360 无音轨 GIF，最大 4 MiB。
5. 导入和预览不等于设备发布。运行时资源安装需要独立的设备能力协议、非活动区写入、设备端哈希回读和一键回退。

## 后果

- 用户现在可以在控制台选片段并审查转码结果，不需要记忆 FFmpeg 命令。
- 大文件上传和转码会占用本机时间与空间；页面需显式告知处理中状态。
- 本切片不实现删除、自动发布、互联网上传或任意 FFmpeg 参数。
