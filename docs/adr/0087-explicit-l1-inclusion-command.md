# ADR-0087：显式写入 L1 采用自指陈述与确定性规范化

- 状态：已接受并实现
- 日期：2026-09-08

## 背景

日常提取策略可以漏掉用户明确希望长期保留的信息。圆屏又是最终用户入口，不能要求用户打开控制台手工补录。但“记住这个”“记住豆包”等表达缺少稳定目标或主体，直接落库会把命令、问题或第三方事实错误地当作用户画像。

## 决定

1. 第一版只识别带分隔符的 `请记住：具体内容` / `记住：具体内容`。
2. 具体内容必须是一条自指陈述：以“我”“我的”开头，或已经规范写成“用户”开头；问题句和主体不明片段拒绝写入。
3. 确定性地把句首“我/我的”规范化为“用户/用户的”，只产生一条 L1，不调用模型自由改写或拆分。
4. 命令原句完整保存为 L0，L1 使用 `user_stated` 来源。相同当前事实不重复建 L1，只增加新的 L0 证据并返回 `NOOP`。
5. 暂停 L1 生成时，明确记住、纠正和事实变化都只保存 L0 并返回 `write_paused`；来源查看与经过双轮确认的删除仍属于管理操作，可以继续使用。
6. 网页直接使用应用层固定回执；圆屏继续受 ADR-0051 所述小智 Memory 插槽限制。

## 后果

- 用户可以从网页或圆屏明确补充一条简单个人事实，同时保持 L0→L1 来源链与去重语义。
- 该命令不是通用信息抽取器，不支持一句话拆成多个事实、第三方实体、自由指代、自动冲突判断或隐私擦除。
- 用户明确要求记住不等于事实已被外部核实；证据类型仍是 `user_stated`。

## 验证

- 合成测试覆盖首次 ADD、重复 NOOP、L0 原文、问题/主体不明拒绝和暂停写入。
- 回归确认普通聊天、来源查看、纠正、变化和删除仍使用原路径。
- 测试不调用模型、网络或个人数据库。
