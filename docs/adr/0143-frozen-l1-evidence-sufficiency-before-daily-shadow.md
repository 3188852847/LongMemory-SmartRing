# ADR-0143：先冻结评估 L1 证据充分性，再接日常影子链路

- 状态：已接受
- 日期：2026-09-13

## 背景

日常召回分数只能表示词项或向量相关性，不能证明候选明确包含回答所需属性。现有 L2 充分性影子链路绑定场景表，直接复制到 L1 会新增数据库、后台模型和控制台维护成本；同一复核提示在短小、离散的 L1 上是否可靠尚未验证。

## 决定

先建立不访问个人库的冻结 L1 充分性数据与独立运行器。每题给出已经召回的候选和期望支持 ID，覆盖直接支持、多条部分证据、缺少属性、主题相关、主体错位、不确定事实、时间变化、不可信候选和空召回。开发集每个非空题最多一次请求，失败不重试；留出集需要显式解锁。

首次官方模型开发运行暴露了一个开放世界标注错误：“用户养猫”不能推出“用户没有养狗”。V1 数据和原报告保持不变；V2 只修正该期望，并通过保存来源报告哈希的离线工具重评分，不再次调用模型。

## 后果

- V2 重评分 16/16 仅说明当前小型合成候选上值得继续影子验证，不代表日常准确率或可以正式过滤召回。
- 下一步可建设独立、默认关闭的 L1 日常影子账本；在真实样本和人工复核前，不改变回答上下文。
- 开放世界问题必须把“没有证据”与“否定事实”分开，不能为了分数把缺失信息标成反证。
