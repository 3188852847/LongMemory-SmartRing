# ADR-0041：本机单用户启动面板默认允许 L1 删除

- 日期：2026-09-06
- 状态：已接受
- 局部取代 ADR-0040 第 5 条的“每次打开恢复关闭”

## 背景

当前控制台仅在用户自己的电脑上使用，网页管理入口绑定本机，L1 单条删除仍需在详情页确认，且不会删除 L0 原话。每次启动都重新勾选权限增加了日常使用摩擦。

## 决定

1. 只将 Windows 本机启动面板的本次 `allow_memory_delete` 默认值改为开启。
2. 该权限仍不写入 `launcher.json`，不接受外部文件暗中开启。
3. 命令行、API 和服务端的默认值仍为关闭；不使用启动面板时不会自动获得删除能力。
4. 网页仍显示目标 L1 内容并要求确认；当前操作仍保留 L0，不宣称完成隐私擦除。
5. 只要准备开放非本机访问、增加第二个用户或发布正式安装包，必须在发布检查中把面板默认值恢复为关闭，并重新评审鉴权和审计边界。

## 后果

当前单用户日常使用少一个重复操作，同时把风险限制在本机启动器。这不是一个可直接继承到生产环境的默认值。
