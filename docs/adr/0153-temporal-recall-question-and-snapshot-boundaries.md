# ADR-0153：历史召回复核问句、锚点与读快照

## 状态

已接受；补充 ADR-0151 的实现边界，不改变显式变化链模型。

## 背景

合成回归复现了 ADR-0151 实现中的三个缺口：历史陈述也会触发读取；传入退役锚点会把当前继任项错误标成历史；两次独立查询之间的写入会造成历史正文与来源关联不属于同一时刻。

## 决定

1. 历史意图要求同一分句同时具有问句特征和历史/变化时间表达。复用中文问句基线，保留无问号提问；历史陈述加另一句普通问题不开放历史。
2. 适配器重新核对锚点未退役、未被取代且在左闭右开的有效区间内；失效或缺失锚点直接跳过，不沿它寻找新锚点。
3. 以显式 SQLite 只读事务固定变化链和来源关联的快照。它不锁住此前的当前召回或之后的模型生成，不宣称整个回答具备跨阶段事务一致性。
4. 新策略标识为 `explicit_temporal_history_v2`，旧回执与版本不改写；数据库结构保持 V48。

## 权衡与失败预演

- 分句门控会放弃“我以前住南京，你还记得吗”这类跨分句隐含回忆请求。优先避免误开放旧事实，后续语义扩展须单独验证。
- 规则仍可能误解引用、复杂句和无标点混合输入，不是通用语义分类器。
- 读取后锚点可能再次变化；本切片仅保证历史读取内部一致，重新生成回答和跨阶段快照需另行设计。
- 不新增依赖、模型请求或数据库迁移；回退代码即可恢复先前策略，已有记忆及来源不变。
