# ADR-0154：个人日用 V1.0 发布边界

## 状态

已接受，2026-09-13。

## 背景

项目的实现已经超过最初 PC 文本 `0.1.0`：网页与圆屏共享记忆、分层管理、可控主动
交流、个性化、动态壁纸和本机分块语音均已形成纵向闭环。但代码版本和部分指南仍
停留在 V0.1 或早期缓冲式语音描述；能力地图中的研究候选又远多于个人日用所需。
若把所有候选、公共分发和外部工具都列为 V1 前置，版本将没有可达到的终点。

## 决定

1. V1.0 定位为当前所有者的单用户、本机个人日用版本，不等同于公共安装产品。
2. 正式核心是单一启动入口、网页/圆屏日常对话、可信 L0/L1、受控 L2/L3、已验收
   的 CosyVoice3 分块语音和显式开启的主动交流。
3. V1 最后一个新增记忆切片是明确日期定位的历史事实召回；随后冻结功能范围。
4. 证据充分性、语义关系、自动整理和习惯推断继续保留为影子、候选或默认关闭能力。
5. 发布前必须通过自动回归、固定日用路径、备份临时恢复和至少 7 个实际使用日的
   RC 观察；观察期只修阻塞缺陷。
6. 多用户、云部署、公共安装器、更多 TTS、外部生活工具、OTA 与论文扩展不阻塞
   V1.0。

## 后果

- 项目第一次拥有与当前产品路线一致、可以完成的正式版本终点。
- 已实现的研究和实验基础继续保留，但界面与文档必须如实标注是否影响正式回答。
- `0.1.0` 暂不因文档决定立刻改为 `1.0.0`；只有 RC 验收完成后才修改产品版本。
- Git 标签和发布仍不属于普通提交推送授权，准备完成后另行确认。

详细范围与验收见[个人日用 V1.0](../requirements/v1-personal-companion.md)。
