# ADR-0098：圆屏明确记忆质量反馈采用保守规则与追加事件

## 背景

真实圆屏用户无法依赖网页按钮给每轮回答贴标签。SQLite V30 已能确定保存“用户 L0—助手 L0—三层召回计数”，因此可以把下一句明确反馈关联到上一轮回答。但“错了”“忘了”等词在普通对话中也很常见，不能直接触发自我修改或研究标签。

## 决定

1. SQLite V31 新增 `round_screen_memory_feedback_events`。事件只保存目标问答 ID、反馈消息 ID、`recall_miss`/`wrong_memory`、解释器版本和时间，不复制对话正文。
2. 第一版解释器只接受同时明确指向助手与上一轮的表达，例如“你刚才没想起来……”或“你上一轮记错了”。失败描述必须位于“你”之后；“我刚才说错了”“你错了”等歧义句不触发。
3. 只关联十分钟内最近一次已经完成的圆屏回答。没有近期目标时不猜测、不写事件。
4. 命中后允许助手确认“已记录、尚未自动修改长期记忆”。事件不删除、纠正、重答或训练 L1–L3。
5. 质量事件短暂存储失败时，正常语音回答继续；协议明确返回未记录原因，不能伪称成功。
6. 记忆质量页面合并展示网页人工复核与圆屏明确反馈，并显式区分来源。统计接口只返回定位和召回元数据；查看正文必须再进入本机 L0 详情。

## 后果

- 可以从真实日常语音中积累可追溯的问题样本，同时控制误报和错误自进化风险。
- 第一版会漏掉委婉表达，这是有意的精确率优先策略；扩展规则必须用真实复核样本驱动。
- `recorded` 只证明反馈事件进入 SQLite，不证明用户判断正确，更不证明根因已经定位。
