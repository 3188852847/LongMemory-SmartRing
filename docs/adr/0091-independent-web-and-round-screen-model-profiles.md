# ADR-0091：网页与圆屏使用独立模型档案，并由启动器安全同步

- 状态：已接受并实现
- 日期：2026-09-08
- 取代：ADR-0089 中“圆屏配置需独立手工同步”的暂时限制

## 背景

网页 LongMemory 从项目 env 档案读取模型，小智圆屏服务从自己的私有 YAML
读取模型。学校服务重新部署后，网页可切到官方档案，但圆屏仍保留旧学校
地址与 Key，最终只播放小智的通用“稍后再试”兜底语。这个结果既难定位，
也让控制台中的“模型选择”容易被误解成同时控制两条链路。

## 决定

1. 保留 `campus` 与 `official` 两个被 Git 忽略的本机档案，不复制或返回 Key。
2. 网页服务和圆屏语音分别保存“下次启动档案”；旧版单一
   `active_profile` 自动兼容，两条选择可以相同也可以不同。
3. 设置中心分别显示网页当前进程和圆屏小智磁盘配置，圆屏选择必须显式
   保存；保存本身不热改运行中的服务。
4. 统一启动器在确认 8000/8003/8766 等端口没有外部服务监听后，才把圆屏
   所选档案同步到小智私有 YAML。同步只替换当前 OpenAI 兼容提供器的
   `base_url`、`model_name`、`api_key`，使用摘要防并发覆盖，并先保存原文备份。
5. 启动前配置预检验证档案存在、Key 非空、URL 结构和 HTTP 明文许可；它
   不自动调用模型。设置中心另提供一次性圆屏模型连接检测，只发送固定合成
   短句，不读取记忆、不重试。
6. “磁盘配置已匹配”不等于模型在线；“连接检测通过”也不等于 ASR、TTS、
   LongMemory 或圆屏播放已经验收。

## 后果

- 学校 Key 失效时，可让网页和圆屏分别切到官方档案，并在同一次统一重启后
  生效，不再运行手工同步命令。
- 小智 YAML 仍是外部系统私有配置，LongMemory 不把它并入版本库。
- 启动会在必要时产生小智配置备份；没有变化时不重复写入或制造备份。
- 运行中的模型不热切换，避免半轮对话跨两个供应商，也避免修改外部启动的
  小智进程。
