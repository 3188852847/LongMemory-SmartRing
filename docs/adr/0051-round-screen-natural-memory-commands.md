# ADR-0051：圆屏自然记忆操作采用高精度契约与受限执行

状态：已接受

日期：2026-09-06

## 背景

网页已经支持人工纠错和事实变化，但 SmartRing-Plus 圆屏终端才是最终用户入口。要求用户为了纠正一条记忆打开内部控制台，不符合日常产品边界；另一方面，把任意口语交给模型直接修改或删除个人记忆，会产生错误目标、错误时间语义和不可审计删除。

## 决定

1. 在共享 `MemoryRuntime` 前置一个可替换的自然记忆操作处理器。没有命中操作契约的输入继续走原来的提取和召回，不改变普通聊天。
2. 第一版只识别四类边界明确的中文表达：`不是旧值，是新值` 的错误纠正；`我以前……，现在……` 的事实变化；`你怎么知道……` 的来源询问；以及明确的忘记/删除请求。
3. 错误纠正必须由旧值只命中一条当前 L1；事实变化必须由完整旧片段只命中一条当前 L1。歧义或无匹配时只保存 L0 并自然追问，不猜测目标。
4. 纠正和变化复用已有 `MemoryManagementService`、`user_corrected`、`valid_from/valid_to` 与 `SUPERSEDE`。自然表达原文作为 L0 来源保存，不用规范化后的文本冒充用户原话。
5. 来源询问沿 L1→证据→L0 返回最多三条用户原话，不产生新的 L1。
6. 删除不属于自动画像演化。只有用户明确提出删除、系统回读唯一目标、用户紧接着在两分钟内说“确认删除这条记忆”才执行单条 L1 删除；插入其他对话、超时、目标变化或歧义均拒绝。删除仍保留 L0，并明确告知这不是彻底擦除。
7. 每条已识别操作在独立 SQLite `BEGIN IMMEDIATE` 事务内整体提交或回滚，并返回种类、状态、提示、目标 ID 和写入轨迹。普通聊天不获取这条额外写锁。
8. 本切片不新增 schema、不迁移个人数据库、不用模型自由生成操作，也不声称理解任意纠正措辞。后续扩展表达识别时必须保持同一受限执行契约。

## 后果

圆屏用户可以在语音对话中纠错、记录明确变化、询问来源，并通过双轮确认删除单条 L1；网页仍保留为事后审计与回滚平面。固定句式换取了较低误操作风险，未覆盖的自然说法会作为普通聊天处理；需要在真实 ASR 中观察漏识别，再决定是否增加模型辅助“只提候选”层，模型不得直接选择 ID 或执行写入。
