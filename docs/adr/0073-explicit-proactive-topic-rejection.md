# ADR-0073：圆屏明确拒绝主动话题

- 状态：已接受
- 日期：2026-09-07

## 背景

最终用户只接触 SmartRing-Plus 圆屏终端，不能依赖网页审批陪伴策略。沉默不能证明用户不喜欢某个话题，但用户直接说“不再主动聊这个话题”是高质量、可执行的控制信号。

## 决定

1. 第一版只识别三句高精度表达：“以后不要主动聊这个话题”“不要再主动聊这个话题”“别再主动聊这个话题”，允许常见句末标点。
2. “这个话题”只能绑定此前 30 分钟内最近一次、已进入投递流程、来自正式自动触发且带有活动话题素材的问候。
3. 手动测试、`development_*` 验收、未投递候选、固定问候和超过时间窗口的记录不能成为目标；找不到目标时只归档 L0，不猜测或停用其他素材。
4. 命中后在同一事务停用话题素材并写入 `companion_feedback_events`，保存用户 L0、主动问候和话题素材引用；反馈证据固定为 `user_explicit`。
5. 该命令不删除 L0/L1/L2/L3，不关闭全部主动交流，也不训练或在线修改模型。
6. 该安全控制即使在“暂停生成新 L1”时也可执行；普通记忆纠错仍遵守 L1 写入开关。
7. 控制台只读展示明确拒绝及停用动作；未来策略候选可以使用该证据，但不能用一次拒绝推断更广泛的用户价值观。

## 后果

- SQLite 升级至 V21；迁移只增加空反馈表，不回填历史拒绝。
- 反馈命令沿用当前 API 的 `memory_command` 兼容字段，但回答上下文明确标记为“陪伴设置结果”；后续统一自然命令协议时再做兼容迁移。
- 若用户想重新启用素材，当前仍需在控制台重新创建；撤销反馈尚未实现。
