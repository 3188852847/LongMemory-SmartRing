# ADR-0180：显式语音轮次观测与只读累计保留计划

状态：已接受本轮最小切片，日用切换／真实链路验收待办。日期：2026-10-15。

## 背景与决定

所有者授权 Q 在独立工作树补齐语音诊断关联及历次日志容量核对。前轮已有服务端 HTTP 请求 ID 和安全阶段摘要；单流轮转不能限制历次运行累计容量。时间邻近、HTTP 成功、发送首包均无法证明完整语音成功。

新增随机语音轮次，与单 HTTP 请求 ID、记忆事件 ID 和业务幂等 ID 分开。沿已有项目包装器传播上下文和准确句子映射，经内部 Memory 的既有 Bearer 边界接收固定白名单事件。CosyVoice 使用共享 Runtime 凭据签名的轮次头，只为观测校验，服务端独立生成 HTTP ID 并直接报告生成／发送方法事实；不把调用者未经证明的声明接入可信事件。共享凭据仍是单机受管进程的信任域，不是多用户身份隔离。

不侵入 Memory Core，不修改提取／检索、业务幂等、语音调度／流控或设备协议。观测队列、每轮事件、进程内存及日志都有上限；投递不等待业务、不重试，错误只降级观测。各源序号独立，缺失、取消、迟到及失败不能被新轮覆盖成成功。不存在全链路成功状态，设备播放固定未确认。

累计维护只统计固定目录直接条目的元数据。默认 64 MiB／至少 7 天用于只读计划；活动、未知写入者、厂家日志及链接都保护。只对经过独立确认已停止且明确声明的旧诊断流列候选；工具没有删除／搬迁入口，不在状态 GET 中清理。保留证据优先于自动执行预算。

## 取舍与回退

不引入依赖或监控平台，不扫描任意路径，不读取日志正文。代价是观测会丢失、原单流轮转仍会替换自身备份、累计预算需要独立维护授权。代码回退后继续原 HTTP 摘要和原合成业务；新增观测字段不是业务输入，原日志不迁移、不回填。新旧进程混用会显示缺失，不假装已完成接线。

本树无部署厂家快照及 Python 3.10 环境；真实识别提交方式、供应商内部过程、兼容 WAV 回退的请求关联、真实声音与设备体验仍须按契约核对。合成子进程、临时 HTTP 服务和离线替身只证明测试边界。详细字段、容量规则与应用步骤见[观测契约](../development/observability-contract.md)。
